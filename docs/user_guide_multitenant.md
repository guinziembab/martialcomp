## Premiers pas

### 1. Accéder à votre espace

Votre organisation dispose d'un espace dédié accessible via :
- URL personnalisée : `https://votre-organisation.martialcomp.com`
- Ou via l'URL principale avec votre identifiant

### 2. Connexion

1. Rendez-vous sur votre URL personnalisée
2. Entrez vos identifiants :
   - Email
   - Mot de passe
3. Cliquez sur "Se connecter"

### 3. Premier accès

Lors de votre première connexion :
1. Vous serez invité à compléter votre profil
2. Configurez les paramètres de base de votre organisation
3. Ajoutez votre logo et vos couleurs

## Tableau de bord

Le tableau de bord est votre centre de contrôle principal.

### Widgets disponibles

1. **Statistiques rapides**
   - Nombre de pratiquants actifs
   - Compétitions à venir
   - Alertes et notifications

2. **Graphiques d'activité**
   - Évolution des inscriptions
   - Participation aux compétitions
   - Progression des grades

3. **Actions rapides**
   - Ajouter un pratiquant
   - Créer une compétition
   - Gérer les paiements

### Personnaliser le tableau de bord

1. Cliquez sur "Personnaliser" en haut à droite
2. Glissez-déposez les widgets
3. Ajoutez ou supprimez des widgets
4. Sauvegardez votre configuration

## Gestion des utilisateurs

### Types d'utilisateurs

1. **Administrateur**
   - Accès complet à toutes les fonctionnalités
   - Gestion des utilisateurs et permissions

2. **Gestionnaire**
   - Gestion des pratiquants et compétitions
   - Accès aux rapports

3. **Instructeur**
   - Gestion de ses élèves
   - Suivi des progressions

4. **Pratiquant**
   - Consultation de son profil
   - Inscription aux compétitions

### Ajouter un utilisateur

1. Allez dans "Paramètres" > "Utilisateurs"
2. Cliquez sur "Ajouter un utilisateur"
3. Remplissez le formulaire :
   - Nom et prénom
   - Email
   - Rôle
   - Permissions spécifiques
4. Envoyez l'invitation par email

### Gérer les permissions

1. Sélectionnez un utilisateur
2. Cliquez sur "Permissions"
3. Cochez/décochez les permissions
4. Sauvegardez les modifications

## Gestion des pratiquants

### Ajouter un pratiquant

1. Menu "Pratiquants" > "Ajouter"
2. Remplissez les informations :
   - Informations personnelles
   - Coordonnées
   - Informations sportives
   - Grade actuel
3. Ajoutez une photo (optionnel)
4. Validez l'inscription

### Importer des pratiquants

1. Préparez votre fichier CSV avec les colonnes :
   - Nom
   - Prénom
   - Date de naissance
   - Email
   - Grade
2. Menu "Pratiquants" > "Importer"
3. Sélectionnez votre fichier
4. Mappez les colonnes
5. Lancez l'import

### Gérer les grades

1. Sélectionnez un pratiquant
2. Onglet "Grades"
3. Cliquez sur "Attribuer un grade"
4. Sélectionnez :
   - Le grade
   - La date d'obtention
   - L'examinateur
5. Validez l'attribution

## Compétitions

### Créer une compétition

1. Menu "Compétitions" > "Créer"
2. Informations générales :
   - Nom de la compétition
   - Date et lieu
   - Type (kata, combat, etc.)
   - Catégories d'âge
3. Configuration :
   - Règlement
   - Système de notation
   - Nombre de participants max
4. Publiez la compétition

### Gérer les inscriptions

1. Ouvrez la compétition
2. Onglet "Inscriptions"
3. Actions disponibles :
   - Valider/refuser une inscription
   - Modifier une catégorie
   - Générer les poules

### Saisir les résultats

1. Pendant la compétition
2. Onglet "Résultats"
3. Saisissez les scores match par match
4. Le classement se met à jour automatiquement

## Grades et certifications

### Système de grades

1. Configuration dans "Paramètres" > "Grades"
2. Définissez :
   - Les grades par discipline
   - Les prérequis
   - Les délais minimum

### Organiser un passage de grade

1. Menu "Grades" > "Nouveau passage"
2. Sélectionnez :
   - La date
   - Les examinateurs
   - Les candidats éligibles
3. Générez les convocations
4. Après l'examen, saisissez les résultats

### Certifications d'instructeur

1. Menu "Certifications"
2. Gérez :
   - Les types de certifications
   - Les formations requises
   - Les renouvellements

## Finances

### Gestion des cotisations

1. Menu "Finances" > "Cotisations"
2. Définissez :
   - Les types de cotisation
   - Les montants
   - Les périodes
3. Suivez les paiements
4. Relancez les retardataires

### Facturation

1. Création automatique ou manuelle
2. Personnalisation des factures
3. Envoi par email
4. Export comptable

### Rapports financiers

1. Menu "Finances" > "Rapports"
2. Disponibles :
   - État des cotisations
   - Revenus par période
   - Prévisions
   - Export pour comptabilité

## Limites et quotas

### Comprendre votre plan

Votre plan détermine vos limites :
- Nombre d'utilisateurs
- Nombre de pratiquants
- Espace de stockage
- Fonctionnalités disponibles

### Surveiller l'utilisation

1. Menu "Ressources"
2. Consultez :
   - Utilisation actuelle
   - Limites du plan
   - Alertes

### Mettre à niveau

1. Si vous atteignez une limite
2. Cliquez sur "Mettre à niveau"
3. Choisissez un nouveau plan
4. Validez le changement

## Raccourcis clavier

- `Ctrl + N` : Nouveau (pratiquant, compétition)
- `Ctrl + S` : Sauvegarder
- `Ctrl + F` : Rechercher
- `Ctrl + P` : Imprimer
- `Esc` : Fermer la fenêtre modale

## Bonnes pratiques

### Sécurité

1. Utilisez des mots de passe forts
2. Activez l'authentification à deux facteurs
3. Révisez régulièrement les permissions
4. Déconnectez-vous après utilisation

### Organisation

1. Structurez vos données
2. Utilisez les tags et catégories
3. Faites des sauvegardes régulières
4. Nettoyez les données obsolètes

### Performance

1. Optimisez les images avant upload
2. Archivez les anciennes données
3. Utilisez les filtres de recherche
4. Évitez les imports massifs aux heures de pointe
