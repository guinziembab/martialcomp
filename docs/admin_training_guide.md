# Guide de formation administrateur - MartialComp Multi-tenant

## Programme de formation

### Durée : 2 jours (14 heures)

## Jour 1 : Fondamentaux

### Module 1 : Introduction (1h)
- Présentation de MartialComp
- Architecture multi-tenant
- Rôles et responsabilités
- Vue d'ensemble des fonctionnalités

### Module 2 : Configuration initiale (2h)
#### Objectifs
- Configurer l'organisation
- Personnaliser l'apparence
- Définir la structure

#### Pratique
1. Configuration de base
   ```
   Paramètres > Organisation
   - Nom
   - Logo  
   - Informations légales
   ```

2. Personnalisation visuelle
   ```
   Paramètres > Apparence
   - Couleurs
   - Typographie
   - Layout
   ```

3. Structure organisationnelle
   ```
   - Clubs
   - Sections
   - Disciplines
   ```

### Module 3 : Gestion des utilisateurs (2h)
#### Objectifs
- Comprendre les rôles
- Gérer les permissions
- Créer des utilisateurs

#### Pratique
1. Création d'utilisateurs
   ```
   Utilisateurs > Ajouter
   - Informations personnelles
   - Rôle
   - Permissions
   ```

2. Gestion des groupes
   ```
   Groupes > Créer
   - Nom du groupe
   - Permissions communes
   - Membres
   ```

3. Audit des accès
   ```
   Sécurité > Audit
   - Journaux d'accès
   - Actions sensibles
   - Rapports
   ```

### Module 4 : Pratiquants et grades (2h)
#### Objectifs
- Gérer les pratiquants
- Système de grades
- Suivi des progressions

#### Pratique
1. Import de pratiquants
   ```csv
   Nom,Prénom,Email,Grade,Club
   Dupont,Jean,jean@email.com,1er Dan,Club A
   ```

2. Configuration des grades
   ```
   Grades > Configuration
   - Hiérarchie
   - Prérequis
   - Validations
   ```

3. Passages de grade
   ```
   Grades > Examens
   - Planification
   - Convocations
   - Résultats
   ```

## Jour 2 : Fonctionnalités avancées

### Module 5 : Compétitions (2h)
#### Objectifs
- Créer des compétitions
- Gérer les inscriptions
- Saisir les résultats

#### Pratique
1. Création de compétition
   ```
   Compétitions > Nouvelle
   - Informations générales
   - Catégories
   - Règlement
   ```

2. Gestion des inscriptions
   ```
   - Validation
   - Répartition
   - Tirage au sort
   ```

3. Saisie des résultats
   ```
   - Scores en temps réel
   - Classements
   - Certificats
   ```

### Module 6 : Finances (2h)
#### Objectifs
- Gérer les cotisations
- Facturation
- Rapports financiers

#### Pratique
1. Configuration tarifaire
   ```
   Finances > Tarifs
   - Types de cotisation
   - Montants
   - Périodes
   ```

2. Suivi des paiements
   ```
   Finances > Paiements
   - Enregistrement
   - Relances
   - Rapprochement
   ```

3. Rapports
   ```
   Finances > Rapports
   - État des cotisations
   - Prévisions
   - Export comptable
   ```

### Module 7 : Ressources et limites (1h)
#### Objectifs
- Comprendre les limites
- Surveiller l'utilisation
- Optimiser les ressources

#### Pratique
1. Tableau de bord ressources
   ```
   Ressources > Dashboard
   - Utilisation actuelle
   - Limites du plan
   - Alertes
   ```

2. Gestion des quotas
   ```
   - Emails mensuels
   - Espace de stockage
   - Nombre d'utilisateurs
   ```

3. Optimisation
   ```
   - Archives
   - Nettoyage
   - Compression
   ```

### Module 8 : Maintenance et support (2h)
#### Objectifs
- Maintenance préventive
- Résolution de problèmes
- Support utilisateurs

#### Pratique
1. Sauvegardes
   ```
   Maintenance > Sauvegardes
   - Planification
   - Restauration
   - Test
   ```

2. Monitoring
   ```
   Système > Monitoring
   - Performance
   - Erreurs
   - Alertes
   ```

3. Support
   ```
   Support > Tickets
   - Création
   - Suivi
   - Résolution
   ```

## Exercices pratiques

### Exercice 1 : Configuration complète
1. Créer une organisation fictive
2. Personnaliser l'apparence
3. Ajouter 3 utilisateurs avec rôles différents
4. Importer 20 pratiquants
5. Créer une compétition

### Exercice 2 : Gestion d'un événement
1. Créer une compétition régionale
2. Gérer 50 inscriptions
3. Organiser les poules
4. Saisir les résultats
5. Générer les classements

### Exercice 3 : Finances
1. Configurer les cotisations annuelles
2. Enregistrer 10 paiements
3. Identifier les retardataires
4. Générer un rapport trimestriel

### Exercice 4 : Résolution de problèmes
1. Un utilisateur ne peut pas se connecter
2. Des pratiquants n'apparaissent pas
3. Une limite de ressources est atteinte
4. Des emails ne sont pas envoyés

2. Gestion des permissions
3. Limites de ressources
4. Bonnes pratiques

- Configuration d'une fédération
- Gestion d'un championnat
- Résolution de problèmes
