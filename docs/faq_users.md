# FAQ - Questions fréquentes

## Compte et connexion

### Comment me connecter ?
1. Rendez-vous sur votre URL personnalisée : `https://votre-club.martialcomp.com`
2. Entrez votre email et mot de passe
3. Cliquez sur "Se connecter"

### J'ai oublié mon mot de passe
1. Cliquez sur "Mot de passe oublié ?"
2. Entrez votre email
3. Consultez vos emails pour le lien de réinitialisation
4. Créez un nouveau mot de passe

### Je ne reçois pas les emails
Vérifiez :
- Votre dossier spam/courrier indésirable
- L'adresse email est correcte dans votre profil
- Contactez votre administrateur pour vérifier

### Comment changer mon email ?
1. Menu > Mon profil
2. Cliquez sur "Modifier"
3. Changez l'email
4. Validez le nouvel email via le lien envoyé

## Pratiquants

### Comment ajouter un pratiquant ?
1. Menu > Pratiquants > Ajouter
2. Remplissez le formulaire
3. Ajoutez une photo (optionnel)
4. Cliquez sur "Enregistrer"

### Comment importer plusieurs pratiquants ?
1. Menu > Pratiquants > Importer
2. Téléchargez le modèle CSV
3. Remplissez le fichier
4. Uploadez et vérifiez le mapping
5. Lancez l'import

### Comment modifier un grade ?
1. Ouvrez la fiche du pratiquant
2. Onglet "Grades"
3. Cliquez sur "Attribuer un grade"
4. Sélectionnez le nouveau grade et la date

### Comment archiver un pratiquant ?
1. Ouvrez la fiche du pratiquant
2. Menu Actions > Archiver
3. Confirmez l'archivage

## Compétitions

### Comment créer une compétition ?
1. Menu > Compétitions > Créer
2. Remplissez les informations
3. Définissez les catégories
4. Publiez la compétition

### Comment gérer les inscriptions ?
1. Ouvrez la compétition
2. Onglet "Inscriptions"
3. Validez ou refusez les demandes
4. Générez les poules si nécessaire

### Comment saisir les résultats ?
1. Pendant la compétition
2. Onglet "Résultats"
3. Entrez les scores match par match
4. Les classements se mettent à jour automatiquement

### Comment exporter les résultats ?
1. Ouvrez la compétition
2. Onglet "Résultats"
3. Cliquez sur "Exporter"
4. Choisissez le format (PDF, Excel, CSV)

## Cotisations et paiements

### Comment enregistrer un paiement ?
1. Menu > Finances > Paiements
2. Cliquez sur "Nouveau paiement"
3. Sélectionnez le pratiquant
4. Entrez le montant et la méthode
5. Validez

### Comment voir qui doit payer ?
1. Menu > Finances > Cotisations
2. Filtre "Impayées"
3. Exportez la liste si besoin

### Comment envoyer des rappels ?
1. Menu > Finances > Relances
2. Sélectionnez les retardataires
3. Choisissez le modèle d'email
4. Envoyez les rappels

### Comment générer une facture ?
1. Après enregistrement du paiement
2. Cliquez sur "Générer facture"
3. Vérifiez les informations
4. Téléchargez ou envoyez par email

### Comment modifier les couleurs ?

4. Prévisualisez et enregistrez

1. Paramètres > Communications

3. Modifiez le contenu
4. Testez l'envoi

### Comment ajouter des champs personnalisés ?
1. Paramètres > Champs personnalisés
2. Choisissez l'entité (pratiquant, compétition...)
3. Ajoutez le champ
4. Définissez le type et les options

- Espace de stockage utilisé

- Contacter le support

### Comment mettre à niveau mon plan ?
1. Menu > Ressources > Mettre à niveau
2. Choisissez le nouveau plan
3. Vérifiez les nouvelles limites
4. Procédez au paiement

## Problèmes techniques

### L'application est lente
Essayez :
- Vider le cache du navigateur
- Utiliser Chrome ou Firefox récent
- Vérifier votre connexion internet
- Contacter le support si persistant

### Je ne vois pas les modifications
1. Actualisez la page (F5)
2. Videz le cache (Ctrl+Shift+F5)
3. Déconnectez et reconnectez-vous
4. Vérifiez vos permissions

### Erreur lors de l'upload
Vérifiez :
- La taille du fichier (limite selon plan)
- Le format est accepté
- Votre connexion est stable
- L'espace de stockage disponible

### Les emails n'arrivent pas
Vérifiez :
- Le dossier spam
- L'adresse est correcte
- Les quotas d'emails
- Contactez votre administrateur

## Sécurité

### Comment sécuriser mon compte ?
1. Utilisez un mot de passe fort
2. Activez l'authentification à deux facteurs
3. Ne partagez jamais vos identifiants
4. Déconnectez-vous après utilisation

### Que faire si mon compte est compromis ?
1. Changez immédiatement votre mot de passe
2. Vérifiez l'activité récente
3. Contactez votre administrateur
4. Activez la double authentification

### Mes données sont-elles sécurisées ?
Oui, nous utilisons :
- Chiffrement SSL/TLS
- Sauvegardes quotidiennes
- Serveurs sécurisés
- Conformité RGPD
