## 📊 **ORGANISATION BASE DE DONNÉES**

### Structure Recommandée :
```sql
categories (
  id, nom, parent_id, ordre, actif, 
  image, description, meta_title, meta_description
)

sous_categories (
  id, nom, categorie_id, ordre, actif,
  description, image
)

produits (
  id, nom, categorie_id, sous_categorie_id,
  discipline_id, prix, stock, actif,
  description, caracteristiques, images
)

disciplines (
  id, nom, code, couleur_theme
)

marques (
  id, nom, logo, description, site_web
)
```

### Filtres Avancés Recommandés :
- **Par discipline** (karaté, judo, taekwondo, etc.)
- **Par niveau** (débutant, confirmé, expert)
- **Par âge** (enfant, adulte, senior)
- **Par genre** (homme, femme, mixte)
- **Par marque** (Tokaido, Mizuno, Adidas, etc.)
- **Par prix** (gammes tarifaires)
- **Par taille** (système international)
- **Par couleur** (important pour ceintures/tenues)

Cette structure permet une navigation intuitive et une recherche efficace, tout en s'adaptant aux spécificités de chaque discipline martiale.
