## 🎨 NOTES DE PRODUCTION

### Musique
- Style : Électro/Sport dynamique
- BPM : 120-130
- Suggestion : Artlist ou Epidemic Sound - catégorie "Sports" ou "Action"

### Transitions
- Utiliser des transitions rapides (0.3s max)
- Style : Wipe, zoom, glitch léger

### Palette de couleurs
- Primaire : Bleu MartialComp (#2563EB)
- Accent : Or (#FFD700)
- Fond : Noir/Gris foncé (#1a1a2e)

### Typographie
- Titres : Montserrat Bold
- Textes : Open Sans

- [ ] Annotations préparées (cercles, flèches)

- [ ] Montage selon le script
- [ ] Ajout des animations et transitions
- [ ] Synchronisation voix off
- [ ] Ajout musique de fond
- [ ] Sous-titres (FR + EN minimum)
