# MartialComp 仪表盘

## 简介

本目录包含MartialComp应用程序中各种仪表盘的完整文档。每种用户类型都拥有与其角色对应的专属仪表盘，提供适合其需求的功能。

## 仪表盘类型

MartialComp提供多个仪表盘，每个仪表盘都针对特定角色而设计：

1. [**选手仪表盘**](./participants/README.md) - 面向参加比赛的武术练习者
2. [**俱乐部仪表盘**](./clubs/README.md) - 面向俱乐部管理员和行政人员
3. [**协会仪表盘**](./federations/README.md) - 面向协会管理员
4. [**裁判/评委仪表盘**](./referees/README.md) - 面向评判比赛的裁判和评委
5. [**多学科教练仪表盘**](./coaches/README.md) - 面向管理多个学科的教练
6. [**对抗赛仪表盘**](./combat/README.md) - 对抗赛管理的专业界面

## 访问仪表盘

每位用户在登录后会自动重定向到与其角色对应的仪表盘。重定向由 `competitions/views/dashboard/base.py` 文件中的 `dashboard` 视图管理。

## 仪表盘通用结构

所有仪表盘共享通用结构：

- **页眉**：显示用户姓名、角色，并提供设置和退出登录的入口
- **侧边栏**：导航至仪表盘的各个部分
- **主要内容区**：显示每个部分特定的信息和功能
- **页脚**：应用程序版本信息和实用链接

## 仪表盘自定义

用户可以自定义仪表盘的某些方面：
- 选择在主页上显示的小组件
- 信息显示顺序
- 通知偏好设置

## 通用功能

所有仪表盘都提供以下基本功能：
- 包含关键统计数据的概览视图
- 通知和警报
- 用户资料管理
- 即将到来的活动日历
- 文档访问

## 技术设计

仪表盘使用以下技术实现：
- 后端：Django
- 前端：HTML/CSS/JavaScript
