# MartialComp ダッシュボード

## はじめに

このディレクトリには、MartialCompアプリケーションで利用可能な各種ダッシュボードの完全なドキュメントが含まれています。各ユーザータイプには、それぞれの役割に特化したダッシュボードがあり、ニーズに適した機能を提供します。

## ダッシュボードの種類

MartialCompでは、それぞれの役割に合わせて設計された複数のダッシュボードを提供しています：

1. [**選手ダッシュボード**](./participants/README.md) - 大会に参加する武道の練習生向け
2. [**クラブダッシュボード**](./clubs/README.md) - クラブの管理者および運営者向け
3. [**連盟ダッシュボード**](./federations/README.md) - 連盟の管理者向け
4. [**審判・審査員ダッシュボード**](./referees/README.md) - 大会を審査する審判および審査員向け
5. [**マルチ種目コーチダッシュボード**](./coaches/README.md) - 複数の種目を管理するコーチ向け
6. [**組手・試合ダッシュボード**](./combat/README.md) - 試合管理専用のインターフェース

## ダッシュボードへのアクセス

各ユーザーはログイン後、自分の役割に対応するダッシュボードに自動的にリダイレクトされます。リダイレクトは`competitions/views/dashboard/base.py`ファイルの`dashboard`ビューによって管理されています。

## ダッシュボードの共通構造

すべてのダッシュボードは共通の構造を持っています：

- **ヘッダー**：ユーザー名、役割を表示し、設定やログアウトへのアクセスを提供
- **サイドバー**：ダッシュボードの各セクションへのナビゲーション
- **メインコンテンツ**：各セクション固有の情報と機能を表示
- **フッター**：アプリケーションのバージョン情報と便利なリンク

## ダッシュボードのカスタマイズ

ユーザーはダッシュボードの一部の要素をカスタマイズできます：
- ホームページに表示するウィジェットの選択
- 情報の表示順序
- 通知の設定

## 共通機能

すべてのダッシュボードには以下の基本機能があります：
- 主要な統計情報を含む概要ビュー
- 通知とアラート
- ユーザープロフィール管理
- 今後のイベントカレンダー
- ドキュメントへのアクセス

## 技術設計

ダッシュボードは以下の技術を使用して実装されています：
- バックエンド：Django
- フロントエンド：HTML/CSS/JavaScript
- レスポンシブレイアウト：Bootstrap
- 動的更新：AJAX技術
