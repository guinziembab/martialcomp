# Amabhodi Okubuka e-MartialComp

## Isingeniso

Le ndawo iqukethe imibhalo ephelele yamabhodi okubuka (dashboards) ahlukene atholakalayo ku-app ye-MartialComp. Uhlobo ngalunye lomsebenzisi lunebhodi lokubuka eliqondene nendima yalo, elinikeza izici ezilungiselelwe izidingo zalo.

## Izinhlobo Zamabhodi Okubuka

I-MartialComp inikeza amabhodi okubuka amaningana, ngalinye lakhelwe indima ethile:

1. [**Ibhodi Lokubuka Lomhlanganyeli**](./participants/README_zu.md) - Ngabahlanganyeli bezemidlalo yobudoda abadlala emiqhudelwaneni
2. [**Ibhodi Lokubuka Lekilabhu**](./clubs/README_zu.md) - Ngabaphathi bezikhungo zemidlalo nabaphathi bazo
3. [**Ibhodi Lokubuka Lenhlangano**](./federations/README_zu.md) - Ngabaphathi bezinhlangano
4. [**Ibhodi Lokubuka Lommeli**](./referees/README_zu.md) - Ngabammeli nabahluleli abahlola imiqhudelwano
5. [**Ibhodi Lokubuka Lomqeqeshi Wezifundo Eziningi**](./coaches/README_zu.md) - Ngabaqeqeshi abaphatha izifundo eziningi
6. [**Ibhodi Lokubuka Lokulwa**](./combat/README_zu.md) - Isixhumi esenzelwe ukuphatha ukulwa

## Ukufinyelela Amabhodi Okubuka

Umsebenzisi ngamunye uthunyelwa ngokuzenzakalelayo ebhodini lokubuka elihambisana nendima yakhe ngemva kokungena ngemvume. Ukuthunyelwa kuphethwe umbono we-`dashboard` efayelini `competitions/views/dashboard/base.py`.

## Isakhiwo Esivamile Samabhodi Okubuka

Wonke amabhodi okubuka ahlanganyela isakhiwo esivamile:

- **Inhloko**: Ibonisa igama lomsebenzisi, indima, futhi inikeza ukufinyelela kuzilungiselelo nokuphuma
- **Ibha eceleni**: Ukuzulazula kuya ezigabeni ezihlukene zebhodi lokubuka
- **Okuqukethwe okuyinhloko**: Kubonisa ulwazi nezici eziqondene nesigaba ngasinye
- **Unyaweni**: Ulwazi ngohlobo lwe-app nezixhumanisi eziwusizo

## Ukulungisa Amabhodi Okubuka

Abasebenzisi bangalungisa izinto ezithile zebhodi labo lokubuka:
- Ukukhetha ama-widget aboniswe ekhasini lasekhaya
- Ukuhlela kokukhishwa kolwazi
- Okuthandayo kwezaziso

## Izici Ezivamile

Wonke amabhodi okubuka anikeza lezi zici eziyisisekelo:
- Ukubuka konke nezibalo ezibalulekile
- Izaziso nezexwayiso
- Ukuphatha iphrofayela yomsebenzisi
- Ikhalenda yezenzakalo ezizayo
- Ukufinyelela emibhalweni

## Ukwakhiwa Ngobuchwepheshe

Amabhodi okubuka enziwe ngokusebenzisa:
- I-Django yebackend
- I-HTML/CSS/JavaScript yefrontend
- I-Bootstrap yokwakheka okuvumelana nezixhumi
- Ubuchwepheshe be-AJAX bokuvuselelwa okuguquguqukayo

## Imibhalo Enemininingwane

Ukuze uthole imininingwane engeziwe ngalinye ibhodi lokubuka, bheka izixhumanisi ezingenhla noma uhlole izinqolobane ezingaphansi kwale ndawo.
