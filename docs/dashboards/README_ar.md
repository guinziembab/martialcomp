# لوحات تحكم MartialComp

## مقدمة

يحتوي هذا الدليل على الوثائق الكاملة للوحات التحكم المختلفة المتاحة في تطبيق MartialComp. يتوفر لكل نوع من المستخدمين لوحة تحكم خاصة بدوره، تقدم وظائف مكيّفة لاحتياجاته.

## أنواع لوحات التحكم

يقدم MartialComp عدة لوحات تحكم، كل واحدة مصممة لدور محدد:

1. [**لوحة تحكم المشارك**](./participants/README.md) - للممارسين في فنون القتال المشاركين في المسابقات
2. [**لوحة تحكم النادي**](./clubs/README.md) - لمديري الأندية ومسؤوليها
3. [**لوحة تحكم الاتحاد**](./federations/README.md) - لمسؤولي الاتحادات
4. [**لوحة تحكم الحَكَم/القاضي**](./referees/README.md) - للحكام والقضاة الذين يقيّمون المسابقات
5. [**لوحة تحكم المدرب متعدد التخصصات**](./coaches/README.md) - للمدربين الذين يديرون عدة تخصصات
6. [**لوحة تحكم القتال**](./combat/README.md) - واجهة متخصصة لإدارة المباريات القتالية

## الوصول إلى لوحات التحكم

يتم توجيه كل مستخدم تلقائياً إلى لوحة التحكم المناسبة لدوره بعد تسجيل الدخول. تتم إدارة التوجيه بواسطة عرض `dashboard` في ملف `competitions/views/dashboard/base.py`.

## الهيكل المشترك للوحات التحكم

تتشارك جميع لوحات التحكم في هيكل مشترك:

- **الرأس**: يعرض اسم المستخدم والدور، ويتيح الوصول إلى الإعدادات وتسجيل الخروج
- **الشريط الجانبي**: التنقل بين الأقسام المختلفة للوحة التحكم
- **المحتوى الرئيسي**: يعرض المعلومات والوظائف الخاصة بكل قسم
- **التذييل**: معلومات عن إصدار التطبيق وروابط مفيدة

## تخصيص لوحات التحكم

يمكن للمستخدمين تخصيص بعض جوانب لوحة التحكم الخاصة بهم:
- اختيار الأدوات المعروضة في الصفحة الرئيسية
- ترتيب عرض المعلومات
- تفضيلات الإشعارات

## الوظائف المشتركة

تقدم جميع لوحات التحكم هذه الوظائف الأساسية:
- نظرة عامة مع إحصائيات رئيسية
- إشعارات وتنبيهات
- إدارة الملف الشخصي
- تقويم الأحداث المستقبلية
- الوصول إلى التوثيق

## التصميم التقني

تم تنفيذ لوحات التحكم باستخدام:
- Django للواجهة الخلفية
- HTML/CSS/JavaScript للواجهة الأمامية
- Bootstrap للتصميم المتجاوب
- تقنية AJAX للتحديثات الديناميكية
