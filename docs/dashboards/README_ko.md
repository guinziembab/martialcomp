# MartialComp 대시보드

## 소개

이 디렉토리에는 MartialComp 애플리케이션에서 사용할 수 있는 다양한 대시보드에 대한 전체 문서가 포함되어 있습니다. 각 사용자 유형에는 해당 역할에 맞는 전용 대시보드가 있으며, 필요에 맞는 기능을 제공합니다.

## 대시보드 유형

MartialComp는 각 역할에 맞게 설계된 여러 대시보드를 제공합니다:

1. [**선수 대시보드**](./participants/README.md) - 대회에 참가하는 무술 수련생용
2. [**클럽 대시보드**](./clubs/README.md) - 클럽 관리자 및 운영자용
3. [**연맹 대시보드**](./federations/README.md) - 연맹 관리자용
4. [**심판/심사위원 대시보드**](./referees/README.md) - 대회를 심사하는 심판 및 심사위원용
5. [**다종목 코치 대시보드**](./coaches/README.md) - 여러 종목을 관리하는 코치용
6. [**대전 대시보드**](./combat/README.md) - 대전 관리를 위한 전문 인터페이스

## 대시보드 접속

각 사용자는 로그인 후 자신의 역할에 해당하는 대시보드로 자동 리디렉션됩니다. 리디렉션은 `competitions/views/dashboard/base.py` 파일의 `dashboard` 뷰에서 관리됩니다.

## 대시보드 공통 구조

모든 대시보드는 공통 구조를 가지고 있습니다:

- **헤더**: 사용자 이름, 역할을 표시하고 설정 및 로그아웃 접근 제공
- **사이드바**: 대시보드의 각 섹션으로 이동
- **메인 콘텐츠**: 각 섹션별 정보와 기능 표시
- **푸터**: 애플리케이션 버전 정보 및 유용한 링크

## 대시보드 사용자 지정

사용자는 대시보드의 일부 요소를 사용자 지정할 수 있습니다:
- 홈 페이지에 표시할 위젯 선택
- 정보 표시 순서
- 알림 설정

## 공통 기능

모든 대시보드는 다음 기본 기능을 제공합니다:
- 주요 통계가 포함된 개요
- 알림 및 경고
- 사용자 프로필 관리
- 예정된 이벤트 캘린더
- 문서 접근

## 기술 설계

대시보드는 다음 기술을 사용하여 구현되었습니다:
- 백엔드: Django
- 프론트엔드: HTML/CSS/JavaScript
- 반응형 레이아웃: Bootstrap
- 동적 업데이트: AJAX 기술
