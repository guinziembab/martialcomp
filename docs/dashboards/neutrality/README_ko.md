# 심판 공정성 분석

## 목적

공정성 분석 모듈은 대회 중 각 심판의 공정성을 객관적으로 평가할 수 있도록 합니다. 여러 통계 기준에 따라 부여된 점수를 비교하여 잠재적 편향을 자동으로 감지합니다.

이 모듈은 심판을 위한 **교육 및 지속적 개선 도구**이며, 징계 도구가 아닙니다. 각 심판이 자신의 무의식적 경향을 인식하고 발전할 수 있도록 돕습니다.

---

## 공정성 점수 (0-100)

각 심판은 100점 만점으로 계산된 **종합 공정성 점수**를 부여받습니다. 점수가 높을수록 해당 심판이 더 공정한 것으로 평가됩니다.

점수는 완벽한 100점에서 4가지 가중 기준에 따른 감점을 적용하여 산출됩니다.

| 기준 | 가중치 | 최대 감점 |
|------|--------|-----------|
| 소속 클럽 편향 | 30% | -30점 |
| 국적 편향 | 25% | -25점 |
| 채점 경향 편향 | 20% | -20점 |
| 동료 심판과의 일치도 | 25% | -25점 |

### 위험 수준

| 점수 | 수준 | 의미 |
|------|------|------|
| **80-100** | 낮은 위험 (녹색) | 심판이 일관되고 공정하게 채점함 |
| **60-79** | 보통 위험 (주황색) | 경향이 감지됨, 주의 필요 |
| **0-59** | 높은 위험 (빨간색) | 유의미한 편향 감지, 교육 권장 |

---

## 기준 1: 소속 클럽 편향

### 원리
이 기준은 심판이 **자신의 소속 클럽** 선수에게 부여한 점수의 평균과 **다른 클럽** 선수에게 부여한 점수의 평균을 비교합니다.

### 산출 방법
```
차이 = 평균(같은 클럽 선수 점수) - 평균(다른 클럽 선수 점수)
```

### 감지 기준값

| 차이 (절댓값) | 심각도 | 해석 |
|---------------|--------|------|
| < 0.3점 | 중립 | 편향 미감지 |
| 0.3 ~ 0.5점 | 경미 | 약간의 편파성 또는 역편파성 |
| 0.5 ~ 0.8점 | 보통 | 주의가 필요한 유의미한 경향 |
| > 0.8점 | 심각 | 뚜렷한 편향, 시정 조치 권장 |

### 해석 방법
- **양수 (+)**: 심판이 자신의 소속 클럽 선수에게 더 높은 점수를 주는 경향
- **음수 (-)**: 심판이 자신의 소속 클럽 선수에게 오히려 더 엄격하게 채점하는 경향 (과잉 보정)
- 두 가지 상황 모두 교정이 필요한 편향임

### 종합 점수에 대한 감점

| 심각도 | 감점 |
|--------|------|
| 중립 | 0점 |
| 경미 | -10점 |
| 보통 | -20점 |
| 심각 | -30점 |

---

## 기준 2: 국적 편향

### 원리
이 기준은 심판과 **같은 국적**의 선수에게 부여한 점수의 평균과 **다른 국적**의 선수에게 부여한 점수의 평균을 비교합니다.

### 산출 방법
```
차이 = 평균(같은 국적 선수 점수) - 평균(다른 국적 선수 점수)
```

### 감지 기준값

| 차이 (절댓값) | 심각도 | 해석 |
|---------------|--------|------|
| < 0.2점 | 중립 | 편향 미감지 |
| 0.2 ~ 0.4점 | 경미 | 약간의 편파성 또는 역편파성 |
| 0.4 ~ 0.6점 | 보통 | 유의미한 경향 |
| > 0.6점 | 심각 | 뚜렷한 편향 |

### 해석 방법
- 국적은 기술 채점에 어떠한 영향도 미쳐서는 안 되므로, 소속 클럽 편향보다 **더 엄격한 기준값**이 적용됨
- **양수**: 자국 국적에 대한 편파성
- **음수**: 자국 국적에 대한 과도한 엄격성

### 종합 점수에 대한 감점

| 심각도 | 감점 |
|--------|------|
| 중립 | 0점 |
| 경미 | -8점 |
| 보통 | -16점 |
| 심각 | -25점 |

---

## 기준 3: 채점 경향 편향

### 원리
이 기준은 심판의 **전체 채점 평균**을 대회 내 **모든 심판의 전체 평균**과 비교합니다. 체계적으로 너무 관대하거나 너무 엄격하게 채점하는 심판을 감지합니다.

### 산출 방법
```
차이 = 평균(해당 심판의 모든 점수) - 평균(전체 심판의 모든 점수)
```

### 감지 기준값

| 차이 (절댓값) | 심각도 | 해석 |
|---------------|--------|------|
| < 0.2점 | 중립 | 평균 범위 내, 보정된 채점 |
| 0.2 ~ 0.4점 | 경미 | 약간 관대하거나 엄격함 |
| 0.4 ~ 0.6점 | 보통 | 눈에 띄게 관대하거나 엄격함 |
| > 0.6점 | 심각 | 매우 관대하거나 매우 엄격함 |

### 해석 방법
- **양수 (+)**: 심판이 체계적으로 평균보다 높게 채점 (관대)
- **음수 (-)**: 심판이 체계적으로 평균보다 낮게 채점 (엄격)
- 우수한 심판은 중립 범위 내에 위치 (0.2점 미만의 편차)

### 종합 점수에 대한 감점

| 심각도 | 감점 |
|--------|------|
| 중립 | 0점 |
| 경미 | -5점 |
| 보통 | -12점 |
| 심각 | -20점 |

## 기준 4: 동료 심판과의 일치도

### 원리
이 기준은 심판의 채점이 동일한 경기에 대해 **다른 심판들의 채점과 얼마나 일치하는지** 측정합니다. 동료 심판들과 지속적으로 상이한 점수를 부여하는 심판은 보정 문제 또는 편향이 있을 수 있습니다.

### 산출 방법
심판이 채점한 각 경기에 대해:
```
다른 심판 평균 = 평균(해당 경기에 대한 다른 심판들의 점수)
편차 = |해당 심판의 점수 - 다른 심판 평균|
개별 일치도 = max(0, 100 - (편차 × 20))
```

**종합 일치도 점수**는 모든 개별 일치도의 평균입니다.

### 해석

| 일치도 | 의미 |
|--------|------|
| **90-100%** | 우수한 일치도, 매우 잘 정렬된 채점 |
| **75-89%** | 양호한 일치도 |
| **60-74%** | 허용 가능하나 개선 필요 |
| **< 60%** | 낮은 일치도, **경고 발생** |

### 종합 점수에 대한 영향
일치도는 보너스/감점을 통해 공정성 점수에 영향을 미칩니다:
```
조정값 = (일치도 - 50) / 2
```
- 일치도 100%: +25점 보너스
- 일치도 50%: 보너스 및 감점 없음
- 일치도 0%: -25점 감점

### 조건
- 산출이 유의미하려면 최소 **3회 이상의 경기** 채점이 필요합니다
- 활성 채점(훈련 채점 제외)만 반영됩니다

## 경고 시스템

다음과 같은 경우 경고가 자동으로 생성됩니다:

| 조건 | 경고 |
|------|------|
| 보통 또는 심각 수준의 소속 클럽 편향 | 편차 값과 함께 "클럽 편향 감지" 표시 |
| 보통 또는 심각 수준의 국적 편향 | 편차 값과 함께 "국적 편향 감지" 표시 |
| 심각 수준의 채점 경향 편향만 해당 | 평균과의 편차와 함께 "극단적 채점 경향" 표시 |
| 일치도 < 60% | "다른 심판들과의 낮은 일치도" 표시 |

경고는 분석 인터페이스에서 각 심판의 상세 정보에서 확인할 수 있습니다.

## 최우수 공정성 심판 시상대

분석이 완료되면, 가장 높은 공정성 점수를 획득한 상위 3명의 심판이 **시상대**에 선정됩니다:

- **1위 (금)**: 가장 높은 공정성 점수
- **2위 (은)**: 두 번째로 높은 점수
- **3위 (동)**: 세 번째로 높은 점수

이 순위는 공정성을 격려하고 모든 심판이 발전하도록 동기를 부여합니다.

## 심판을 위한 권고 사항

### 공정성 점수를 향상시키기 위한 방법

1. **소속 클럽 편향**: 자신의 소속 클럽 선수를 채점할 때 특히 주의하십시오. 다른 선수와 동일한 기술 기준을 적용하십시오.

2. **국적 편향**: 기술과 수행력에만 집중하십시오. 선수의 국적이 평가에 영향을 미쳐서는 안 됩니다.

3. **채점 경향**: 정해진 기준에 맞춰 점수를 보정하십시오. 너무 관대하거나 너무 엄격하지 않도록 합니다. 의문이 있을 경우 공식 채점 기준표를 참고하십시오.

4. **일치도**: 동료 심판들과 자주 다른 점수를 부여한다면 기준 이해에 문제가 있을 수 있습니다. 보정 세션에 참여하십시오.

### 모범 실천 사항

- 다른 심판의 점수를 확인하지 않고 각 경기를 독립적으로 채점하십시오
- 채점 척도의 전체 범위를 활용하십시오
- 다른 심판의 점수를 확인한 후 자신의 점수를 수정하지 마십시오
- 각 기준을 별도로 평가하는 데 충분한 시간을 투자하십시오
- 피로감을 느끼면 집중력 유지를 위해 휴식을 취하십시오

---

## 접근 권한 및 기밀성

- 공정성 분석은 **대회 주최자** 및 **연맹 관리자**에게 제공됩니다
- 각 심판은 **자신의 결과**만 열람할 수 있습니다
- 데이터는 기존 채점을 기반으로 **실시간**으로 계산됩니다 (공정성 데이터가 영구적으로 저장되지 않음)
- 분석의 신뢰성을 위해 충분한 수의 채점이 필요합니다 (일치도 계산의 경우 최소 3회 경기)
