# Анализ нейтральности судей

## Цель

Модуль анализа нейтральности позволяет объективно оценить беспристрастность каждого судьи во время соревнования. Он автоматически обнаруживает потенциальную предвзятость, сравнивая выставленные оценки по нескольким статистическим критериям.

Этот модуль является инструментом **обучения и непрерывного совершенствования** для судей, а не дисциплинарным инструментом. Он позволяет каждому судье осознать свои неосознанные тенденции для дальнейшего прогресса.

---

## Балл нейтральности (0-100)

Каждый судья получает **общий балл нейтральности**, рассчитанный из 100 баллов. Чем выше балл, тем более беспристрастным считается судья.

Балл рассчитывается путём вычитания штрафов из максимальных 100 баллов по 4 взвешенным критериям:

| Критерий | Вес | Максимальный штраф |
|----------|-----|-------------------|
| Предвзятость к клубу | 30% | -30 баллов |
| Национальная предвзятость | 25% | -25 баллов |
| Предвзятость позиционирования | 20% | -20 баллов |
| Согласованность с коллегами | 25% | -25 баллов |

### Уровни риска

| Балл | Уровень | Значение |
|------|---------|----------|
| **80-100** | Низкий риск (зелёный) | Судья оценивает последовательно и беспристрастно |
| **60-79** | Умеренный риск (оранжевый) | Выявлены тенденции, требуют наблюдения |
| **0-59** | Высокий риск (красный) | Обнаружена значительная предвзятость, рекомендуется обучение |

---

## Критерий 1: Предвзятость к клубу

### Принцип
Этот критерий сравнивает средние оценки, которые судья ставит спортсменам **своего клуба**, с оценками спортсменам **других клубов**.

### Расчёт
```
Разница = Среднее(оценки спортсменам своего клуба) - Среднее(оценки другим спортсменам)
```

### Пороги обнаружения

| Разница (абсолютное значение) | Степень | Интерпретация |
|-------------------------------|---------|---------------|
| < 0,3 балла | Нейтрально | Предвзятость не обнаружена |
| 0,3 - 0,5 балла | Низкая | Незначительный фаворитизм или антипатия |
| 0,5 - 0,8 балла | Умеренная | Значительная тенденция, требующая наблюдения |
| > 0,8 балла | Высокая | Выраженная предвзятость, рекомендуются корректирующие меры |

### Как интерпретировать
- **Положительное значение** (+): судья склонен оценивать спортсменов своего клуба более благоприятно
- **Отрицательное значение** (-): судья склонен быть строже к спортсменам своего клуба (гиперкомпенсация)
- Обе ситуации являются предвзятостью, требующей корректировки

### Штраф к общему баллу

| Степень | Штраф |
|---------|-------|
| Нейтрально | 0 баллов |
| Низкая | -10 баллов |
| Умеренная | -20 баллов |
| Высокая | -30 баллов |

---

## Критерий 2: Национальная предвзятость

### Принцип
Этот критерий сравнивает средние оценки, выставленные спортсменам **той же национальности**, что и судья, с оценками спортсменам **других национальностей**.

### Расчёт
```
Разница = Среднее(оценки спортсменам той же национальности) - Среднее(оценки спортсменам других национальностей)
```

### Пороги обнаружения

| Разница (абсолютное значение) | Степень | Интерпретация |
|-------------------------------|---------|---------------|
| < 0,2 балла | Нейтрально | Предвзятость не обнаружена |
| 0,2 - 0,4 балла | Низкая | Незначительный фаворитизм или антипатия |
| 0,4 - 0,6 балла | Умеренная | Значительная тенденция |
| > 0,6 балла | Высокая | Выраженная предвзятость |

### Как интерпретировать
- **Более строгие пороги**, чем для клубной предвзятости, поскольку национальность не должна влиять на техническую оценку
- **Положительное значение**: фаворитизм по отношению к своей национальности
- **Отрицательное значение**: чрезмерная строгость к своей национальности

### Штраф к общему баллу

| Степень | Штраф |
|---------|-------|
| Нейтрально | 0 баллов |
| Низкая | -8 баллов |
| Умеренная | -16 баллов |
| Высокая | -25 баллов |

---

## Критерий 3: Предвзятость позиционирования

### Принцип
Этот критерий сравнивает **общее среднее оценок** судьи со **средним всех судей** соревнования. Он выявляет судей, систематически склонных к завышению или занижению оценок.

### Расчёт
```
Разница = Среднее(все оценки судьи) - Среднее(все оценки всех судей)
```

### Пороги обнаружения

| Разница (абсолютное значение) | Степень | Интерпретация |
|-------------------------------|---------|---------------|
| < 0,2 балла | Нейтрально | В пределах среднего, калиброванное оценивание |
| 0,2 - 0,4 балла | Низкая | Слегка щедро или строго |
| 0,4 - 0,6 балла | Умеренная | Заметно щедро или строго |
| > 0,6 балла | Высокая | Очень щедро или очень строго |

### Как интерпретировать
- **Положительное значение** (+): судья систематически оценивает выше среднего (щедро)
- **Отрицательное значение** (-): судья систематически оценивает ниже среднего (строго)
- Хороший судья находится в нейтральном диапазоне (< 0,2 балла отклонения)

### Штраф к общему баллу

| Степень | Штраф |
|---------|-------|
| Нейтрально | 0 баллов |
| Низкая | -5 баллов |
| Умеренная | -12 баллов |
| Высокая | -20 баллов |

---

## Критерий 4: Согласованность с коллегами

### Принцип
Этот критерий измеряет, насколько оценки судьи **согласуются с оценками других судей** за одни и те же выступления. Судья, чьи оценки постоянно расходятся с коллегами, может иметь проблему с калибровкой или предвзятостью.

### Расчёт
Для каждого выступления, оценённого судьёй:
```
Среднее других = Среднее(оценки других судей за это выступление)
Отклонение = |Оценка судьи - Среднее других|
Индивидуальная согласованность = макс(0, 100 - (Отклонение x 20))
```

**Общий балл согласованности** — это среднее всех индивидуальных согласованностей.

### Интерпретация

| Согласованность | Значение |
|-----------------|----------|
| **90-100%** | Отличная согласованность, очень согласованное оценивание |
| **75-89%** | Хорошая согласованность |
| **60-74%** | Приемлемая согласованность, но требует улучшения |
| **< 60%** | Низкая согласованность, **сгенерировано оповещение** |

### Влияние на общий балл
Согласованность влияет на балл нейтральности через бонус/штраф:
```
Корректировка = (Согласованность - 50) / 2
```
- Согласованность 100%: бонус +25 баллов
- Согласованность 50%: ни бонуса, ни штрафа
- Согласованность 0%: штраф -25 баллов

### Условия
- Для значимости расчёта требуется минимум **3 оценённых выступления**
- Учитываются только активные оценки (не тренировочные)

## Система оповещений

Оповещения генерируются автоматически в следующих случаях:

| Условие | Оповещение |
|---------|-----------|
| Умеренная или высокая клубная предвзятость | "Обнаружена клубная предвзятость" с величиной отклонения |
| Умеренная или высокая национальная предвзятость | "Обнаружена национальная предвзятость" с величиной отклонения |
| Только высокое позиционирование | "Экстремальное позиционирование" с отклонением от среднего |
| Согласованность < 60% | "Низкая согласованность с другими судьями" |

Оповещения отображаются в детальной карточке каждого судьи в интерфейсе анализа.

По окончании анализа **подиум** выделяет 3 судей с лучшими баллами нейтральности:

## Рекомендации для судей

### Как улучшить балл нейтральности

1. **Клубная предвзятость**: Будьте особенно внимательны при оценке спортсмена из вашего клуба. Применяйте те же технические критерии, что и ко всем остальным.

2. **Национальная предвзятость**: Сосредоточьтесь исключительно на технике и исполнении. Национальность спортсмена не должна влиять на вашу оценку.

3. **Позиционирование**: Калибруйте свои оценки, ориентируясь на установленные критерии. Не будьте ни слишком щедры, ни слишком строги. В случае сомнений обращайтесь к официальному оценочному листу.

4. **Согласованность**: Если ваши оценки часто расходятся с коллегами, это может указывать на проблему понимания критериев. Участвуйте в калибровочных сессиях.

### Лучшие практики

- Оценивайте каждое выступление независимо, не глядя на оценки других судей
- Используйте всю шкалу оценок
- Не изменяйте свои оценки после просмотра оценок других
- Уделяйте время отдельной оценке каждого критерия
- При усталости делайте перерыв для поддержания концентрации

---

## Доступ и конфиденциальность

- Анализ нейтральности доступен **организаторам соревнований** и **администраторам федераций**
- Каждый судья может просматривать **свои собственные результаты**
- Данные рассчитываются **в реальном времени** на основе существующих оценок (никакие данные о нейтральности не хранятся постоянно)
- Для надёжности анализа требуется достаточное количество оценок (минимум 3 выступления для согласованности)
