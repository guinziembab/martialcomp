# የዳኞች ገለልተኝነት ትንተና

## ዓላማ

የገለልተኝነት ትንተና ሞጁል በውድድር ወቅት የእያንዳንዱን ዳኛ አድልዖ-አልባነት በተጨባጭ ለመገምገም ያስችላል። በበርካታ ስታቲስቲካዊ መስፈርቶች መሰረት የተሰጡ ውጤቶችን በማነጻጸር ሊኖሩ የሚችሉ አድልዖዎችን በራስ-ሰር ያገኛል።

ይህ ሞጁል ለዳኞች **የስልጠና እና ቀጣይ የማሻሻያ መሳሪያ** ነው እንጂ የዲሲፕሊን መሳሪያ አይደለም። እያንዳንዱ ዳኛ ለማደግ ሲል ያልተገነዘባቸውን ዝንባሌዎች እንዲያውቅ ያግዛል።

---

## የገለልተኝነት ነጥብ (0-100)

እያንዳንዱ ዳኛ ከ100 ነጥብ ላይ የሚሰላ **አጠቃላይ የገለልተኝነት ነጥብ** ያገኛል። ነጥቡ ከፍ ባለ ቁጥር ዳኛው የበለጠ አድልዖ-አልባ ተደርጎ ይቆጠራል።

ነጥቡ ከፍጹም 100 ነጥብ ላይ በ4 ክብደት-ተሰጪ መስፈርቶች መሰረት ቅጣቶችን በመቀነስ ይሰላል፦

| መስፈርት | ክብደት | ከፍተኛ ቅጣት |
|---------|--------|------------|
| የክለብ አድልዖ | 30% | -30 ነጥብ |
| የዜግነት አድልዖ | 25% | -25 ነጥብ |
| የአቀማመጥ አድልዖ | 20% | -20 ነጥብ |
| ከአቻዎች ጋር ተስማሚነት | 25% | -25 ነጥብ |

|------|------|--------|
| **80-100** | ዝቅተኛ አደጋ (አረንጓዴ) | ዳኛው ወጥ እና አድልዖ-አልባ በሆነ መንገድ ነጥብ ይሰጣል |
| **60-79** | መካከለኛ አደጋ (ብርቱካናማ) | ዝንባሌዎች ተገኝተዋል፣ ክትትል ያስፈልጋል |
| **0-59** | ከፍተኛ አደጋ (ቀይ) | ጉልህ አድልዖዎች ተገኝተዋል፣ ስልጠና ይመከራል |

## መስፈርት 1፡ የክለብ አድልዖ

### መርህ
ይህ መስፈርት ዳኛው ለ**ራሱ ክለብ** ተለማማጆች ከ**ሌሎች ክለቦች** ተለማማጆች ጋር ሲነጻጸር የሚሰጠውን አማካይ ነጥብ ያወዳድራል።

### ስሌት
```
ልዩነት = አማካይ(ለተመሳሳይ ክለብ ተለማማጆች የተሰጡ ነጥቦች) - አማካይ(ለሌሎች ተለማማጆች የተሰጡ ነጥቦች)
```

### የመለየት ደረጃዎች

| ልዩነት (ፍጹም ዋጋ) | ክብደት | ትርጓሜ |
|--------------------|--------|--------|
| < 0.3 ነጥብ | ገለልተኛ | አድልዖ አልተገኘም |
| 0.3 እስከ 0.5 ነጥብ | ዝቅተኛ | ቀላል ወገንተኝነት ወይም ጥብቅነት |
| 0.5 እስከ 0.8 ነጥብ | መካከለኛ | ክትትል የሚያስፈልግ ጉልህ ዝንባሌ |
| > 0.8 ነጥብ | ከፍተኛ | ግልጽ አድልዖ፣ የማስተካከያ እርምጃ ይመከራል |

### እንዴት መተርጎም ይቻላል
- **አዎንታዊ ዋጋ** (+)፡ ዳኛው ለራሱ ክለብ ተለማማጆች ከፍ ያለ ነጥብ የመስጠት ዝንባሌ አለው
- **አሉታዊ ዋጋ** (-)፡ ዳኛው ለራሱ ክለብ ተለማማጆች የበለጠ ጥብቅ የመሆን ዝንባሌ አለው (ከልክ በላይ ማካካስ)
- ሁለቱም ሁኔታዎች ማስተካከል ያለባቸው አድልዖዎች ናቸው

### በአጠቃላይ ነጥብ ላይ ቅጣት

| ዝቅተኛ | -10 ነጥብ |
| መካከለኛ | -20 ነጥብ |
| ከፍተኛ | -30 ነጥብ |

## መስፈርት 2፡ የዜግነት አድልዖ

### መርህ
ይህ መስፈርት ከዳኛው **ጋር ተመሳሳይ ዜግነት** ላላቸው ተለማማጆች ከ**ሌሎች ዜግነቶች** ተለማማጆች ጋር ሲነጻጸር የተሰጡ አማካይ ነጥቦችን ያወዳድራል።

### ስሌት
```
ልዩነት = አማካይ(ተመሳሳይ ዜግነት ነጥቦች) - አማካይ(ሌሎች ዜግነቶች ነጥቦች)
```

### የመለየት ደረጃዎች

| < 0.2 ነጥብ | ገለልተኛ | አድልዖ አልተገኘም |

| > 0.6 ነጥብ | ከፍተኛ | ግልጽ አድልዖ |

- **አዎንታዊ ዋጋ**፡ ለራሱ ዜግነት ወገንተኝነት
- **አሉታዊ ዋጋ**፡ ለራሱ ዜግነት ከልክ በላይ ጥብቅነት

### ስሌት

ልዩነት = አማካይ(የዳኛው ሁሉም ነጥቦች) - አማካይ(የሁሉም ዳኞች ሁሉም ነጥቦች)

## መስፈርት 4፡ ከአቻዎች ጋር ተስማሚነት

### መርህ
ይህ መስፈርት የአንድ ዳኛ ነጥቦች ለተመሳሳዩ ትርኢቶች **ከሌሎች ዳኞች ነጥቦች ጋር** ምን ያህል **የሚስማሙ** እንደሆነ ይለካል። ነጥቦቹ ሁልጊዜ ከባልደረቦቹ የሚለያዩ ዳኛ የማስተካከል ወይም የአድልዖ ችግር ሊኖረው ይችላል።

### ስሌት
ዳኛው ለሰጠው ለእያንዳንዱ ትርኢት፦
```
የሌሎች አማካይ = አማካይ(ለዚህ ትርኢት የሌሎች ዳኞች ነጥቦች)
ልዩነት = |የዳኛው ነጥብ - የሌሎች አማካይ|
ግለሰባዊ ተስማሚነት = max(0, 100 - (ልዩነት × 20))
```

**አጠቃላይ የተስማሚነት ነጥብ** የሁሉም ግለሰባዊ ተስማሚነቶች አማካይ ነው።

### ትርጓሜ

| ተስማሚነት | ትርጉም |
|-----------|--------|
| **90-100%** | እጅግ በጣም ጥሩ ተስማሚነት፣ በጣም የተጣጣመ ውጤት አሰጣጥ |
| **75-89%** | ጥሩ ተስማሚነት |
| **60-74%** | ተቀባይነት ያለው ነገር ግን መሻሻል ያለበት ተስማሚነት |
| **< 60%** | ዝቅተኛ ተስማሚነት፣ **ማንቂያ ይነሳል** |

### በአጠቃላይ ነጥብ ላይ ተጽዕኖ
ተስማሚነት በጉርሻ/ቅጣት አማካይነት የገለልተኝነት ነጥቡን ይነካል፦
```
ማስተካከያ = (ተስማሚነት - 50) / 2
```
- 100% ተስማሚነት፡ +25 ነጥብ ጉርሻ
- 50% ተስማሚነት፡ ጉርሻም ቅጣትም የለም
- 0% ተስማሚነት፡ -25 ነጥብ ቅጣት

### ሁኔታዎች
- ስሌቱ ትርጉም ያለው እንዲሆን ቢያንስ **3 ትርኢቶች** ነጥብ መሰጠት አለባቸው
- ንቁ ነጥቦች (የስልጠና ያልሆኑ) ብቻ ግምት ውስጥ ይገባሉ

## የማንቂያ ስርዓት

በሚከተሉት ሁኔታዎች ማንቂያዎች በራስ-ሰር ይነሳሉ፦

| ሁኔታ | ማንቂያ |
|------|--------|
| መካከለኛ ወይም ከፍተኛ የክለብ አድልዖ | "የክለብ አድልዖ ተገኝቷል" ከልዩነት ዋጋ ጋር |
| መካከለኛ ወይም ከፍተኛ የዜግነት አድልዖ | "የዜግነት አድልዖ ተገኝቷል" ከልዩነት ዋጋ ጋር |
| ከፍተኛ አቀማመጥ ብቻ | "ጽንፍ አቀማመጥ" ከአማካይ ጋር ካለው ልዩነት ጋር |
| ተስማሚነት < 60% | "ከሌሎች ዳኞች ጋር ዝቅተኛ ተስማሚነት" |

ማንቂያዎች በትንተና በይነገጹ ውስጥ በእያንዳንዱ ዳኛ ዝርዝር ገጽ ላይ ይታያሉ።

## በጣም ገለልተኛ ዳኞች ሽልማት

ከትንተናው መጨረሻ ላይ **የሽልማት ምደባ** ከፍተኛ የገለልተኝነት ነጥቦችን ያገኙ 3 ዳኞችን ያሳያል፦

- **1ኛ ደረጃ (ወርቅ)**፡ ከፍተኛው የገለልተኝነት ነጥብ
- **2ኛ ደረጃ (ብር)**፡ ሁለተኛ ምርጥ ነጥብ
- **3ኛ ደረጃ (ነሐስ)**፡ ሶስተኛ ምርጥ ነጥብ

ይህ ደረጃ አሰጣጥ አድልዖ-አልባነትን ያበረታታል እና ሁሉም ዳኞች እንዲሻሻሉ ያበረታታል።

---

## ለዳኞች ምክሮች

### የገለልተኝነት ነጥብን ለማሻሻል

1. **የክለብ አድልዖ**፡ ከራስዎ ክለብ ተለማማጅ ነጥብ ሲሰጡ ልዩ ጥንቃቄ ያድርጉ። ለሌሎች ተለማማጆች የሚጠቀሙባቸውን ተመሳሳይ ቴክኒካዊ መስፈርቶች ይተግብሩ።

2. **የዜግነት አድልዖ**፡ በቴክኒክ እና በአፈጻጸም ላይ ብቻ ያተኩሩ። የተለማማጁ ዜግነት ግምገማዎን መነካት የለበትም።

3. **አቀማመጥ**፡ ነጥቦችዎን ከተዘጋጁ መስፈርቶች ጋር ያስተካክሉ። ከልክ በላይ ለጋስም ከልክ በላይ ጥብቅም አይሁኑ። ጥርጣሬ ሲኖርዎ ኦፊሴላዊ የነጥብ መስጫ ሰንጠረዥን ይመልከቱ።

4. **ተስማሚነት**፡ ነጥቦችዎ ብዙ ጊዜ ከባልደረቦችዎ የሚለያዩ ከሆነ ይህ የመስፈርቶች ግንዛቤ ችግር ሊያሳይ ይችላል። በማስተካከያ ስብሰባዎች ይሳተፉ።

### ጥሩ ልምዶች

- ለእያንዳንዱ ትርኢት የሌሎች ዳኞች ነጥቦችን ሳይመለከቱ በነጻ ነጥብ ይስጡ
- የውጤት አሰጣጥ መለኪያውን ሙሉ ስፋት ይጠቀሙ
- የሌሎችን ነጥቦች ካዩ በኋላ ነጥቦችዎን አይቀይሩ
- እያንዳንዱን መስፈርት ለብቻ ለመገምገም ጊዜ ይውሰዱ
- ድካም ሲሰማዎ ትኩረትዎን ለመጠበቅ እረፍት ያድርጉ

---

## መዳረሻ እና ምስጢራዊነት

- የገለልተኝነት ትንተናው ለ**ውድድር አዘጋጆች** እና ለ**ፌዴሬሽን አስተዳዳሪዎች** ተደራሽ ነው
- እያንዳንዱ ዳኛ **የራሱን ውጤቶች** ማየት ይችላል
- ውሂቡ ከነባር ነጥቦች **በቅጽበት** ይሰላል (ምንም የገለልተኝነት ውሂብ በቋሚነት አይከማችም)
- ትንተናው አስተማማኝ ለመሆን በቂ ነጥቦች ያስፈልጉታል (ለተስማሚነት ቢያንስ 3 ትርኢቶች)
