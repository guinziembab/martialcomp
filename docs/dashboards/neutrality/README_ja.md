# 審判の公正性分析

## 目的

公正性分析モジュールは、競技会における各審判の公平性を客観的に評価するためのものです。複数の統計基準に基づいて付与された得点を比較し、潜在的な偏向を自動的に検出します。

本モジュールは審判の**研修および継続的な改善**を目的としたツールであり、懲戒的なツールではありません。各審判が自身の無意識的な傾向を認識し、成長するための支援を行います。

---

## 公正性スコア（0-100）

各審判は100点満点で計算された**総合公正性スコア**を受け取ります。スコアが高いほど、審判はより公平であると評価されます。

スコアは、満点の100点から、以下の4つの加重基準に基づいてペナルティを差し引くことで算出されます：

| 基準 | 比重 | 最大ペナルティ |
|------|------|----------------|
| クラブ偏向 | 30% | -30点 |
| 国籍偏向 | 25% | -25点 |
| ポジショニング偏向 | 20% | -20点 |
| 他審判との一致度 | 25% | -25点 |

### リスクレベル

| スコア | レベル | 意味 |
|--------|--------|------|
| **80-100** | 低リスク（緑） | 審判は一貫して公平に採点している |
| **60-79** | 中リスク（橙） | 傾向が検出されており、注意が必要 |
| **0-59** | 高リスク（赤） | 重大な偏向が検出されており、研修を推奨 |

---

## 基準1：クラブ偏向

### 原理
この基準は、審判が**自身のクラブ**の選手に付与した得点の平均と、**他のクラブ**の選手に付与した得点の平均を比較します。

### 計算方法
```
差分 = 平均（同一クラブの選手への得点） - 平均（他の選手への得点）
```

### 検出閾値

| 差分（絶対値） | 重大度 | 解釈 |
|----------------|--------|------|
| < 0.3点 | 中立 | 偏向は検出されず |
| 0.3 ～ 0.5点 | 軽度 | わずかなえこひいきまたは不利益 |
| 0.5 ～ 0.8点 | 中程度 | 注意すべき有意な傾向 |
| > 0.8点 | 高度 | 顕著な偏向、是正措置を推奨 |

### 解釈の方法
- **正の値**（+）：審判は自身のクラブの選手に対してより高い得点を付ける傾向がある
- **負の値**（-）：審判は自身のクラブの選手に対してより厳しく採点する傾向がある（過剰補正）
- どちらの状況も是正すべき偏向である

### 総合スコアへのペナルティ

| 重大度 | ペナルティ |
|--------|------------|
| 中立 | 0点 |
| 軽度 | -10点 |
| 中程度 | -20点 |
| 高度 | -30点 |

---

## 基準2：国籍偏向

### 原理
この基準は、審判と**同じ国籍**の選手に付与した得点の平均と、**他の国籍**の選手に付与した得点の平均を比較します。

### 計算方法
```
差分 = 平均（同一国籍への得点） - 平均（他の国籍への得点）
```

### 検出閾値

| 差分（絶対値） | 重大度 | 解釈 |
|----------------|--------|------|
| < 0.2点 | 中立 | 偏向は検出されず |
| 0.2 ～ 0.4点 | 軽度 | わずかなえこひいきまたは不利益 |
| 0.4 ～ 0.6点 | 中程度 | 有意な傾向 |
| > 0.6点 | 高度 | 顕著な偏向 |

### 解釈の方法
- クラブ偏向よりも**閾値が厳格**に設定されている。国籍は技術的な採点に一切影響を及ぼすべきではないためである
- **正の値**：自国籍の選手へのえこひいき
- **負の値**：自国籍の選手への過度な厳格さ

### 総合スコアへのペナルティ

| 重大度 | ペナルティ |
|--------|------------|
| 中立 | 0点 |
| 軽度 | -8点 |
| 中程度 | -16点 |
| 高度 | -25点 |

---

## 基準3：ポジショニング偏向

### 原理
この基準は、審判の**全体的な平均得点**と競技会における**全審判の平均得点**を比較します。体系的に甘すぎる、または厳しすぎる審判を検出します。

### 計算方法
```
差分 = 平均（当該審判の全得点） - 平均（全審判の全得点）
```

### 検出閾値

| 差分（絶対値） | 重大度 | 解釈 |
|----------------|--------|------|
| < 0.2点 | 中立 | 平均的であり、適切に較正されている |
| 0.2 ～ 0.4点 | 軽度 | やや甘い、またはやや厳しい |
| 0.4 ～ 0.6点 | 中程度 | 顕著に甘い、または厳しい |
| > 0.6点 | 高度 | 非常に甘い、または非常に厳しい |

### 解釈の方法
- **正の値**（+）：審判は体系的に平均より高く採点している（甘い）
- **負の値**（-）：審判は体系的に平均より低く採点している（厳しい）
- 優れた審判は中立の範囲内に位置する（偏差0.2点未満）

### 総合スコアへのペナルティ

| 重大度 | ペナルティ |
|--------|------------|
| 中立 | 0点 |
| 軽度 | -5点 |
| 中程度 | -12点 |
| 高度 | -20点 |

---

## 基準4：他審判との一致度

### 原理
この基準は、同一演技に対する審判の得点が**他の審判の得点とどの程度一致しているか**を測定します。他の審判と常に大きく異なる得点を付ける審判は、較正の問題や偏向の可能性があります。

### 計算方法
審判が採点した各演技について：
```
他の審判の平均 = 平均（同一演技に対する他の審判の得点）
偏差 = |審判の得点 - 他の審判の平均|
個別一致度 = max(0, 100 - (偏差 × 20))
```

**総合一致度スコア**は、全ての個別一致度の平均です。

### 解釈

| 一致度 | 意味 |
|--------|------|
| **90-100%** | 優秀な一致度、非常に整合性の高い採点 |
| **75-89%** | 良好な一致度 |
| **60-74%** | 許容範囲内だが改善が必要 |
| **< 60%** | 一致度が低い、**アラートが発生** |

### 総合スコアへの影響
一致度はボーナスおよびペナルティを通じて公正性スコアに影響します：
```
調整値 = (一致度 - 50) / 2
```
- 一致度100%：+25点のボーナス
- 一致度50%：ボーナスもペナルティもなし
- 一致度0%：-25点のペナルティ

### 条件
- 計算が統計的に有意となるためには、最低**3件の演技**の採点が必要
- 有効な得点のみが対象となる（練習用の得点は除外）

---

## アラートシステム

以下の条件に該当する場合、アラートが自動的に生成されます：

| 条件 | アラート |
|------|----------|
| クラブ偏向が中程度または高度 | 「クラブ偏向を検出」と偏差の値を表示 |
| 国籍偏向が中程度または高度 | 「国籍偏向を検出」と偏差の値を表示 |
| ポジショニング偏向が高度のみ | 「極端なポジション」と平均からの偏差を表示 |
| 一致度 < 60% | 「他の審判との一致度が低い」 |

アラートは分析インターフェースの各審判の詳細画面で確認できます。

---

## 最も公正な審判の表彰台

分析の最後に、公正性スコアの上位3名の審判を**表彰台**で表彰します：

- **第1位（金）**：最も高い公正性スコア
- **第2位（銀）**：2番目に高いスコア
- **第3位（銅）**：3番目に高いスコア

このランキングは公平性を評価し、全審判の成長を促進します。

## 審判への推奨事項

### 公正性スコアを向上させるために

1. **クラブ偏向**：自身のクラブの選手を採点する際は特に注意を払ってください。他の選手と同じ技術基準を適用してください。

2. **国籍偏向**：技術と実行のみに集中してください。選手の国籍が評価に影響を及ぼしてはなりません。

3. **ポジショニング**：定められた基準に合わせて得点を較正してください。甘すぎず、厳しすぎないようにしましょう。迷った場合は公式の採点基準を参照してください。

4. **一致度**：他の審判と得点が頻繁に異なる場合、基準の理解に問題がある可能性があります。較正セッションに参加してください。

### 模範的な実践

- 各演技を独立して採点し、他の審判の得点を見ないようにする
- 採点スケールの全範囲を活用する
- 他の審判の得点を確認した後に自分の得点を変更しない
- 各基準を個別に十分な時間をかけて評価する
- 疲労を感じた場合は、集中力を維持するために休憩を取る

---

## アクセスと機密性

- 公正性分析は**競技会主催者**および**連盟管理者**がアクセスできる
- 各審判は**自身の結果のみ**閲覧可能
- データは既存の得点から**リアルタイム**で算出される（公正性データは永続的には保存されない）
- 分析の信頼性を確保するためには十分な数の得点が必要（一致度の計算には最低3件の演技）
