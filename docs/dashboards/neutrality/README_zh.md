# 裁判公正性分析

## 目标

裁判公正性分析模块旨在对比赛中每位裁判的公正性进行客观评估。该模块通过多项统计指标自动检测潜在的评分偏差，将裁判的评分进行对比分析。

本模块是裁判**培训与持续改进**的工具，而非纪律处分工具。它帮助每位裁判认识到自身的无意识倾向，从而不断进步。

---

## 公正性评分（0-100）

每位裁判会获得一个**公正性综合评分**，满分为100分。分数越高，表明裁判越公正。

评分以100分为基础，根据以下4项加权指标扣除相应罚分：

| 指标 | 权重 | 最高罚分 |
|------|------|----------|
| 俱乐部偏向 | 30% | -30分 |
| 国籍偏向 | 25% | -25分 |
| 评分定位偏差 | 20% | -20分 |
| 与同行一致性 | 25% | -25分 |

### 风险等级

| 分数 | 等级 | 含义 |
|------|------|------|
| **80-100** | 低风险（绿色） | 裁判评分一致且公正 |
| **60-79** | 中等风险（橙色） | 检测到一定倾向，需关注 |
| **0-59** | 高风险（红色） | 检测到明显偏差，建议进行培训 |

---

## 指标一：俱乐部偏向

### 原理
该指标比较裁判给**本俱乐部**选手的平均评分与给**其他俱乐部**选手的平均评分之间的差异。

### 计算方法
```
差值 = 平均分(本俱乐部选手评分) - 平均分(其他俱乐部选手评分)
```

### 检测阈值

| 差值（绝对值） | 严重程度 | 解释 |
|----------------|----------|------|
| < 0.3分 | 中性 | 未检测到偏差 |
| 0.3至0.5分 | 轻微 | 存在轻微偏袒或偏严 |
| 0.5至0.8分 | 中等 | 存在明显倾向，需关注 |
| > 0.8分 | 严重 | 偏差显著，建议采取纠正措施 |

### 如何解读
- **正值**（+）：裁判倾向于给本俱乐部选手更高的评分
- **负值**（-）：裁判倾向于对本俱乐部选手评分更严格（过度补偿）
- 以上两种情况均属于需要纠正的偏差

### 对综合评分的罚分

| 严重程度 | 罚分 |
|----------|------|
| 中性 | 0分 |
| 轻微 | -10分 |
| 中等 | -20分 |
| 严重 | -30分 |

---

## 指标二：国籍偏向

### 原理
该指标比较裁判给**与自身同国籍**选手的平均评分与给**其他国籍**选手的平均评分之间的差异。

### 计算方法
```
差值 = 平均分(同国籍选手评分) - 平均分(其他国籍选手评分)
```

### 检测阈值

| 差值（绝对值） | 严重程度 | 解释 |
|----------------|----------|------|
| < 0.2分 | 中性 | 未检测到偏差 |
| 0.2至0.4分 | 轻微 | 存在轻微偏袒或偏严 |
| 0.4至0.6分 | 中等 | 存在明显倾向 |
| > 0.6分 | 严重 | 偏差显著 |

### 如何解读
- **阈值更严格**，因为国籍不应对技术评分产生任何影响
- **正值**：偏袒本国籍选手
- **负值**：对本国籍选手过于严格

### 对综合评分的罚分

| 严重程度 | 罚分 |
|----------|------|
| 中性 | 0分 |
| 轻微 | -8分 |
| 中等 | -16分 |
| 严重 | -25分 |

---

## 指标三：评分定位偏差

### 原理
该指标比较裁判的**总体平均评分**与比赛中**所有裁判的总体平均评分**。用于检测系统性偏高或偏低评分的裁判。

### 计算方法
```
差值 = 平均分(该裁判的所有评分) - 平均分(所有裁判的所有评分)
```

### 检测阈值

| 差值（绝对值） | 严重程度 | 解释 |
|----------------|----------|------|
| < 0.2分 | 中性 | 处于平均水平，评分校准良好 |
| 0.2至0.4分 | 轻微 | 略偏高或偏低 |
| 0.4至0.6分 | 中等 | 明显偏高或偏低 |
| > 0.6分 | 严重 | 严重偏高或偏低 |

### 如何解读
- **正值**（+）：裁判系统性地高于平均分评分（偏宽松）
- **负值**（-）：裁判系统性地低于平均分评分（偏严格）
- 优秀的裁判应处于中性范围内（偏差 < 0.2分）

### 对综合评分的罚分

| 严重程度 | 罚分 |
|----------|------|
| 中性 | 0分 |
| 轻微 | -5分 |
| 中等 | -12分 |
| 严重 | -20分 |

---

## 指标四：与同行一致性

### 原理
该指标衡量裁判的评分与**其他裁判**对同一表演的评分**一致程度**。如果某位裁判的评分持续与同行偏离，可能存在校准问题或评分偏差。

### 计算方法
对于裁判评分的每一场表演：
```
其他裁判平均分 = 平均分(其他裁判对该表演的评分)
偏差 = |裁判评分 - 其他裁判平均分|
单项一致性 = max(0, 100 - (偏差 × 20))
```

**综合一致性评分**为所有单项一致性的平均值。

### 解读

| 一致性 | 含义 |
|--------|------|
| **90-100%** | 一致性极佳，评分高度对齐 |
| **75-89%** | 一致性良好 |
| **60-74%** | 一致性尚可，但有待改进 |
| **< 60%** | 一致性较差，**触发预警** |

### 对综合评分的影响
一致性通过加分/扣分影响公正性评分：
```
调整分 = (一致性 - 50) / 2
```
- 一致性100%：加25分
- 一致性50%：不加不扣
- 一致性0%：扣25分

### 条件
- 至少需要**3场表演**的评分数据，计算结果才具有统计意义
- 仅计入有效评分（不含训练评分）

## 预警系统

系统在以下情况自动生成预警：

| 触发条件 | 预警内容 |
|----------|----------|
| 俱乐部偏向为中等或严重 | "检测到俱乐部偏向"，附偏差值 |
| 国籍偏向为中等或严重 | "检测到国籍偏向"，附偏差值 |
| 仅在评分定位偏差为严重时 | "极端定位"，附与平均值的偏差 |
| 一致性 < 60% | "与其他裁判一致性较低" |

预警显示在分析界面中每位裁判的详细资料页面上。

---

## 最公正裁判排行榜

分析完成后，系统会展示一个**排行榜**，表彰公正性评分最高的前3名裁判：

- **第1名（金牌）**：公正性评分最高
- **第2名（银牌）**：公正性评分第二
- **第3名（铜牌）**：公正性评分第三

该排名旨在奖励公正执裁，并激励所有裁判不断进步。

## 裁判改进建议

### 如何提高公正性评分

1. **俱乐部偏向**：在对本俱乐部选手评分时应格外注意，确保使用与其他选手相同的技术标准。

2. **国籍偏向**：专注于技术水平和动作质量，选手的国籍不应影响您的评价。

3. **评分定位**：参照既定标准校准您的评分，做到既不偏高也不偏低。如有疑问，请参考官方评分标准。

4. **一致性**：如果您的评分经常与同行不一致，可能说明对评分标准的理解存在偏差。建议积极参加评分校准培训。

### 最佳实践

- 独立评分，不参考其他裁判的评分
- 充分利用评分量表的完整区间
- 在看到其他裁判的评分后不要修改自己的评分
- 花时间逐项评估每个标准
- 感到疲劳时适当休息，以保持注意力集中

---

## 访问权限与数据保密

- 公正性分析仅向**比赛组织者**和**联盟管理员**开放
- 每位裁判可以查看**自己的分析结果**
- 数据基于现有评分**实时计算**（不永久存储公正性分析数据）
- 分析需要足够的评分数据才具有可靠性（一致性指标至少需要3场表演的数据）
