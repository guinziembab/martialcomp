# Awon Dasibodu MartialComp

## Ifaara

Itosona yii ni iwe alaye kikun ti awon dasibodu orisirisii ti o wa ninu ohun elo MartialComp. Iru olumulo kookan ni dasibodu kan pato si ipa re, ti o n pese awon isise ti o ba awon aini re mu.

## Awon Iru Dasibodu

MartialComp n pese awon dasibodu pupọ, ọkọọkan ti a se apere fun ipa kan pato:

1. [**Dasibodu Olukopa**](./participants/README.md) - Fun awon ti n se ere idaraya ologun ti wọn n kopa ninu idije
2. [**Dasibodu Egbe**](./clubs/README.md) - Fun awon alagbato egbe ati awon alabojuto wọn
3. [**Dasibodu Ajọ Agbaye**](./federations/README.md) - Fun awon alabojuto ajọ agbaye
4. [**Dasibodu Adajo/Onidajo**](./referees/README.md) - Fun awon adajo ti wọn n se idajo idije
5. [**Dasibodu Olukọni Ọpọ-ẹkọ**](./coaches/README.md) - Fun awon olukọni ti wọn n kọ ọpọ ẹkọ
6. [**Dasibodu Ija**](./combat/README.md) - Atọka amọja fun isakoso ija

## Iwọle si Awon Dasibodu

A ma darí olumulo kookan lọ si dasibodu ti o ba ipa re mu lẹyin ti o wọle. Atunse yii ni a n sakoso nipase wiwo `dashboard` ninu faili `competitions/views/dashboard/base.py`.

## Eto Ti O Wọpọ Fun Awon Dasibodu

Gbogbo awon dasibodu pin eto kan:

- **Akọle**: Fi orukọ olumulo, ipa han, ati fun iraye si awon eto ati ijade
- **Apa ita**: Lilọ kiri si awon apakan orisirisii dasibodu
- **Akoonu akọkọ**: Fi alaye ati awon isise ti o jẹ pato si apakan kookan han
- **Apa isalẹ**: Alaye nipa ẹya ohun elo ati awon ọna asopọ ti o wulo

## Aṣayan Awon Dasibodu

Awon olumulo le se aṣayan awon apakan dasibodu wọn:
- Yiyan awon widjeti ti a fi han lori oju-iwe akọkọ
- Eto ifihan alaye
- Awon ayanfẹ iwifunni

## Awon Isise Ti O Wọpọ

Gbogbo awon dasibodu n pese awon isise ipilẹ wọnyi:
- Akopọ pẹlu awon iṣiro pataki
- Awon iwifunni ati itaniji
- Isakoso profaili olumulo
- Kalẹnda awon iṣẹlẹ ti n bọ
- Iraye si iwe alaye

## Eto Imọ-ẹrọ

A se awon dasibodu nipa lilo:
- Django fun ẹhin
- HTML/CSS/JavaScript fun iwaju
- Bootstrap fun apẹrẹ ti o yipada
- Imọ-ẹrọ AJAX fun awon imudojuiwọn alagbeka

## Iwe Alaye Alaye

Fun alaye diẹ sii nipa dasibodu kookan, tẹle awon ọna asopọ ti o wa loke tabi se iwadii awon apoti-faili kekere ti itọsọna yii.
