# Dasibodu Egbe

## Ifaara

Dasibodu Egbe ni a se apere fun awon alagbato ati alabojuto awon egbe ere idaraya ologun. Atọka aarin yii jẹ ki wọn le sakoso awon ọmọ ẹgbẹ, awon idije, awon ikẹkọ ati isakoso gbogbogbo egbe naa.

## Iwọle si Dasibodu

Lati wọle si dasibodu egbe:
1. Wọle si akọọlẹ MartialComp rẹ
2. Ti a ba ti se profaili rẹ pẹlu ipa "club_manager", a o darí ọ lọ si dasibodu yii laifọwọyi
3. Bibẹẹkọ, lo URL `/dashboard/club/`

## Awon Isise Akọkọ

### Akopọ

Oju-iwe akọkọ dasibodu egbe fi wọnyi han:
- Nọmba apapọ awon ọmọ ẹgbẹ ti n sise
- Pinpin awon ọmọ ẹgbẹ nipa ẹkọ ati ẹka
- Awon idije ti n bọ ti a ṣeto tabi ti o kan egbe naa
- Awon isise aipẹ awon ọmọ ẹgbẹ
- Awon iṣiro owo (ti a ba mu modulu Owo sise)
- Awon iwifunni ati itaniji pataki

### Isakoso Awon Ọmọ Ẹgbẹ

Apakan "Awon Ọmọ Ẹgbẹ" jẹ ki o:
- Wo akojọ pipe awon ọmọ ẹgbẹ
- Fi awon ọmọ ẹgbẹ titun kun
- Sakoso awon profaili, awon ipele ati awon iwe-aṣẹ
- Tẹle awon atuntunse ọmọ ẹgbẹ
- Sakoso awon ibeere ọmọ ẹgbẹ
- Ṣeto awon ọmọ ẹgbẹ nipa ẹgbẹ ati ẹkọ

### Isakoso Idije

Apakan "Awon Idije" jẹ ki o:
- Se ati seto awon idije
- Sakoso awon iforukọsilẹ awon ọmọ ẹgbẹ fun awon idije ita
- Tẹle awon abajade ati awon isise
- Gbero kalẹnda idije
- Sakoso irin-ajo ati ohun elo

### Isakoso Ikẹkọ

Apakan "Awon Ikẹkọ" jẹ ki o:
- Gbero awon akoko ikẹkọ
- Yan awon olukọni fun awon akoko
- Tẹle wiwa awon ọmọ ẹgbẹ
- Sakoso awon ohun elo ati awon irinṣẹ
- Se awon eto ikẹkọ ti ara ẹni

### Isakoso

Apakan "Isakoso" jẹ ki o:
- Sakoso alaye egbe (awon alaye olubasọrọ, aami, ati bẹbẹ lọ)
- Tunto awon ipa ati awon igbanilaaye olumulo
- Sakoso awon ibatan pẹlu awon ajọ agbaye
- Ṣakoso owo egbe
- Wọle si awon ijabọ ati iṣiro

## Awon Isise Afikun

### Ibasọrọ

Awon irinṣẹ fun ibasọrọ pẹlu awon ọmọ ẹgbẹ:
- Fifi ifiranṣẹ ẹgbẹ ranṣẹ
- Sise awon ikede
- Isakoso awon iwifunni
- Pinpin awon iwe aṣẹ

### Awon Iṣẹlẹ

Isakoso awon iṣẹlẹ egbe:
- Awon idije inu ile
- Awon idanileko ati ikẹkọ
- Awon igbesoke ipele
- Awon ifihan ati ilẹkun sisi

### Owo

Ti a ba mu modulu Owo sise:
- Itọpinpin awon owo isanwo
- Isakoso awon owo-owo ati awon sisanwo
- Awon ijabọ owo
- Isuna asọtẹlẹ

### Awon Iyẹn ati Awon Iwe-ẹri

Isakoso awon iyẹn awon ọmọ ẹgbẹ ati awon oṣiṣẹ:
- Itọpinpin awon ipele ati ilọsiwaju
- Isakoso awon iwe-ẹri ikọni
- Awon iwe-ẹri idajo
- Ikẹkọ ti n tẹsiwaju

## Aṣayan

Awon alabojuto le se aṣayan dasibodu gẹgẹ bi awon aini egbe pato:
1. Tunto awon modulu ti o han
2. Ibamu awon fọọmu ati awon aaye
3. Aṣayan awon ijabọ
4. Atunṣe awon eto iwifunni

## Isọpọ Pẹlu Awon Modulu Miran

Dasibodu Egbe sọpọ pẹlu awon ẹya miran ti MartialComp:
- Modulu isakoso ipele
- Eto isiro fun awon idije
- Ile itaja ori ayelujara (ti a ba mu sise)
- Eto ibasọrọ

## Atilẹyin Imọ-ẹrọ

Ni ọran isoro pẹlu dasibodu rẹ:
1. Wo iwe alaye alaye ninu itọsọna lilo
2. Lo isise "Iranlọwọ" ti o wa lati akojọ akọkọ
3. Kan si atilẹyin imọ-ẹrọ nipase fọọmu ti a yan si
