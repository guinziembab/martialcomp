# 俱乐部仪表盘

## 简介

俱乐部仪表盘专为武术俱乐部的管理员和行政人员而设计。这个集中管理界面允许管理会员、比赛、训练以及俱乐部的整体行政事务。

## 访问仪表盘

要访问俱乐部仪表盘：
1. 登录您的MartialComp账户
2. 如果您的账户配置为"club_manager"角色，您将自动重定向到此仪表盘
3. 否则，请通过URL `/dashboard/club/` 访问

## 主要功能

### 概览

俱乐部仪表盘的主页显示：
- 活跃会员总数
- 按学科和类别的会员分布
- 俱乐部组织或相关的即将举行的比赛
- 会员近期表现
- 财务统计（如果财务模块已启用）
- 重要通知和警报

### 会员管理

"会员"部分允许：
- 查看完整的会员列表
- 添加新会员
- 管理个人资料、段位/级别和执照
- 跟踪会员续费
- 管理入会申请
- 按组别和学科组织会员

### 比赛管理

"比赛"部分允许：
- 创建和组织比赛
- 管理会员参加外部比赛的报名
- 跟踪成绩和表现
- 规划比赛日历
- 管理出行和后勤

### 训练管理

"训练"部分允许：
- 规划训练课程
- 为课程分配教练
- 跟踪会员出勤
- 管理设施和器材
- 创建个性化训练计划

### 行政管理

"行政管理"部分允许：
- 管理俱乐部信息（地址、标志等）
- 配置用户角色和权限
- 管理协会隶属关系
- 管理俱乐部财务
- 访问报告和统计数据

## 附加功能

### 通信

与会员沟通的工具：
- 发送群发消息
- 创建公告
- 管理通知
- 共享文档

### 活动

管理俱乐部活动：
- 内部比赛
- 集训和培训
- 段位/级别考试
- 表演和开放日

### 财务

如果财务模块已启用：
- 会费跟踪
- 发票和付款管理
- 财务报告
- 预算规划

### 资质与认证

管理会员和工作人员的资质：
- 段位/级别和进度跟踪
- 教练资格管理
- 裁判认证
- 继续教育

## 自定义

管理员可以根据俱乐部的特定需求自定义仪表盘：
1. 配置可见模块
2. 调整表单和字段
3. 自定义报告
4. 调整通知设置

## 与其他模块的集成

俱乐部仪表盘与MartialComp的其他组件集成：
- 段位/级别管理模块
- 比赛评分系统
- 在线商店（如果已启用）
- 通信系统

## 技术支持

如果在使用仪表盘时遇到困难：
1. 请参阅用户指南中的详细文档
2. 使用主菜单中的"帮助"功能
3. 通过专用表单联系技术支持
