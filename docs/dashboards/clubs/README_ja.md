# クラブダッシュボード

## はじめに

クラブダッシュボードは、武道クラブの管理者および運営者のために設計されています。この集中管理インターフェースにより、会員、大会、稽古、クラブの総合的な管理が可能です。

## ダッシュボードへのアクセス

クラブダッシュボードにアクセスするには：
1. MartialCompアカウントにログインします
2. プロフィールが「club_manager」の役割で設定されている場合、このダッシュボードに自動的にリダイレクトされます
3. それ以外の場合は、URL `/dashboard/club/` からアクセスしてください

## 主な機能

### 概要

クラブダッシュボードのメインページには以下が表示されます：
- アクティブ会員の総数
- 種目とカテゴリー別の会員分布
- クラブが主催または関連する今後の大会
- 会員の最近のパフォーマンス
- 財務統計（財務モジュールが有効な場合）
- 重要な通知とアラート

### 会員管理

「会員」セクションでは以下が可能です：
- 全会員リストの閲覧
- 新規会員の追加
- プロフィール、段位・級位、ライセンスの管理
- 会員更新の追跡
- 入会申請の管理
- グループおよび種目別の会員整理

### 大会管理

「大会」セクションでは以下が可能です：
- 大会の作成と運営
- 外部大会への会員登録の管理
- 結果とパフォーマンスの追跡
- 大会カレンダーの計画
- 移動と物流の管理

### 稽古管理

「稽古」セクションでは以下が可能です：
- 稽古セッションの計画
- セッションへのコーチの割り当て
- 会員の出席追跡
- 施設と設備の管理
- カスタマイズされた稽古プログラムの作成

### 管理運営

「管理運営」セクションでは以下が可能です：
- クラブ情報の管理（連絡先、ロゴなど）
- ユーザーの役割と権限の設定
- 連盟への加盟管理
- クラブ財務の管理
- レポートと統計へのアクセス

## 追加機能

### コミュニケーション

会員とのコミュニケーションツール：
- グループメッセージの送信
- お知らせの作成
- 通知管理
- 文書の共有

### イベント

クラブイベントの管理：
- 内部大会
- 合宿と研修
- 昇段・昇級審査
- デモンストレーションとオープンデー

### 財務

財務モジュールが有効な場合：
- 会費の追跡
- 請求書と支払いの管理
- 財務レポート
- 予算計画

### 資格と認定

会員とスタッフの資格管理：
- 段位・級位と進捗の追跡
- 指導資格の管理
- 審判資格
- 継続研修

## カスタマイズ

管理者はクラブの特定のニーズに合わせてダッシュボードをカスタマイズできます：
1. 表示モジュールの設定
2. フォームとフィールドの調整
3. レポートのカスタマイズ
4. 通知設定の調整

## 他のモジュールとの連携

クラブダッシュボードはMartialCompの他のコンポーネントと連携しています：
- 段位・級位管理モジュール
- 大会スコアリングシステム
- オンラインショップ（有効な場合）
- コミュニケーションシステム

## テクニカルサポート

ダッシュボードでお困りの場合：
1. ユーザーガイドの詳細なドキュメントをご参照ください
2. メインメニューからアクセスできる「ヘルプ」機能をご利用ください
3. 専用フォームからテクニカルサポートにお問い合わせください
