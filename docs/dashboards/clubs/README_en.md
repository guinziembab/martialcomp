# Club Dashboard

## Introduction

The Club Dashboard is designed for managers and administrators of martial arts clubs. This centralized interface allows managing members, competitions, training sessions and the club's general administration.

## Accessing the Dashboard

To access the club dashboard:
1. Log in to your MartialComp account
2. If your profile is configured with the "club_manager" role, you will be automatically redirected to this dashboard
3. Otherwise, access it via the URL `/dashboard/club/`

## Main Features

### Overview

The main page of the club dashboard displays:
- Total number of active members
- Member breakdown by discipline and category
- Upcoming competitions organized by or involving the club
- Recent member performances
- Financial statistics (if the Finance module is enabled)
- Important notifications and alerts

### Member Management

The "Members" section allows you to:
- View the complete member list
- Add new members
- Manage profiles, grades and licenses
- Track membership renewals
- Handle membership requests
- Organize members by groups and disciplines

### Competition Management

The "Competitions" section allows you to:
- Create and organize competitions
- Manage member registrations for external competitions
- Track results and performances
- Plan the competitive calendar
- Manage travel and logistics

### Training Management

The "Training" section allows you to:
- Schedule training sessions
- Assign coaches to sessions
- Track member attendance
- Manage facilities and equipment
- Create personalized training programs

### Administration

The "Administration" section allows you to:
- Manage club information (contact details, logo, etc.)
- Configure user roles and permissions
- Manage federation affiliations
- Administer club finances
- Access reports and statistics

## Additional Features

### Communication

Tools for communicating with members:
- Send group messages
- Create announcements
- Manage notifications
- Share documents

### Events

Club event management:
- Internal competitions
- Workshops and training courses
- Grade examinations
- Demonstrations and open days

### Finances

If the Finance module is enabled:
- Membership fee tracking
- Invoice and payment management
- Financial reports
- Budget forecasting

### Qualifications and Certifications

Management of member and staff qualifications:
- Grade tracking and progression
- Teaching diploma management
- Refereeing certifications
- Continuing education

## Customization

Administrators can customize the dashboard to meet the club's specific needs:
1. Configuration of visible modules
2. Adaptation of forms and fields
3. Report customization
4. Notification settings adjustment

## Integration with Other Modules

The Club Dashboard integrates with other MartialComp components:
- Grade management module
- Competition scoring system
- Online shop (if enabled)
- Communication system

## Technical Support

If you encounter difficulties with your dashboard:
1. See the detailed documentation in the user guide
2. Use the "Help" function accessible from the main menu
3. Contact technical support via the dedicated form
