# لوحة تحكم النادي

## مقدمة

لوحة تحكم النادي مصممة لمديري ومسؤولي أندية فنون القتال. توفر هذه الواجهة المركزية إدارة الأعضاء والمسابقات والتدريبات والإدارة العامة للنادي.

## الوصول إلى لوحة التحكم

للوصول إلى لوحة تحكم النادي:
1. سجّل الدخول إلى حسابك على MartialComp
2. إذا كان ملفك الشخصي مُعدّاً بدور "club_manager"، سيتم توجيهك تلقائياً إلى هذه اللوحة
3. وإلا، يمكنك الوصول عبر الرابط `/dashboard/club/`

## الوظائف الرئيسية

### نظرة عامة

تعرض الصفحة الرئيسية للوحة تحكم النادي:
- العدد الإجمالي للأعضاء النشطين
- توزيع الأعضاء حسب التخصص والفئة
- المسابقات المستقبلية المنظمة أو المتعلقة بالنادي
- الأداء الأخير للأعضاء
- الإحصائيات المالية (إذا كان نظام المالية مُفعّلاً)
- الإشعارات والتنبيهات المهمة

### إدارة الأعضاء

قسم "الأعضاء" يتيح:
- الاطلاع على القائمة الكاملة للأعضاء
- إضافة أعضاء جدد
- إدارة الملفات الشخصية والدرجات والرخص
- متابعة تجديدات العضوية
- إدارة طلبات الانضمام
- تنظيم الأعضاء حسب المجموعات والتخصصات

### إدارة المسابقات

قسم "المسابقات" يتيح:
- إنشاء وتنظيم المسابقات
- إدارة تسجيلات الأعضاء في المسابقات الخارجية
- متابعة النتائج والأداء
- تخطيط التقويم التنافسي
- إدارة التنقلات واللوجستيات

### إدارة التدريبات

قسم "التدريبات" يتيح:
- تخطيط حصص التدريب
- تعيين المدربين للحصص
- متابعة حضور الأعضاء
- إدارة المرافق والمعدات
- إنشاء برامج تدريبية مخصصة

### الإدارة

قسم "الإدارة" يتيح:
- إدارة معلومات النادي (بيانات الاتصال، الشعار، إلخ.)
- إعداد الأدوار والأذونات للمستخدمين
- إدارة الانتسابات للاتحادات
- إدارة مالية النادي
- الوصول إلى التقارير والإحصائيات

## وظائف إضافية

### التواصل

أدوات للتواصل مع الأعضاء:
- إرسال رسائل جماعية
- إنشاء إعلانات
- إدارة الإشعارات
- مشاركة المستندات

### الأحداث

إدارة أحداث النادي:
- مسابقات داخلية
- معسكرات وتدريبات
- امتحانات الدرجات
- عروض وأبواب مفتوحة

### المالية

إذا كان نظام المالية مُفعّلاً:
- متابعة الاشتراكات
- إدارة الفواتير والمدفوعات
- تقارير مالية
- ميزانية تقديرية

### المؤهلات والشهادات

إدارة مؤهلات الأعضاء والطاقم:
- متابعة الدرجات والتقدم
- إدارة شهادات التدريس
- شهادات التحكيم
- التكوين المستمر

## التخصيص

يمكن للمسؤولين تخصيص لوحة التحكم حسب احتياجات النادي:
1. إعداد الوحدات المرئية
2. تكييف النماذج والحقول
3. تخصيص التقارير
4. ضبط إعدادات الإشعارات

## التكامل مع الوحدات الأخرى

تتكامل لوحة تحكم النادي مع مكونات MartialComp الأخرى:
- نظام إدارة الدرجات
- نظام التقييم للمسابقات
- المتجر الإلكتروني (إذا كان مُفعّلاً)
- نظام التواصل

## الدعم التقني

في حالة وجود صعوبة مع لوحة التحكم:
1. راجع الوثائق التفصيلية في دليل الاستخدام
2. استخدم وظيفة "المساعدة" المتاحة من القائمة الرئيسية
3. تواصل مع الدعم التقني عبر النموذج المخصص
