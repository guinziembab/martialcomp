# Panel de Combate

## Introducción

El Panel de Combate es una interfaz especializada diseñada para la gestión y el seguimiento de competiciones de combate en artes marciales. Esta plataforma permite organizar, arbitrar y analizar los combates con precisión, ofreciendo funcionalidades adaptadas a las diferentes disciplinas de combate (Taekwondo, Karate, Judo, etc.).

## Acceso al Panel

Para acceder al panel de combate:
1. Inicie sesión en su cuenta MartialComp
2. Acceda al panel a través de la URL `/dashboard/combat/`
3. O seleccione "Modo Combate" desde el menú principal si tiene los permisos apropiados

## Funcionalidades Principales

### Vista General

La página principal del panel de combate muestra:
- Competiciones de combate en curso y próximas
- Estado de las áreas de combate
- Progresión de las categorías
- Estadísticas del día (combates terminados, en curso, próximos)
- Alertas importantes (retrasos, modificaciones, incidentes)

### Configuración de Competiciones

La sección "Configuración" permite:
- Definir los parámetros generales de la competición de combate
- Configurar las reglas específicas por disciplina
- Establecer los tiempos de combate, pausas y prórrogas
- Definir el sistema de puntos y penalizaciones
- Configurar los criterios de victoria
- Establecer el sistema de repesca o eliminación directa

### Gestión de Combatientes

La sección "Combatientes" permite:
- Consultar la lista de participantes por categoría
- Verificar las inscripciones y pesajes
- Visualizar las fichas de los combatientes (historial, club, grado)
- Gestionar las retiradas y sustituciones
- Seguir el recorrido de cada combatiente en la competición

### Planificación de Combates

La sección "Planificación" permite:
- Generar automáticamente los cuadros de combate
- Equilibrar la distribución entre las áreas
- Definir el orden de las categorías y combates
- Gestionar los horarios y el timing
- Ajustar la programación en tiempo real según los retrasos
- Visualizar el avance global de la competición

### Interfaz de Arbitraje

La sección "Arbitraje" ofrece interfaces adaptadas a cada disciplina:
- Sistema de conteo de puntos en tiempo real
- Gestión de penalizaciones y advertencias
- Cronometraje preciso con controles (inicio, pausa, reanudación)
- Registro de las técnicas utilizadas
- Gestión de las intervenciones médicas
- Interfaz para las decisiones arbitrales
- Sistema de vídeo-replay (si disponible)

### Visualización Pública

El módulo "Visualización" permite gestionar las pantallas destinadas:
- Al público (resultados, combates en curso, programa)
- A los entrenadores (planificación, llamada de combatientes)
- A los combatientes (preparación, orden de paso)
- A la organización (vista global, estadísticas)

## Funcionalidades Específicas por Disciplina

### Taekwondo

Interfaz adaptada con:
- Sistema de puntuación electrónico
- Gestión de protecciones electrónicas
- Seguimiento de las zonas de golpe
- Integración con los sistemas KPNP/Daedo/Adidas

### Karate

Interfaz específica para:
- Puntuación Ippon/Waza-ari/Yuko
- Gestión de Hansoku y Shikkaku
- Sistema adaptado al Shobu Ippon o a puntos

### Judo

Interfaz dedicada para:
- Puntuación de Ippon, Waza-ari
- Gestión de las inmovilizaciones con cronómetro
- Seguimiento de penalizaciones Shido/Hansoku-make

### Deportes de Combate Mixtos

Sistema adaptable para:
- Boxeo (sistema de puntos o KO)
- MMA (sumisiones, TKO, decisiones)
- Lucha (derribos, puntos técnicos)

## Funcionalidades Analíticas

### Estadísticas en Tiempo Real

Durante la competición:
- Número de combates terminados/restantes
- Duración media de los combates
- Distribución de victorias (puntos, KO, retirada)
- Distribución de penalizaciones
- Técnicas más utilizadas

### Análisis Post-competición

Después del evento:
- Informe completo de la competición
- Análisis de rendimiento por club
- Estadísticas detalladas por categoría
- Identificación de tendencias técnicas
- Comparación con competiciones anteriores

### Seguimiento de Atletas

Para el desarrollo a largo plazo:
- Historial completo de combates
- Análisis de fortalezas y debilidades
- Evolución del rendimiento
- Estadísticas personalizadas
- Recomendaciones de entrenamiento

## Seguridad y Médico

### Seguimiento Médico

Funcionalidades para el equipo médico:
- Registro de intervenciones
- Seguimiento de lesiones
- Gestión de suspensiones médicas
- Comunicación con los árbitros
- Informes de incidentes

### Protocolos de Seguridad

Herramientas para garantizar la seguridad de los combatientes:
- Verificación del equipamiento de protección
- Control de los tiempos de recuperación
- Alertas en caso de golpes peligrosos repetidos
- Gestión de las paradas de combate
- Documentación de incidentes

## Personalización e Integración

El panel de combate es altamente personalizable:
- Adaptación a los reglamentos específicos de cada federación
- Configuración de las interfaces según las preferencias
- Integración con sistemas externos (puntuación electrónica)
- Compatibilidad con equipamiento especializado
- Exportación de datos hacia los sistemas federales

## Soporte Técnico

En caso de dificultad durante una competición:
- Soporte prioritario disponible
- Guía de resolución rápida de problemas
- Procedimientos de emergencia para problemas técnicos
- Modo sin conexión en caso de pérdida de conexión
- Herramientas de recuperación de datos
