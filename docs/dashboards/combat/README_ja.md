# 試合ダッシュボード

## はじめに

試合ダッシュボードは、武道における組手・試合競技の管理と運営のために設計された専門インターフェースです。このプラットフォームにより、各種格闘系武道（テコンドー、空手、柔道など）に対応した機能を提供しながら、試合の編成、審判、分析を正確に行うことができます。

## ダッシュボードへのアクセス

試合ダッシュボードにアクセスするには：
1. MartialCompアカウントにログインしてください
2. URL `/dashboard/combat/` からダッシュボードにアクセスしてください
3. または、適切な権限をお持ちの場合、メインメニューから「試合モード」を選択してください

## 主な機能

### 概要

試合ダッシュボードのメインページには以下が表示されます：
- 開催中および今後の試合競技
- 試合場の状態
- カテゴリーの進行状況
- 当日の統計（完了済み、進行中、予定の試合数）
- 重要なアラート（遅延、変更、インシデント）

### 競技会の設定

「設定」セクションでは以下が可能です：
- 試合競技の一般パラメータの設定
- 種目別の固有ルールの設定
- 試合時間、休憩、延長の設定
- ポイントシステムとペナルティの設定
- 勝利条件の設定
- 敗者復活戦またはトーナメント方式の設定

### 選手管理

「選手」セクションでは以下が可能です：
- カテゴリー別の参加者リストの確認
- 登録および計量の確認
- 選手情報（戦績、所属道場、段級位）の閲覧
- 棄権および補欠選手の管理
- 各選手の競技内での戦績追跡

### 試合の計画

「計画」セクションでは以下が可能です：
- トーナメント表の自動生成
- 試合場間の均等な配分
- カテゴリーおよび試合の順序設定
- スケジュールとタイミングの管理
- 遅延に応じたリアルタイムでの進行表調整
- 競技全体の進捗状況の確認

### 審判インターフェース

「審判」セクションでは、各種目に対応したインターフェースを提供します：
- リアルタイムのポイント計数システム
- ペナルティおよび警告の管理
- 精密な計時機能（開始、一時停止、再開）
- 使用された技の記録
- メディカル介入の管理
- 審判判定用インターフェース
- ビデオリプレイシステム（利用可能な場合）

### 公開表示

「表示」モジュールでは、以下の対象向けの画面を管理できます：
- 観客向け（結果、進行中の試合、プログラム）
- コーチ向け（計画、選手の招集）
- 選手向け（準備、出場順）
- 運営向け（全体ビュー、統計）

## 種目別の固有機能

### テコンドー

以下に対応した専用インターフェース：
- 電子スコアリングシステム
- 電子防具の管理
- 打撃ゾーンの追跡
- KPNP/Daedo/Adidasシステムとの連携

### 空手

以下に対応した専用インターフェース：
- Ippon/Waza-ari/Yuko判定
- Hansoku（反則）およびShikkaku（失格）の管理
- Shobu Ippon方式またはポイント方式に対応

### 柔道

以下に対応した専用インターフェース：
- Ippon、Waza-ariの判定
- タイマー付きの抑え込み管理
- Shido/Hansoku-makeペナルティの追跡

### 総合格闘技

以下に対応した柔軟なシステム：
- ボクシング（ポイント制またはKO）
- MMA（サブミッション、TKO、判定）
- レスリング（フォール、テクニカルポイント）

## 分析機能

### リアルタイム統計

競技中：
- 完了済み/残りの試合数
- 平均試合時間
- 勝利の分布（ポイント、KO、棄権）
- ペナルティの分布
- 最も多く使用された技

### 競技後の分析

大会終了後：
- 競技会の完全レポート
- 道場別のパフォーマンス分析
- カテゴリー別の詳細統計
- 技術的傾向の特定
- 過去の大会との比較

### 選手の追跡

長期的な育成のために：
- 全試合の完全な履歴
- 強みと弱みの分析
- パフォーマンスの推移
- カスタム統計
- トレーニングに関する推奨事項

## 安全管理と医療

### 医療管理

医療チーム向け機能：
- 介入の記録
- 負傷の追跡
- 医療的な出場停止の管理
- 審判との連絡
- インシデント報告

### 安全プロトコル

選手の安全を確保するためのツール：
- 防具の確認
- 回復時間の管理
- 危険な打撃が繰り返された場合のアラート
- 試合中止の管理
- インシデントの記録

## カスタマイズと連携

試合ダッシュボードは高いカスタマイズ性を備えています：
- 各連盟の固有規則への対応
- 好みに応じたインターフェースの設定
- 外部システム（電子スコアリング）との連携
- 専用機器との互換性
- 連盟システムへのデータエクスポート

## テクニカルサポート

競技中に問題が発生した場合：
- 優先サポートが利用可能
- クイックトラブルシューティングガイド
- 技術的な問題発生時の緊急対応手順
- 接続が失われた場合のオフラインモード
- データ復旧ツール
