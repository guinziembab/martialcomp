# Painel de Combate

## Introdução

O painel de controlo de Combate é uma interface especializada concebida para a gestão e o acompanhamento de competições de combate nas artes marciais. Esta plataforma permite organizar, arbitrar e analisar os combates com precisão, oferecendo funcionalidades adaptadas às diferentes disciplinas de combate (Taekwondo, Karaté, Judo, etc.).

## Acesso ao Painel

Para aceder ao painel de combate:
1. Inicie sessão na sua conta MartialComp
2. Aceda ao painel através do URL `/dashboard/combat/`
3. Ou selecione "Modo Combate" a partir do menu principal se tiver as permissões adequadas

## Funcionalidades Principais

### Vista Geral

A página principal do painel de combate apresenta:
- Competições de combate em curso e futuras
- Estado das áreas de combate
- Progressão das categorias
- Estatísticas do dia (combates terminados, em curso, futuros)
- Alertas importantes (atrasos, alterações, incidentes)

### Configuração das Competições

A secção "Configuração" permite:
- Definir os parâmetros gerais da competição de combate
- Configurar as regras específicas por disciplina
- Parametrizar os tempos de combate, pausas e prolongamentos
- Definir o sistema de pontos e penalizações
- Configurar os critérios de vitória
- Implementar o sistema de repescagem ou eliminação direta

### Gestão dos Combatentes

A secção "Combatentes" permite:
- Consultar a lista dos participantes por categoria
- Verificar as inscrições e pesagens
- Visualizar as fichas dos combatentes (histórico, clube, graduação)
- Gerir as desistências e substituições
- Acompanhar o percurso de cada combatente na competição

### Planeamento dos Combates

A secção "Planeamento" permite:
- Gerar automaticamente os quadros de combate
- Equilibrar a distribuição entre as áreas
- Definir a ordem das categorias e dos combates
- Gerir os horários e o timing
- Ajustar o planeamento em tempo real em função dos atrasos
- Visualizar o avanço global da competição

### Interface de Arbitragem

A secção "Arbitragem" oferece interfaces adaptadas a cada disciplina:
- Sistema de contagem de pontos em tempo real
- Gestão de penalizações e advertências
- Cronometragem precisa com controlos (iniciar, pausa, retomar)
- Registo das técnicas utilizadas
- Gestão das intervenções médicas
- Interface para decisões de arbitragem
- Sistema de vídeo-replay (se disponível)

### Apresentação Pública

O módulo "Apresentação" permite gerir os ecrãs destinados:
- Ao público (resultados, combates em curso, programa)
- Aos treinadores (planeamento, chamada dos combatentes)
- Aos combatentes (preparação, ordem de passagem)
- À organização (vista global, estatísticas)

## Funcionalidades Específicas por Disciplina

### Taekwondo

Interface adaptada com:
- Sistema de scoring eletrónico
- Gestão das proteções eletrónicas
- Acompanhamento das zonas de impacto
- Integração com os sistemas KPNP/Daedo/Adidas

### Karaté

Interface específica para:
- Avaliação Ippon/Waza-ari/Yuko
- Gestão dos Hansoku e Shikkaku
- Sistema adaptado ao Shobu Ippon ou aos pontos

### Judo

Interface dedicada para:
- Avaliação dos Ippon, Waza-ari
- Gestão das imobilizações com cronómetro
- Acompanhamento das penalizações Shido/Hansoku-make

### Desportos de Combate Mistos

Sistema adaptável para:
- Boxe (sistema de pontos ou KO)
- MMA (submissões, TKO, decisões)
- Luta (quedas, pontos técnicos)

## Funcionalidades Analíticas

### Estatísticas em Tempo Real

Durante a competição:
- Número de combates terminados/restantes
- Tempo médio dos combates
- Distribuição das vitórias (pontos, KO, desistência)
- Distribuição das penalizações
- Técnicas mais utilizadas

### Análise Pós-competição

Após o evento:
- Relatório completo da competição
- Análise dos desempenhos por clube
- Estatísticas detalhadas por categoria
- Identificação de tendências técnicas
- Comparação com competições anteriores

### Acompanhamento dos Atletas

Para o desenvolvimento a longo prazo:
- Histórico completo dos combates
- Análise das forças e fraquezas
- Evolução dos desempenhos
- Estatísticas personalizadas
- Recomendações de treino

## Segurança e Medicina

### Acompanhamento Médico

Funcionalidades para a equipa médica:
- Registo das intervenções
- Acompanhamento das lesões
- Gestão das suspensões médicas
- Comunicação com os árbitros
- Relatórios de incidentes

### Protocolos de Segurança

Ferramentas para garantir a segurança dos combatentes:
- Verificação dos equipamentos de proteção
- Controlo dos tempos de recuperação
- Alertas em caso de golpes perigosos repetidos
- Gestão das paragens de combate
- Documentação dos incidentes

## Personalização e Integração

O painel de combate é altamente personalizável:
- Adaptação aos regulamentos específicos de cada federação
- Configuração das interfaces segundo as preferências
- Integração com sistemas externos (scoring eletrónico)
- Compatibilidade com equipamentos especializados
- Exportação de dados para os sistemas federativos

## Suporte Técnico

Em caso de dificuldade durante uma competição:
- Suporte prioritário disponível
- Guia de resolução rápida de problemas
- Procedimentos de emergência em caso de problema técnico
- Modo offline em caso de perda de ligação
- Ferramentas de recuperação de dados
