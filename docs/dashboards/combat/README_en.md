# Combat Dashboard

## Introduction

The Combat Dashboard is a specialized interface designed for managing and tracking combat competitions in martial arts. This platform allows organizing, officiating, and analyzing fights with precision, while offering features adapted to different combat disciplines (Taekwondo, Karate, Judo, etc.).

## Accessing the Dashboard

To access the combat dashboard:
1. Log in to your MartialComp account
2. Access the dashboard via the URL `/dashboard/combat/`
3. Or select "Combat Mode" from the main menu if you have the appropriate permissions

## Main Features

### Overview

The main page of the combat dashboard displays:
- Current and upcoming combat competitions
- Status of combat areas
- Category progression
- Daily statistics (completed fights, in progress, upcoming)
- Important alerts (delays, changes, incidents)

### Competition Configuration

The "Configuration" section allows you to:
- Define the general parameters of the combat competition
- Configure discipline-specific rules
- Set fight durations, breaks, and extensions
- Define the point and penalty system
- Configure victory criteria
- Set up the repechage or direct elimination system

### Fighter Management

The "Fighters" section allows you to:
- View the list of participants by category
- Verify registrations and weigh-ins
- View fighter profiles (history, club, grade)
- Manage forfeits and replacements
- Track each fighter's progress through the competition

### Fight Planning

The "Planning" section allows you to:
- Automatically generate fight brackets
- Balance distribution across areas
- Define the order of categories and fights
- Manage schedules and timing
- Adjust the schedule in real time based on delays
- Visualize overall competition progress

### Officiating Interface

The "Officiating" section offers interfaces adapted to each discipline:
- Real-time point counting system
- Penalty and warning management
- Precise timing with controls (start, pause, resume)
- Recording of techniques used
- Medical intervention management
- Interface for referee decisions
- Video replay system (if available)

### Public Display

The "Display" module manages screens for:
- The public (results, current fights, schedule)
- Coaches (planning, fighter calls)
- Fighters (preparation, order of appearance)
- Organization (global view, statistics)

## Discipline-Specific Features

### Taekwondo

Adapted interface with:
- Electronic scoring system
- Electronic protector management
- Strike zone tracking
- Integration with KPNP/Daedo/Adidas systems

### Karate

Specific interface for:
- Ippon/Waza-ari/Yuko scoring
- Hansoku and Shikkaku management
- System adapted to Shobu Ippon or points

### Judo

Dedicated interface for:
- Ippon, Waza-ari scoring
- Immobilization management with timer
- Shido/Hansoku-make penalty tracking

### Mixed Combat Sports

Adaptable system for:
- Boxing (point system or KO)
- MMA (submissions, TKO, decisions)
- Wrestling (falls, technical points)

## Analytical Features

### Real-Time Statistics

During the competition:
- Number of completed/remaining fights
- Average fight duration
- Victory distribution (points, KO, forfeit)
- Penalty distribution
- Most used techniques

### Post-Competition Analysis

After the event:
- Complete competition report
- Performance analysis by club
- Detailed statistics by category
- Identification of technical trends
- Comparison with previous competitions

### Athlete Tracking

For long-term development:
- Complete fight history
- Strengths and weaknesses analysis
- Performance evolution
- Personalized statistics
- Training recommendations
