# Dasibodu Ija

## Ifaara

Dasibodu Ija jẹ atọka amọja ti a ṣe apẹrẹ fun isakoso ati itọpinpin awọn idije ija ni ere idaraya ologun. Iru ẹrọ yii jẹ ki o ṣeto, ṣe idajọ ati ṣe itupalẹ awọn ija pẹlu pipe, lakoko ti o n pese awọn iṣẹ ti a ṣe deede si awọn ẹkọ ija oriṣiriṣi (Taekwondo, Karate, Judo, ati bẹbẹ lọ).

## Iwọle si Dasibodu

Lati wọle si dasibodu ija:
1. Wọle si akọọlẹ MartialComp rẹ
2. Wọle si dasibodu nipasẹ URL `/dashboard/combat/`
3. Tabi yan "Ipo Ija" lati akojọ akọkọ ti o ba ni awọn igbanilaaye ti o yẹ

## Awọn Iṣẹ Akọkọ

### Akopọ

Oju-iwe akọkọ dasibodu ija fi wọnyi han:
- Awọn idije ija ti n lọ lọwọ ati ti n bọ
- Ipo awọn aaye ija
- Ilọsiwaju awọn ẹka
- Awọn iṣiro ọjọ naa (awọn ija ti pari, ti n lọ lọwọ, ti n bọ)
- Awọn itaniji pataki (awọn idaduro, awọn iyipada, awọn iṣẹlẹ)

### Tunto Awọn Idije

Apakan "Tunto" jẹ ki o:
- Ṣe alaye awọn eto gbogbogbo ti idije ija
- Ṣeto awọn ofin kan pato nipa ẹkọ
- Ṣe eto awọn akoko ija, awọn isinmi ati awọn akoko afikun
- Ṣe alaye eto awọn aaye ati awọn ijiya
- Ṣeto awọn ilana iṣẹgun
- Fi idi eto atunṣe tabi iparun taara mulẹ

### Isakoso Awọn Ojagun

Apakan "Awọn Ojagun" jẹ ki o:
- Wo akojọ awọn olukopa nipa ẹka
- Ṣayẹwo awọn iforukọsilẹ ati awọn iwọn
- Ri awọn kaadi ojagun (itan, ẹgbẹ, ipele)
- Ṣakoso awọn afẹyinti ati awọn aropo
- Tẹle irin-ajo ojagun kọọkan ninu idije naa

### Igbero Awọn Ija

Apakan "Igbero" jẹ ki o:
- Ṣẹda awọn tabili ija laifọwọyi
- Ṣe iwọntunwọnsi pinpin laarin awọn aaye
- Ṣe alaye ilana awọn ẹka ati awọn ija
- Ṣakoso awọn akoko ati eto akoko
- Ṣatunṣe eto ni akoko gidi ni ibamu pẹlu awọn idaduro
- Ri ilọsiwaju gbogbogbo idije naa

### Atọka Idajọ

Apakan "Idajọ" n pese awọn atọka ti a ṣe deede si ẹkọ kọọkan:
- Eto kika awọn aaye ni akoko gidi
- Isakoso awọn ijiya ati awọn ikilọ
- Iṣiro akoko pipe pẹlu awọn iṣakoso (bẹrẹ, duro, tun bẹrẹ)
- Iforukọsilẹ awọn imọ-ẹrọ ti a lo
- Isakoso awọn idasi ilera
- Atọka fun awọn ipinnu adajo
- Eto atunwo fidio (ti o ba wa)

### Ifihan Gbangba

Apa "Ifihan" jẹ ki o ṣakoso awọn iboju ti a pinnu fun:
- Awọn oluwo (awọn abajade, awọn ija ti n lọ lọwọ, eto)
- Awọn olukọni (igbero, ipe awọn ojagun)
- Awọn ojagun (imurasilẹ, ilana ọna kọja)
- Ẹgbẹ ṣiṣeto (wiwo gbogbogbo, awọn iṣiro)

## Awọn Iṣẹ Kan Pato Nipa Ẹkọ

### Taekwondo

Atọka ti a ṣe deede pẹlu:
- Eto isiro itanna
- Isakoso awọn aabo itanna
- Itọpinpin awọn agbegbe ikọlu
- Isọpọ pẹlu awọn eto KPNP/Daedo/Adidas

### Karate

Atọka kan pato fun:
- Isiro Ippon/Waza-ari/Yuko
- Isakoso awọn Hansoku ati Shikkaku
- Eto ti a ṣe deede si Shobu Ippon tabi nipa aaye

### Judo

Atọka ti a yan si fun:
- Isiro awọn Ippon, Waza-ari
- Isakoso awọn idaduro pẹlu aago akoko
- Itọpinpin awọn ijiya Shido/Hansoku-make

### Awọn Ere Ija Idapọ

Eto ti a le ṣe deede fun:
- Afẹṣẹja (eto aaye tabi KO)
- MMA (igbowo, TKO, awọn ipinnu)
- Ijakadi (isubu, awọn aaye imọ-ẹrọ)

## Awọn Iṣẹ Itupalẹ

### Awọn Iṣiro Ni Akoko Gidi

Lakoko idije:
- Nọmba awọn ija ti pari/ti o ku
- Akoko aarin awọn ija
- Pinpin awọn iṣẹgun (awọn aaye, KO, afẹyinti)
- Pinpin awọn ijiya
- Awọn imọ-ẹrọ ti a lo julọ

### Itupalẹ Lẹyin Idije

Lẹyin iṣẹlẹ naa:
- Ijabọ pipe idije naa
- Itupalẹ awọn isise nipa ẹgbẹ
- Awọn iṣiro alaye nipa ẹka
- Idanimọ awọn aṣa imọ-ẹrọ
- Afiwe pẹlu awọn idije ti tẹlẹ

### Itọpinpin Awọn Elere-ije

Fun idagbasoke igba pipẹ:
- Itan pipe awọn ija
- Itupalẹ awọn aaye ti o lagbara ati awọn ailera
- Iyipada awọn isise
- Awọn iṣiro ti ara ẹni
- Awọn igbaniyanju ikẹkọ

## Aabo ati Ilera

### Itọpinpin Ilera

Awọn iṣẹ fun ẹgbẹ ilera:
- Iforukọsilẹ awọn idasi
- Itọpinpin awọn ipalara
- Isakoso awọn idaduro ilera
- Ibasọrọ pẹlu awọn adajo
- Awọn ijabọ awọn iṣẹlẹ

### Awọn Ilana Aabo

Awọn irinṣẹ lati rii daju aabo awọn ojagun:
- Ṣayẹwo awọn ohun elo aabo
- Iṣakoso awọn akoko isinmi
- Awọn itaniji ni ọran ikọlu eewu leralera
- Isakoso awọn iduro ija
- Iwe akọsilẹ awọn iṣẹlẹ

## Aṣayan ati Isọpọ

Dasibodu ija le ṣe aṣayan pupọ:
- Atunṣe si awọn ofin kan pato ti ajọ agbaye kọọkan
- Tunto awọn atọka gẹgẹ bi awọn ayanfẹ
- Isọpọ pẹlu awọn eto ita (isiro itanna)
- Ibamu pẹlu awọn ohun elo amọja
- Okeere awọn data si awọn eto ajọ agbaye

## Atilẹyin Imọ-ẹrọ

Ni ọran iṣoro lakoko idije:
- Atilẹyin pataki wa
- Itọsọna atunṣe iyara
- Awọn ilana pajawiri ni ọran iṣoro imọ-ẹrọ
- Ipo aisiasopọ ni ọran ipadanu asopọ
- Awọn irinṣẹ igbapada data
