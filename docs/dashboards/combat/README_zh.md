# 对抗赛控制面板

## 简介

对抗赛控制面板是一个专为武术搏击比赛管理和跟踪而设计的专业界面。该平台可精确地组织、裁判和分析比赛，同时提供适配不同搏击项目（跆拳道、空手道、柔道等）的功能。

## 访问控制面板

访问对抗赛控制面板的方法：
1. 登录您的 MartialComp 账户
2. 通过 URL `/dashboard/combat/` 进入对抗赛控制面板
3. 或在拥有相应权限的情况下，从主菜单中选择"对抗赛模式"

## 主要功能

### 总览

对抗赛控制面板的主页面展示：
- 正在进行和即将举行的搏击比赛
- 比赛场地状态
- 各组别进度
- 当日统计数据（已完成、进行中、待进行的比赛场次）
- 重要警报（延迟、变更、突发事件）

### 赛事配置

"配置"板块可用于：
- 设定搏击赛事的通用参数
- 配置各项目的专属规则
- 设置比赛时间、休息时间和加时赛
- 设定计分和罚则体系
- 配置胜利判定标准
- 建立复活赛或直接淘汰赛机制

### 选手管理

"选手"板块可用于：
- 按组别查看参赛人员列表
- 核验报名信息和称重记录
- 查看选手档案（比赛记录、所属俱乐部、段位等级）
- 处理弃权与替补事宜
- 跟踪每位选手的赛事进程

### 赛程编排

"赛程编排"板块可用于：
- 自动生成对阵表
- 均衡分配各比赛场地的赛事
- 确定组别和比赛场次的顺序
- 管理时间安排和节奏
- 根据延迟情况实时调整赛程
- 查看赛事整体进度

### 裁判界面

"裁判"板块提供适配各项目的界面：
- 实时计分系统
- 处罚和警告管理
- 精确计时控制（开始、暂停、恢复）
- 技术动作记录
- 医疗干预管理
- 裁判判罚界面
- 视频回放系统（如配备）

### 公共显示

"显示"模块可管理面向不同对象的屏幕：
- 观众（比赛结果、当前比赛、赛程安排）
- 教练（赛程安排、选手点名）
- 选手（赛前准备、出场顺序）
- 赛事组织方（全局视图、统计数据）

## 各项目专属功能

### 跆拳道

适配界面包括：
- 电子计分系统
- 电子护具管理
- 击打区域追踪
- 与 KPNP/Daedo/Adidas 系统集成

### 空手道

专属界面用于：
- Ippon/Waza-ari/Yuko 评分
- Hansoku 和 Shikkaku 处理
- 适配 Shobu Ippon 或计分制

### 柔道

专属界面用于：
- Ippon、Waza-ari 评分
- 带计时器的压制技术管理
- Shido/Hansoku-make 罚则跟踪

### 综合格斗项目

可适配的系统包括：
- 拳击（计分制或 KO 制）
- MMA（降服、TKO、判定）
- 摔跤（摔倒、技术得分）

## 数据分析功能

### 实时统计

赛事进行期间：
- 已完成/剩余比赛场次
- 比赛平均时长
- 胜利方式分布（计分、KO、弃权）
- 罚则分布情况
- 最常用技术动作

### 赛后分析

赛事结束后：
- 完整赛事报告
- 按俱乐部的成绩分析
- 按组别的详细统计
- 技术趋势识别
- 与往届赛事对比

### 运动员追踪

用于长期发展：
- 完整比赛记录
- 优势和劣势分析
- 成绩变化趋势
- 个性化统计数据
- 训练建议

## 安全与医疗

### 医疗跟踪

为医疗团队提供的功能：
- 干预记录
- 伤病跟踪
- 医疗停赛管理
- 与裁判的沟通
- 事故报告

### 安全规程

保障选手安全的工具：
- 护具检查
- 恢复时间监控
- 反复危险击打预警
- 比赛中止管理
- 事故记录

## 自定义与集成

对抗赛控制面板具有高度可定制性：
- 适配各联合会的专属规则
- 根据偏好配置界面
- 与外部系统集成（电子计分）
- 兼容专业设备
- 向联合会系统导出数据

## 技术支持

比赛期间遇到困难时：
- 提供优先支持服务
- 快速故障排除指南
- 技术故障应急预案
- 断网时的离线模式
- 数据恢复工具
