# የMartialComp ዳሽቦርዶች

## መግቢያ

ይህ ማውጫ በMartialComp መተግበሪያ ውስጥ የሚገኙ የተለያዩ ዳሽቦርዶች (dashboards) ሙሉ ሰነድ ይዟል። እያንዳንዱ የተጠቃሚ ዓይነት ለሚያስፈልገው ሚና የተዘጋጀ ዳሽቦርድ ያለው ሲሆን ለፍላጎቱ የተስማሙ ተግባራት ይሰጣል።

## የዳሽቦርድ ዓይነቶች

MartialComp ለእያንዳንዱ ሚና የተዘጋጁ በርካታ ዳሽቦርዶች ያቀርባል፦

1. [**የተሳታፊ ዳሽቦርድ**](./participants/README.md) - በውድድሮች ለሚሳተፉ የማርሻል ስፖርት ተለማማጆች
2. [**የክለብ ዳሽቦርድ**](./clubs/README.md) - ለክለብ አስተዳዳሪዎችና ሥራ አስኪያጆች
3. [**የፌዴሬሽን ዳሽቦርድ**](./federations/README.md) - ለፌዴሬሽን አስተዳዳሪዎች
4. [**የዳኛ/ሪፈሪ ዳሽቦርድ**](./referees/README.md) - ውድድሮችን ለሚያስተናግዱና ለሚገመግሙ ዳኞች
5. [**የብዙ-ዲሲፕሊን አሰልጣኝ ዳሽቦርድ**](./coaches/README.md) - ብዙ ዲሲፕሊኖችን ለሚያስተዳድሩ አሰልጣኞች
6. [**የውጊያ ዳሽቦርድ**](./combat/README.md) - ለውጊያ አስተዳደር የተዘጋጀ ልዩ ገጽ

## ወደ ዳሽቦርዶች መድረስ

እያንዳንዱ ተጠቃሚ ከመግባቱ በኋላ ለሚናው ተገቢ ወደሆነው ዳሽቦርድ በራስ-ሰር ይዛወራል። ማዛወሩ በ`competitions/views/dashboard/base.py` ፋይል ውስጥ ባለው `dashboard` ተግባር ይመራል።

## የዳሽቦርዶች ጋራ መዋቅር

ሁሉም ዳሽቦርዶች ጋራ መዋቅር ይጋራሉ፦

- **ራስጌ**፦ የተጠቃሚውን ስም፣ ሚና ያሳያል፣ ወደ ቅንብሮችና ውጣ ያደርሳል
- **የጎን አሞሌ**፦ ወደ ተለያዩ የዳሽቦርድ ክፍሎች ማሰስ
- **ዋና ይዘት**፦ ለእያንዳንዱ ክፍል ልዩ መረጃና ተግባራት ያሳያል
- **ግርጌ**፦ ስለ መተግበሪያው ስሪት መረጃና ጠቃሚ አገናኞች

## ዳሽቦርዶችን ማበጀት

ተጠቃሚዎች የዳሽቦርዳቸውን አንዳንድ ገጽታዎች ማበጀት ይችላሉ፦
- በዋና ገጹ ላይ የሚታዩ ዊጀቶችን መምረጥ
- የመረጃ ማሳያ ቅደም ተከተል
- የማሳወቂያ ምርጫዎች

## ጋራ ተግባራት

ሁሉም ዳሽቦርዶች እነዚህን መሠረታዊ ተግባራት ያቀርባሉ፦
- ቁልፍ ስታቲስቲክስ ያለው አጠቃላይ ዕይታ
- ማሳወቂያዎችና ማንቂያዎች
- የተጠቃሚ ፕሮፋይል አስተዳደር
- የሚመጡ ዝግጅቶች ቀን መቁጠሪያ
- ወደ ሰነድ መድረስ
