# Dasibodu Ajọ Agbaye

## Ifaara

Dasibodu Ajọ Agbaye jẹ atọka pipe ti a se apere fun awon alabojuto ati awon olori awon ajọ agbaye ere idaraya ologun. O n pese awon irinṣẹ alagbara lati sakoso gbogbo awon apakan ajọ agbaye: awon egbe ti o somọ, awon iwe-aṣẹ, awon idije, ikẹkọ, ati diẹ sii.

## Iwọle si Dasibodu

Lati wọle si dasibodu ajọ agbaye:
1. Wọle si akọọlẹ MartialComp rẹ
2. Ti a ba ti se profaili rẹ pẹlu ipa "federation_admin", a o darí ọ lọ si dasibodu yii laifọwọyi
3. Bibẹẹkọ, lo URL `/dashboard/federations/`

## Awon Isise Akọkọ

### Akopọ

Oju-iwe akọkọ dasibodu ajọ agbaye fi wọnyi han:
- Awon iṣiro gbogbogbo (nọmba awon egbe, awon olumulo iwe-aṣẹ, awon idije)
- Pinpin awon olumulo iwe-aṣẹ nipa ẹkọ, ọjọ ori ati akọ/abo
- Kalẹnda awon iṣẹlẹ ti n bọ
- Awon isise aipẹ ati awon iwifunni pataki
- Ipo awon iwe-aṣẹ ati awon ibatan
- Dasibodu owo (ti a ba mu modulu Owo sise)

### Isakoso Awon Egbe

Apakan "Awon Egbe" jẹ ki o:
- Wo akojọ pipe awon egbe ti o somọ
- Sakoso awon ibeere ibatan
- Tẹle awon atuntunse ibatan
- Basọrọ pẹlu awon egbe
- Se itupalẹ awon iṣiro nipa egbe
- Sakoso awon aṣoju ati awon oluṣakoso

### Isakoso Awon Iwe-aṣẹ

Apakan "Awon Iwe-aṣẹ" jẹ ki o:
- Sakoso awon iru iwe-aṣẹ orisirisii
- Se ayẹwo awon ibeere iwe-aṣẹ
- Fun awon iwe-aṣẹ lọkọọkan tabi ni ẹgbẹ
- Tẹle awon atuntunse
- Se awon ijabọ iṣiro
- Ṣayẹwo ọjọ iwe-aṣẹ

### Ṣiṣeto Awon Idije

Apakan "Awon Idije" jẹ ki o:
- Se ati tunto awon idije osise
- Sakoso kalẹnda ajọ agbaye
- Bojuto awon iforukọsilẹ
- Yan awon adajo ati awon onidajo
- Tẹle awon abajade ni akoko gidi
- Gbejade awon ipo osise
- Fọwọsi awon igbasilẹ ati awon isise

### Eto Ipele

Apakan "Awon Ipele" jẹ ki o:
- Se alaye awon eto ipele nipa ẹkọ
- Ṣeto awon igbesoke ipele
- Fọwọsi awon igbesoke
- Sakoso awon dogba
- Pa iwe akọsilẹ osise awon ipele mọ
- Se awon iwe-ẹri ati awon ẹri

### Ikẹkọ ati Iyẹn

Apakan "Ikẹkọ" jẹ ki o:
- Sakoso awon eto ikẹkọ (awon olukọni, awon adajo)
- Ṣeto awon idanileko ati awon apejọ
- Tẹle awon iyẹn awon oṣiṣẹ imọ-ẹrọ
- Sakoso awon iwe-ẹri ati atuntunse wọn
- Gbejade awon ohun elo ikẹkọ

## Awon Isise Afikun

### Ibasọrọ

Awon irinṣẹ fun ibasọrọ pẹlu awon ọmọ ẹgbẹ ati awon egbe:
- Eto awon ikede osise
- Fifi imeeli ti a fojusi ranṣẹ
- Isakoso awon iroyin
- Gbigbejade awon iroyin lori oju opo wẹẹbu ajọ agbaye

### Isakoso Iwe Aṣẹ

Eto pipe isakoso awon iwe aṣẹ ajọ agbaye:
- Awon ofin imọ-ẹrọ
- Awon iwe aṣẹ isakoso
- Awon ipamọ idije
- Awon ohun elo ikẹkọ
- Awon iwe ipade ati awon ipinnu osise

### Modulu Owo

Ti a ba mu modulu Owo sise:
- Isakoso awon owo isanwo awon egbe
- Itọpinpin awon owo oya lati awon iwe-aṣẹ ati awon ibatan
- Awon isuna idije
- Awon ijabọ owo
- Fifi owo-owo pamọ laifọwọyi

### Awon Iṣiro ati Awon Ijabọ

Awon irinṣẹ itupalẹ ilọsiwaju:
- Iyipada nọmba awon ọmọ ẹgbẹ
- Pinpin agbegbe awon olukose
- Itupalẹ awon isise ni idije
- Awon ijabọ ti a le se aṣayan
- Awon dasibodu ti a le kojade

## Isakoso Ilọsiwaju

### Isakoso Awon Olumulo

Awon irinṣẹ fun sakoso awon ipa orisirisii ninu ajọ agbaye:
- Sise awon akọọlẹ isakoso
- Yiyan awon ipa ati awon igbanilaaye
- Fifun aṣẹ nipa agbegbe
- Itọpinpin awon isise awon alabojuto

### Awon Eto Ajọ Agbaye

Tunto pipe profaili ajọ agbaye:
- Alaye gbogbogbo ati awon olubasọrọ
- Aami ati apẹrẹ
- Awon ẹkọ osise
- Awon eto ipele ti a mọ
- Awon ofin idije

### Aṣayan

Awon aṣayan aṣayan dasibodu:
- Awon modulu ti o han ati eto wọn
- Awon ijabọ ati iṣiro ti o jẹ pataki julọ
- Awon itaniji ati awon iwifunni
- Atọka ni awọ ajọ agbaye

## Atilẹyin Imọ-ẹrọ

Ni ọran isoro pẹlu dasibodu rẹ:
1. Wo iwe alaye alaye ninu itọsọna lilo
2. Lo isise "Iranlọwọ" ti o wa lati akojọ akọkọ
3. Kan si atilẹyin imọ-ẹrọ nipase fọọmu ti a yan si

## Aabo ati Ibamu

Dasibodu ajọ agbaye ni awon isise aabo ilọsiwaju:
- Kikọ awon isise isakoso silẹ
- Idaabobo alaye ti ara ẹni (ibamu GDPR)
- Ibi ipamọ alaye laifọwọyi
- Awon ipele iwọle orisirisii gẹgẹ bi awon ipa
