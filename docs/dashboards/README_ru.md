# Панели управления MartialComp

## Введение

Этот каталог содержит полную документацию по различным панелям управления (дашбордам), доступным в приложении MartialComp. Каждый тип пользователя имеет панель управления, специфичную для его роли, с функционалом, адаптированным под его потребности.

## Типы панелей управления

MartialComp предлагает несколько панелей управления, каждая из которых разработана для определённой роли:

1. [**Панель участника**](./participants/README.md) - Для практикующих боевые искусства, участвующих в соревнованиях
2. [**Панель клуба**](./clubs/README.md) - Для менеджеров клубов и их администраторов
3. [**Панель федерации**](./federations/README.md) - Для администраторов федераций
4. [**Панель арбитра/судьи**](./referees/README.md) - Для арбитров и судей, оценивающих соревнования
5. [**Панель мультидисциплинарного тренера**](./coaches/README.md) - Для тренеров, работающих с несколькими дисциплинами
6. [**Панель управления поединками**](./combat/README.md) - Специализированный интерфейс для управления поединками

## Доступ к панелям управления

Каждый пользователь автоматически перенаправляется на панель управления, соответствующую его роли, после входа в систему. Перенаправление управляется представлением `dashboard` в файле `competitions/views/dashboard/base.py`.

## Общая структура панелей управления

Все панели управления имеют общую структуру:

- **Заголовок**: Отображает имя пользователя, роль и предоставляет доступ к настройкам и выходу из системы
- **Боковая панель**: Навигация по различным разделам панели управления
- **Основное содержимое**: Отображает информацию и функции, специфичные для каждого раздела
- **Нижний колонтитул**: Информация о версии приложения и полезные ссылки

## Настройка панелей управления

Пользователи могут настроить некоторые аспекты своей панели управления:
- Выбор виджетов, отображаемых на главной странице
- Порядок отображения информации
- Настройки уведомлений

## Общие функции

Все панели управления предоставляют следующие базовые функции:
- Обзор с ключевыми статистиками
- Уведомления и оповещения
- Управление профилем пользователя
- Календарь предстоящих событий
- Доступ к документации

## Техническое исполнение

Панели управления реализованы с использованием:
- Django для серверной части
- HTML/CSS/JavaScript для клиентской части
- Bootstrap для адаптивной вёрстки
- Технология AJAX для динамических обновлений
