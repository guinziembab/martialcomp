# 選手ダッシュボード

## はじめに

選手ダッシュボードは、MartialCompプラットフォームを通じて開催される大会に参加する武道の練習生のために設計されています。このインターフェースにより、参加者は登録の管理、結果の閲覧、進捗の追跡ができます。

## ダッシュボードへのアクセス

選手ダッシュボードにアクセスするには：
1. MartialCompアカウントにログインします
2. プロフィールが「participant」の役割で設定されている場合、このダッシュボードに自動的にリダイレクトされます
3. それ以外の場合は、URL `/dashboard/participant/` からアクセスしてください

## 主な機能

### 概要

選手ダッシュボードのメインページには以下が表示されます：
- 今後の大会数
- 獲得メダル数
- 総参加回数
- 承認待ちの登録
- 合計スコアと平均スコア
- 種目別統計
- パフォーマンスグラフ

### 大会管理

「大会」セクション（`/dashboard/participant/competitions/`）では以下が可能です：
- 登録済みの今後の大会を確認
- 過去の大会履歴を閲覧
- 保留中の登録状況を追跡
- 新しい大会を発見し登録

### 選手プロフィール

「プロフィール」セクション（`/dashboard/participant/profile/`）では以下が可能です：
- 個人情報の閲覧と編集
- 練習中の種目と関連する段位・級位の確認
- 段位・級位の履歴を閲覧
- プロフィール写真の更新

### 結果

「結果」セクション（`/dashboard/participant/results/`）では以下が可能です：
- すべての大会結果を閲覧
- 大会やカテゴリーで結果をフィルタリング
- 各パフォーマンスの詳細を確認
- 参加証明書や表彰状のダウンロード

## 追加機能

### 通知

通知システムにより、重要なイベントについてお知らせします：
- 登録確認
- 今後の大会のリマインダー
- 結果の発表
- スケジュールの変更

### 稽古の追跡

有効化されている場合、稽古のセッションを追跡できます：
- セッションの総数
- 今月のセッション数
- 今週のセッション数
- 種目別の内訳

### 今後のイベント

登録済みまたは興味のあるイベントのカレンダーです。

### 財務

プラットフォームに関連する金融取引の概要：
- 最近の支払い
- 支払い総額
- 未払いの請求書

### ショップ

ショップモジュールが有効な場合：
- 最近の注文
- 注文状況
- おすすめ商品へのクイックアクセス

### サポート

サポートチケットシステムへのアクセス：
- 新しいチケットの作成
- 既存のチケットの追跡

## カスタマイズ

ダッシュボードをカスタマイズできます：
1. 右上の「設定」アイコンをクリック
2. 「ダッシュボード設定」セクションで表示するウィジェットを選択
3. ドラッグ＆ドロップでウィジェットを並べ替え
4. 設定を保存

## ナビゲーション

サイドバーでダッシュボードの各セクション間を移動できます。メニューアイコンをクリックしてサイドバーを折りたたむと、表示スペースが広がります。

## モバイル対応

選手ダッシュボードは完全にレスポンシブ対応しており、モバイル端末に適応し、スマートフォンやタブレットで最適な体験を提供します。

## テクニカルサポート

ダッシュボードでお困りの場合：
1. ヘルプセクションのFAQをご確認ください
2. フッターからアクセスできるお問い合わせフォームをご利用ください
3. 専用セクションからサポートチケットを作成してください
