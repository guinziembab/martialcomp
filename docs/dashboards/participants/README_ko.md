# 선수 대시보드

## 소개

선수 대시보드는 MartialComp 플랫폼을 통해 개최되는 대회에 참가하는 무술 수련생을 위해 설계되었습니다. 이 인터페이스를 통해 참가자는 등록 관리, 결과 조회, 진행 상황 추적이 가능합니다.

## 대시보드 접속

선수 대시보드에 접속하려면:
1. MartialComp 계정에 로그인합니다
2. 프로필이 "participant" 역할로 설정되어 있으면 이 대시보드로 자동 리디렉션됩니다
3. 그렇지 않으면 URL `/dashboard/participant/`로 접속하세요

## 주요 기능

### 개요

선수 대시보드의 메인 페이지에는 다음이 표시됩니다:
- 예정된 대회 수
- 획득한 메달 수
- 총 참가 횟수
- 승인 대기 중인 등록
- 총점 및 평균 점수
- 종목별 통계
- 성적 그래프

![선수 대시보드](../../../Images/Dashbord%20participant%20%202025-05-18%20184013.png)

### 대회 관리

"대회" 섹션(`/dashboard/participant/competitions/`)에서는 다음이 가능합니다:
- 등록된 예정 대회 확인
- 과거 대회 기록 조회
- 대기 중인 등록 상태 추적
- 새로운 대회 탐색 및 등록

### 선수 프로필

"프로필" 섹션(`/dashboard/participant/profile/`)에서는 다음이 가능합니다:
- 개인 정보 조회 및 수정
- 수련 중인 종목과 관련 단/급 확인
- 단/급 이력 조회
- 프로필 사진 업데이트

### 결과

"결과" 섹션(`/dashboard/participant/results/`)에서는 다음이 가능합니다:
- 모든 대회 결과 조회
- 대회 또는 카테고리별 결과 필터링
- 각 경기 상세 내용 확인
- 참가 증명서 및 상장 다운로드

## 추가 기능

### 알림

알림 시스템이 중요한 이벤트를 알려줍니다:
- 등록 확인
- 예정 대회 리마인더
- 결과 발표
- 일정 변경

### 훈련 추적

활성화된 경우, 훈련 세션을 추적할 수 있습니다:
- 총 세션 수
- 이번 달 세션 수
- 이번 주 세션 수
- 종목별 분포

### 예정 이벤트

등록한 이벤트 또는 관심 있을 수 있는 이벤트 캘린더입니다.

### 재무

플랫폼 관련 금융 거래 개요:
- 최근 결제
- 총 결제 금액
- 미결제 청구서

### 쇼핑몰

쇼핑몰 모듈이 활성화된 경우:
- 최근 주문
- 주문 상태
- 추천 상품 빠른 접근

### 지원

지원 티켓 시스템 접근:
- 새 티켓 생성
- 기존 티켓 추적

## 사용자 지정

대시보드를 사용자 지정할 수 있습니다:
1. 오른쪽 상단의 "설정" 아이콘을 클릭합니다
2. "대시보드 환경설정" 섹션에서 표시할 위젯을 선택합니다
3. 드래그 앤 드롭으로 위젯을 재배열합니다
4. 설정을 저장합니다

## 내비게이션

사이드바를 통해 대시보드의 각 섹션 간을 이동할 수 있습니다. 메뉴 아이콘을 클릭하여 사이드바를 접으면 더 넓은 표시 공간을 확보할 수 있습니다.

## 모바일 호환성

선수 대시보드는 완전한 반응형으로 모바일 기기에 적응하며, 스마트폰과 태블릿에서 최적의 경험을 제공합니다.

## 기술 지원

대시보드 사용 중 어려움이 있는 경우:
1. 도움말 섹션의 FAQ를 참조하세요
2. 푸터에서 접근 가능한 문의 양식을 이용하세요
3. 전용 섹션에서 지원 티켓을 생성하세요
