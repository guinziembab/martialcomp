# Ibhodi Lokubuka Lomhlanganyeli

## Isingeniso

Ibhodi lokubuka lomhlanganyeli lakhelwe abahlanganyeli bezemidlalo yobudoda abadlala emiqhudelwaneni ehlelwe nge-platform ye-MartialComp. Lesi sixhumi sivumela abahlanganyeli ukuphatha ukubhaliswa kwabo, ukubheka imiphumela yabo, nokulandela intuthuko yabo.

## Ukufinyelela Ibhodi Lokubuka

Ukuze ufinyelele ibhodi lokubuka lomhlanganyeli:
1. Ngena ngemvume ku-akhawunti yakho ye-MartialComp
2. Uma iphrofayela yakho ilungiselelwe indima "participant", uzothunyelwa ngokuzenzakalelayo kuleli bhodi lokubuka
3. Noma, ungafinyelela nge-URL `/dashboard/participant/`

## Izici Eziyinhloko

### Ukubuka Konke

Ikhasi eliyinhloko lebhodi lokubuka lomhlanganyeli libonisa:
- Inombolo yemiqhudelwano ezayo
- Inombolo yamamedali atholwe
- Inombolo yonke yokudlala
- Ukubhaliswa okulindile ukuqinisekiswa
- Amaphuzu onke namaphuzu aphakathi
- Izibalo ngokwesifundo
- Amagrafu okusebenza

### Ukuphatha Imiqhudelwano

Isigaba "Imiqhudelwano" (`/dashboard/participant/competitions/`) sikuvumela ukuthi:
- Ubone imiqhudelwano ezayo obhalise kuyo
- Ubheke umlando wemiqhudelwano edlule
- Ulandele isimo sokubhaliswa okulindile
- Uthole futhi ubhalise emiqhudelwaneni emisha

### Iphrofayela Yomhlanganyeli

Isigaba "Iphrofayela" (`/dashboard/participant/profile/`) sikuvumela ukuthi:
- Ubheke futhi ushintshi ulwazi lwakho lomuntu siqu
- Ubone izifundo zakho namazinga ahambisana nazo
- Ubheke umlando wamazinga akho
- Ushintshe isithombe sakho sephrofayela

### Imiphumela

Isigaba "Imiphumela" (`/dashboard/participant/results/`) sikuvumela ukuthi:
- Ubheke yonke imiphumela yakho yemiqhudelwano
- Uhluze imiphumela ngomqhudelwano noma isigaba
- Ubone imininingwane yokusebenza ngakunye
- Ulayishe phansi izitifiketi zokuhlanganyela namadiploma

## Izici Ezengeziwe

### Izaziso

Uhlelo lwezaziso lukwazisa ngezenzakalo ezibalulekile:
- Iziqinisekiso zokubhaliswa
- Izikhumbuzo zemiqhudelwano ezayo
- Izimemezelo zemiphumela
- Izinguquko zesikhathi

### Ukulandela Ukuqeqeshwa

Uma kusebenza, ungalandela izikhathi zakho zokuqeqeshwa:
- Inombolo yonke yezikhathi
- Izikhathi kule nyanga
- Izikhathi kule wiki
- Ukwahlukana ngokwesifundo

### Izenzakalo Ezizayo

Ikhalenda yezenzakalo obhalise kuyo noma ezingakuthanda.

### Izimali

Ukubuka konke kwemali yakho ehambisana ne-platform:
- Izinkokhelo zamuva
- Inani lonke lezinkokhelo
- Ama-invoyisi alindile

### Isitolo

Uma imoduli yesitolo isebenza:
- Ama-oda amuva
- Isimo sama-oda
- Ukufinyelela okusheshayo kumikhiqizo enconyiwe

### Ukusekela

Ukufinyelela ohlelweni lwamathikithi okusekela:
- Ukwenza amathikithi amasha
- Ukulandela amathikithi akhona

## Ukulungisa

Ungalungisa ibhodi lakho lokubuka:
1. Chofoza isithonjana "Izilungiselelo" phezulu kwesokudla
2. Esigabeni "Okuthandayo kwebhodi lokubuka", khetha ama-widget okuwabonisa
3. Hlela kabusha ama-widget ngokuwadonsela
4. Gcina okuthandayo kwakho

## Ukuzulazula

Ibha eceleni ikuvumela ukuzulazula phakathi kwezigaba ezihlukene zebhodi lokubuka. Ungayinciphisa ngokuchofoza isithonjana semenyu ukuze uthole indawo eningi yokubonisa.

## Ukuhambisana Nomakhalekhukhwini

Ibhodi lokubuka lomhlanganyeli livumelana ngokuphelele nezixhumi eziphathekayo, linikeza ulwazi oluhle ku-smartphone ne-tablet.

## Ukusekela Ngobuchwepheshe

Uma unenkinga nebhodi lakho lokubuka:
1. Bheka i-FAQ esigabeni Usizo
2. Sebenzisa ifomu yokuxhumana etholakala ekugcineni kwekhasi
3. Dala ithikithi lokusekela esigabeni esibekwe ngokukhethekile
