# Dasibodu Olukopa

## Ifaara

Dasibodu Olukopa ni a se apere fun awon ti n se ere idaraya ologun ti wọn n kopa ninu awon idije ti a se eto nipase pẹpẹ MartialComp. Atọka yii jẹ ki awon olukopa le sakoso awon iforukọsilẹ wọn, wo awon abajade wọn, ati tẹle ilọsiwaju wọn.

## Iwọle si Dasibodu

Lati wọle si dasibodu olukopa:
1. Wọle si akọọlẹ MartialComp rẹ
2. Ti a ba ti se profaili rẹ pẹlu ipa "olukopa", a o darí ọ lọ si dasibodu yii laifọwọyi
3. Bibẹẹkọ, lo URL `/dashboard/participant/`

## Awon Isise Akọkọ

### Akopọ

Oju-iwe akọkọ dasibodu olukopa fi wọnyi han:
- Nọmba awon idije ti n bọ
- Nọmba awon ami-ẹyẹ ti a gba
- Nọmba apapọ awon ikopa
- Awon iforukọsilẹ ti n duro de ifọwọsi
- Isiro lapapọ ati isiro apapọ
- Awon iṣiro nipa ẹkọ
- Awon aworan isise

### Isakoso Idije

Apakan "Awon Idije" (`/dashboard/participant/competitions/`) jẹ ki o:
- Wo awon idije ti n bọ ti a forukọsilẹ si
- Wo itan awon idije ti o ti kọja
- Tẹle ipo awon iforukọsilẹ ti n duro de
- Se awari ati forukọsilẹ fun awon idije titun

### Profaili Olukopa

Apakan "Profaili" (`/dashboard/participant/profile/`) jẹ ki o:
- Wo ati se atunse alaye ti ara ẹni
- Ri awon ẹkọ ti o n se ati awon ipele ti o somọ
- Wo itan awon ipele rẹ
- Se imudojuiwọn foto profaili rẹ

### Awon Abajade

Apakan "Awon Abajade" (`/dashboard/participant/results/`) jẹ ki o:
- Wo gbogbo awon abajade idije rẹ
- Se asẹ awon abajade nipa idije tabi ẹka
- Ri awon alaye isise kookan
- Se igbasilẹ awon iwe-ẹri ikopa ati awon iwe-ẹri

## Awon Isise Afikun

### Awon Iwifunni

Eto iwifunni n sọ fun ọ nipa awon iṣẹlẹ pataki:
- Ifọwọsi iforukọsilẹ
- Iranti awon idije ti n bọ
- Ikede awon abajade
- Awon ayipada ninu eto

### Itọpinpin Ikẹkọ

Ti a ba mu isise yii sise, o le tẹle awon akoko ikẹkọ rẹ:
- Nọmba apapọ awon akoko
- Awon akoko ni osu yii
- Awon akoko ni ọsẹ yii
- Pinpin nipa ẹkọ

### Awon Iṣẹlẹ Ti N Bọ

Kalẹnda awon iṣẹlẹ ti o forukọsilẹ si tabi ti o le nifẹ si.

### Owo

Akopọ awon idunadura owo rẹ ti o somọ pẹpẹ:
- Awon sisanwo aipẹ
- Iye apapọ awon sisanwo
- Awon owo-owo ti n duro de

### Ile Itaja

Ti a ba mu modulu ile itaja sise:
- Awon aṣẹ aipẹ
- Ipo awon aṣẹ
- Iraye iyara si awon ọja ti a gba niyanju

### Atilẹyin

Iraye si eto tikẹti atilẹyin:
- Sise tikẹti titun
- Tẹle awon tikẹti ti o wa tẹlẹ

## Aṣayan

O le se aṣayan dasibodu rẹ:
1. Tẹ aami "Awon Eto" ni apa ọtun oke
2. Ni apakan "Awon ayanfẹ dasibodu", yan awon widjeti lati fi han
3. Tun se eto awon widjeti nipa fifa-ati-jù
4. Fi awon ayanfẹ rẹ pamọ

## Lilọ Kiri

Apa ita n jẹ ki o lọ kiri laarin awon apakan orisirisii dasibodu. O le di i ku nipa titẹ aami akojọ lati ni aaye ifihan diẹ sii.

## Ibamu Alagbeka

Dasibodu olukopa yipada patapata ati pe o ba awon ẹrọ alagbeka mu, ti o n pese iriri ti o dara julọ lori foonu alagbeka ati tabulẹti.

## Atilẹyin Imọ-ẹrọ

Ni ọran isoro pẹlu dasibodu rẹ:
1. Wo FAQ ni apakan Iranlọwọ
2. Lo fọọmu olubasọrọ ti o wa lati apa isalẹ
3. Se tikẹti atilẹyin nipase apakan ti a yan si
