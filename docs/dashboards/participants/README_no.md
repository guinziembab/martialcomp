# Deltaker-dashbord

## Introduksjon

Deltaker-dashbordet er designet for kampsportutøvere som deltar i konkurranser organisert via MartialComp-plattformen. Dette grensesnittet lar deltakere administrere sine påmeldinger, se resultater og følge sin progresjon.

## Tilgang til Dashbordet

For å få tilgang til deltaker-dashbordet:
1. Logg inn på din MartialComp-konto
2. Hvis profilen din er konfigurert med rollen "deltaker", blir du automatisk videresendt til dette dashbordet
3. Ellers kan du få tilgang via URL-en `/dashboard/participant/`

## Hovedfunksjoner

### Oversikt

Hovedsiden til deltaker-dashbordet viser:
- Antall kommende konkurranser
- Antall vunne medaljer
- Totalt antall deltakelser
- Påmeldinger som venter på godkjenning
- Total poengsum og gjennomsnittlig poengsum
- Statistikk per disiplin
- Ytelsesdiagrammer

![Deltaker-dashbord](../../../Images/Dashbord%20participant%20%202025-05-18%20184013.png)

### Konkurranseoversikt

Seksjonen "Konkurranser" (`/dashboard/participant/competitions/`) lar deg:
- Se kommende konkurranser du er påmeldt til
- Se historikk over tidligere konkurranser
- Følge status for ventende påmeldinger
- Oppdage og melde deg på nye konkurranser

### Deltakerprofil

Seksjonen "Profil" (`/dashboard/participant/profile/`) lar deg:
- Se og endre dine personlige opplysninger
- Se dine utøvde disipliner og tilhørende grader
- Se historikk over dine grader
- Oppdatere profilbildet ditt

### Resultater

Seksjonen "Resultater" (`/dashboard/participant/results/`) lar deg:
- Se alle dine konkurranseresultater
- Filtrere resultater etter konkurranse eller kategori
- Se detaljer for hver prestasjon
- Laste ned deltakelsessertifikater og diplomer

## Tilleggsfunksjoner

### Varsler

Varslingssystemet informerer deg om viktige hendelser:
- Påmeldingsbekreftelser
- Påminnelser om kommende konkurranser
- Resultatkunngjøringer
- Endringer i tidsplanen

### Treningsoppfølging

Hvis aktivert, kan du følge dine treningsøkter:
- Totalt antall økter
- Økter denne måneden
- Økter denne uken
- Fordeling per disiplin

### Kommende Arrangementer

Kalender over arrangementer du er påmeldt til eller som kan være av interesse for deg.

### Økonomi

Oversikt over dine finansielle transaksjoner knyttet til plattformen:
- Nylige betalinger
- Totalt betalingsbeløp
- Ubetalte fakturaer

### Butikk

Hvis butikkmodulen er aktivert:
- Nylige bestillinger
- Ordrestatus
- Rask tilgang til anbefalte produkter

### Support

Tilgang til support-billetsystemet:
- Opprettelse av nye billetter
- Oppfølging av eksisterende billetter

## Tilpasning

Du kan tilpasse dashbordet ditt:
1. Klikk på "Innstillinger"-ikonet øverst til høyre
2. I seksjonen "Dashbord-innstillinger", velg widgetene som skal vises
3. Omorganiser widgets ved å dra og slippe
4. Lagre dine innstillinger

## Navigasjon

Sidefeltet lar deg navigere mellom de ulike seksjonene i dashbordet. Du kan minimere det ved å klikke på menyikonet for å få mer visningsplass.

## Mobilkompatibilitet

Deltaker-dashbordet er fullt responsivt og tilpasser seg mobile enheter, og gir en optimal opplevelse på smarttelefon og nettbrett.

## Teknisk Support

Hvis du har problemer med dashbordet ditt:
1. Se FAQ i Hjelp-seksjonen
2. Bruk kontaktskjemaet som er tilgjengelig fra bunnteksten
3. Opprett en support-billett via den dedikerte seksjonen
