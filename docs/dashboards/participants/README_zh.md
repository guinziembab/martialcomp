# 选手仪表盘

## 简介

选手仪表盘专为通过MartialComp平台参加比赛的武术练习者而设计。该界面允许参赛者管理报名、查看成绩并跟踪个人进步。

## 访问仪表盘

要访问选手仪表盘：
1. 登录您的MartialComp账户
2. 如果您的账户配置为"participant"角色，您将自动重定向到此仪表盘
3. 否则，请通过URL `/dashboard/participant/` 访问

## 主要功能

### 概览

选手仪表盘的主页显示：
- 即将举行的比赛数量
- 获得的奖牌数量
- 总参赛次数
- 等待确认的报名
- 总分和平均分
- 按学科分类的统计数据
- 成绩表现图表

![选手仪表盘](../../../Images/Dashbord%20participant%20%202025-05-18%20184013.png)

### 比赛管理

"比赛"部分（`/dashboard/participant/competitions/`）允许：
- 查看已报名的即将举行的比赛
- 浏览过往比赛记录
- 跟踪待审核的报名状态
- 发现并报名新比赛

### 选手资料

"资料"部分（`/dashboard/participant/profile/`）允许：
- 查看和编辑个人信息
- 查看所练学科及相关段位/级别
- 查看段位/级别历史记录
- 更新个人头像

### 成绩

"成绩"部分（`/dashboard/participant/results/`）允许：
- 查看所有比赛成绩
- 按比赛或类别筛选成绩
- 查看每场表现的详细信息
- 下载参赛证书和获奖证书

## 附加功能

### 通知

通知系统会告知您重要事件：
- 报名确认
- 即将举行的比赛提醒
- 成绩公布
- 日程变更

### 训练跟踪

如果已启用，您可以跟踪训练课程：
- 总课程数
- 本月课程数
- 本周课程数
- 按学科分布

### 即将举行的活动

您已报名或可能感兴趣的活动日历。

### 财务

与平台相关的财务交易概览：
- 最近的付款
- 付款总额
- 待付账单

### 商店

如果商店模块已启用：
- 最近的订单
- 订单状态
- 快速访问推荐产品

### 技术支持

访问支持工单系统：
- 创建新工单
- 跟踪现有工单

## 自定义

您可以自定义仪表盘：
1. 点击右上角的"设置"图标
2. 在"仪表盘偏好设置"部分，选择要显示的小组件
3. 通过拖放重新排列小组件
4. 保存您的偏好设置

## 导航

侧边栏允许在仪表盘的各个部分之间导航。您可以点击菜单图标折叠侧边栏以获得更多显示空间。

## 移动端兼容

选手仪表盘完全响应式设计，适配移动设备，在智能手机和平板电脑上提供最佳体验。

## 技术支持

如果在使用仪表盘时遇到困难：
1. 请查看帮助部分的常见问题
2. 使用页脚中的联系表单
3. 通过专用部分创建支持工单
