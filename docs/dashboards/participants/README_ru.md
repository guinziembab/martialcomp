# Панель участника

## Введение

Панель участника предназначена для практикующих боевые искусства, которые участвуют в соревнованиях, организованных через платформу MartialComp. Этот интерфейс позволяет участникам управлять своими регистрациями, просматривать результаты и отслеживать свой прогресс.

## Доступ к панели

Для доступа к панели участника:
1. Войдите в свою учётную запись MartialComp
2. Если ваш профиль настроен с ролью "участник", вы будете автоматически перенаправлены на эту панель
3. Или перейдите по URL `/dashboard/participant/`

## Основные функции

### Обзор

Главная страница панели участника отображает:
- Количество предстоящих соревнований
- Количество завоёванных медалей
- Общее количество участий
- Регистрации, ожидающие подтверждения
- Общий балл и средний балл
- Статистика по дисциплинам
- Графики производительности

### Управление соревнованиями

Раздел "Соревнования" (`/dashboard/participant/competitions/`) позволяет:
- Просматривать предстоящие соревнования, на которые вы зарегистрированы
- Просматривать историю прошедших соревнований
- Отслеживать статус ожидающих регистраций
- Находить и регистрироваться на новые соревнования

### Профиль участника

Раздел "Профиль" (`/dashboard/participant/profile/`) позволяет:
- Просматривать и редактировать личную информацию
- Видеть практикуемые дисциплины и связанные с ними разряды
- Просматривать историю разрядов
- Обновлять фотографию профиля

### Результаты

Раздел "Результаты" (`/dashboard/participant/results/`) позволяет:
- Просматривать все результаты соревнований
- Фильтровать результаты по соревнованию или категории
- Видеть детали каждого выступления
- Скачивать сертификаты участия и дипломы

## Дополнительные функции

### Уведомления

Система уведомлений информирует вас о важных событиях:
- Подтверждения регистрации
- Напоминания о предстоящих соревнованиях
- Объявления результатов
- Изменения в расписании

### Отслеживание тренировок

Если функция активирована, вы можете отслеживать свои тренировки:
- Общее количество сессий
- Сессии в этом месяце
- Сессии на этой неделе
- Распределение по дисциплинам

### Предстоящие события

Календарь событий, на которые вы зарегистрированы или которые могут вас заинтересовать.

### Финансы

Обзор ваших финансовых операций, связанных с платформой:
- Последние платежи
- Общая сумма платежей
- Ожидающие счета

### Магазин

Если модуль магазина активирован:
- Последние заказы
- Статус заказов
- Быстрый доступ к рекомендуемым товарам

### Поддержка

Доступ к системе тикетов поддержки:
- Создание новых тикетов
- Отслеживание существующих тикетов

## Настройка

Вы можете настроить свою панель управления:
1. Нажмите на значок "Настройки" в правом верхнем углу
2. В разделе "Настройки панели" выберите виджеты для отображения
3. Перетаскивайте виджеты для изменения порядка
4. Сохраните ваши настройки

## Навигация

Боковая панель позволяет перемещаться между различными разделами панели управления. Вы можете свернуть её, нажав на значок меню, чтобы увеличить область отображения.

## Мобильная совместимость

Панель участника полностью адаптивна и приспособлена к мобильным устройствам, обеспечивая оптимальный опыт на смартфонах и планшетах.

## Техническая поддержка

В случае затруднений с панелью управления:
1. Ознакомьтесь с FAQ в разделе Помощь
2. Используйте форму обратной связи, доступную из нижнего колонтитула
3. Создайте тикет поддержки через специальный раздел
