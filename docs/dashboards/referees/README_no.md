# Dommer-dashbord

## Introduksjon

Dommer-dashbordet er et spesialisert grensesnitt designet for funksjonærer som evaluerer og dømmer kampsportkonkurranser. Denne plattformen tilbyr verktøy tilpasset de spesifikke behovene til tekniske dommere og kampdommere.

## Tilgang til Dashbordet

For å få tilgang til dommer-dashbordet:
1. Logg inn på din MartialComp-konto
2. Hvis profilen din er konfigurert med rollen "judge" eller "referee", blir du automatisk videresendt til dette dashbordet
3. Ellers kan du få tilgang via URL-en `/dashboard/referee/`

## Hovedfunksjoner

### Oversikt

Hovedsiden til dommer-dashbordet viser:
- Kommende konkurranser der du er tildelt
- Historikk over tidligere konkurranser
- Kalender for utdanning og resertifiseringer
- Viktige varsler (innkallinger, tidsplanendringer)
- Hurtigtilgang til regelverk og bedømmelseskriterier

### Tildelte Konkurranser

Seksjonen "Konkurranser" lar deg:
- Se detaljer for konkurranser der du er tildelt
- Se din rolle og berørte konkurranseområder
- Få tilgang til detaljerte tidsplaner
- Se listen over deltakere per kategori
- Laste ned bedømmelsesark og spesifikke regelverk

### Teknisk Bedømming

Seksjonen "Bedømming" tilbyr verktøy for å:
- Få tilgang til det elektroniske bedømmelsessystemet
- Registrere poeng i sanntid
- Se evalueringskriterier per disiplin
- Gjennomgå tidligere prestasjoner
- Analysere konsistensen i dine bedømmelser

### Kampdømming

For kampdommere, dedikerte funksjoner:
- Poengtellersystem
- Administrasjon av straffer og advarsler
- Integrert stoppeklokke
- Oppfølging av skader og avbrudd
- Grensesnitt tilpasset ulike regelverk (Taekwondo, Karate osv.)

### Etterutdanning

Seksjonen "Utdanning" lar deg:
- Følge nye regler og regelverksoppdateringer
- Få tilgang til pedagogiske ressurser (videoer, dokumenter)
- Melde seg på resertifiseringskurs
- Se din utdanningshistorikk
- Forberede seg til oppgraderinger av dommergrad

## Tilleggsfunksjoner

### Dommerprofil

Administrasjon av din offisielle profil:
- Personlig informasjon og kontaktdetaljer
- Kvalifikasjoner og dommernivåer
- Disipliner og spesialiseringer
- Tilgjengelighet og preferanser
- Historikk over dømte konkurranser

### Kommunikasjon

Verktøy for å kommunisere med arrangører og andre funksjonærer:
- Intern meldingstjeneste
- Varsler om tidsplanendringer
- Tilgjengelighetsbekreftelser
- Etterkonkurranserapporter
- Spørsmål om regelverk

### Analyse og Statistikk

For dommere som ønsker å analysere sitt arbeid:
- Bedømmelsesstatistikk per kategori
- Sammenligning med andre dommere
- Konsistensanalyse
- Utviklingsdiagrammer
- Tilpassede rapporter

### Frakoblet Modus

Funksjoner tilgjengelige uten internettforbindelse:
- Forhåndsnedlasting av konkurransedata
- Poengregistrering i frakoblet modus
- Automatisk synkronisering ved gjenoppretting av tilkobling
- Batterisparemodus for lange dager

## Bruk Under Konkurranser

### Forberedelse

Før en konkurranse:
1. Se din tildeling og tidsplan
2. Last ned spesifikke regelverk
3. Gjennomgå bedømmelseskriteriene
4. Last ned data i frakoblet modus om nødvendig

### Under Konkurransen

Under arrangementet:
1. Bruk sanntids bedømmelsesgrensesnittet
2. Se raskt på kriteriene ved tvil
3. Kommuniser med områdeansvarlig via systemet
4. Se andre dommeres poeng (hvis autorisert)
5. Håndter hendelser og spesielle tilfeller effektivt

### Etter Konkurransen

For å avslutte arbeidet ditt:
1. Godkjenn alle dine bedømmelser
2. Send inn din etterkonkurranserapport
3. Rapporter eventuelle hendelser eller forbedringer
4. Se arrangementets statistikk
5. Oppdater din fremtidige tilgjengelighet

## Teknisk Support

Hvis du har problemer med dashbordet ditt:
1. Se den detaljerte brukerveiledningen
2. Kontakt konkurransens IT-ansvarlige
3. Bruk den integrerte hjelpefunksjonen
4. Ved nødstilfeller under en konkurranse er prioritert support tilgjengelig
