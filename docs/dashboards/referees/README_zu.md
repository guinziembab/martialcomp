# Ibhodi Lokubuka Lommeli/Umhluleli

## Isingeniso

Ibhodi lokubuka lommeli/umhluleli liyisixhumi esenzelwe izikhulu ezihlola futhi zahlulele imiqhudelwano yezemidlalo yobudoda. Le platform inikeza amathuluzi alungiselelwe izidingo ezikhethekile zabammeli bobuchwepheshe nabammeli bokulwa.

## Ukufinyelela Ibhodi Lokubuka

Ukuze ufinyelele ibhodi lokubuka lommeli:
1. Ngena ngemvume ku-akhawunti yakho ye-MartialComp
2. Uma iphrofayela yakho ilungiselelwe indima "judge" noma "referee", uzothunyelwa ngokuzenzakalelayo kuleli bhodi lokubuka
3. Noma, ungafinyelela nge-URL `/dashboard/referee/`

## Izici Eziyinhloko

### Ukubuka Konke

Ikhasi eliyinhloko lebhodi lokubuka lommeli libonisa:
- Imiqhudelwano ezayo lapho unikwe khona
- Umlando wemiqhudelwano edlule
- Ikhalenda yokugqeqeshwa nokuvuselelwa
- Izaziso ezibalulekile (izimemo, izinguquko zezikhathi)
- Ukufinyelela okusheshayo emithethweni nasezindinganisweni zokuhlola

### Imiqhudelwano Enikeziwe

Isigaba "Imiqhudelwano" sikuvumela ukuthi:
- Ubheke imininingwane yemiqhudelwano enikeziwe kuyo
- Ubone indima yakho nezindawo zomqhudelwano ezithintekayo
- Ufinyelele izikhathi zohlelo enemininingwane
- Ubheke uhlu lwababambe iqhaza ngesigaba
- Ulayishe phansi amashidi okwahlulela nemithetho eqondile

### Ukuhlola Kobuchwepheshe

Isigaba "Ukuhlola" sinikeza amathuluzi okuthi:
- Ufinyelele uhlelo lokuhlola ngobuchwepheshe
- Ubhale amaphuzu ngesikhathi sangempela
- Ubheke izindinganiso zokuhlola ngokwesifundo
- Ubuyekeze ukusebenza okudlule
- Uhlaziye ukuhambisana kokuhlola kwakho

### Ukwahlulela Ukulwa

Ngabammeli bokulwa, izici ezibekwe ngokukhethekile:
- Uhlelo lokubalwa kwamaphuzu
- Ukuphathwa kwezijeziso nezexwayiso
- Isibalokazi esihlanganisiwe
- Ukulandela kwalimala nokuphazamiseka
- Isixhumi esilungiselelwe imithetho ehlukene (I-Taekwondo, I-Karate, njll.)

### Ukuqeqeshwa Okuqhubekayo

Isigaba "Ukuqeqeshwa" sikuvumela ukuthi:
- Ulandele imithetho emisha nezinguquko zemithetho
- Ufinyelele izinsiza zokufundisa (amavidiyo, imibhalo)
- Ubhalise ezifundweni zokuvuselelwa
- Ubheke umlando wakho wokuqeqeshwa
- Ulungiselele izivivinyo zokuphakanyiswa kwezinga lokwahlulela

## Izici Ezengeziwe

### Iphrofayela Yommeli

Ukuphathwa kwephrofayela yakho esemthethweni:
- Ulwazi lomuntu siqu nemininingwane yokuxhumana
- Iziqu namazinga okwahlulela
- Izifundo nokukhethekiswa
- Ukutholakala nokukhethwa
- Umlando wemiqhudelwano owayihlulela

### Ukuxhumana

Amathuluzi okuxhumana nabahleleli nezinye izikhulu:
- Imiyalezo yangaphakathi
- Izaziso zezinguquko zezikhathi
- Iziqinisekiso zokutholakala
- Imibiko yangemva komqhudelwano
- Imibuzo ngemithetho

### Ukuhlaziya Nezibalo

Ngabammeli abafisa ukuhlaziya umsebenzi wabo:
- Izibalo zokuhlola ngesigaba
- Ukuqhathaniswa nabanye abammeli
- Ukuhlaziya kokuhambisana
- Amagrafu okuthuthuka
- Imibiko elungiselelwe

### Imodi Engaxhunyiwe

Izici ezitholakalayo ngaphandle kwe-inthanethi:
- Ukulayisha phansi kwangaphambili kwedatha yomqhudelwano
- Ukubhala amaphuzu ngemodi engaxhunyiwe
- Ukuxhumanisa ngokuzenzakalelayo uma kuxhunywa kabusha
- Imodi yokonga ibhethri ngezinsuku ezinde

## Ukusetshenziswa Phakathi Nemiqhudelwano

### Ukulungiselela

Ngaphambi komqhudelwano:
1. Bheka ukwabelwa kwakho nohlelo lwesikhathi
2. Layisha phansi imithetho eqondile
3. Hlola izindinganiso zokuhlola
4. Layisha phansi idatha ngemodi engaxhunyiwe uma kudingeka

### Phakathi Nomqhudelwano

Phakathi kwesenzakalo:
1. Sebenzisa isixhumi sokuhlola ngesikhathi sangempela
2. Bheka ngokushesha izindinganiso uma ungaqinisekile
3. Xhumana nophathayo wendawo ngohlelo
4. Bona amaphuzu abanye abammeli (uma kuvunyelwe)
5. Phatha izehlakalo nezimo ezikhethekile ngempumelelo

### Ngemva Komqhudelwano

Ukuze uqedele umsebenzi wakho:
1. Qinisekisa konke ukuhlola kwakho
2. Thumela umbiko wakho wangemva komqhudelwano
3. Bika izehlakalo noma izincomo
4. Bheka izibalo zesenzakalo
5. Vuselela ukutholakala kwakho kwesikhathi esizayo

## Ukusekela Ngobuchwepheshe

Uma unenkinga nebhodi lakho lokubuka:
1. Bheka umhlahlandlela wokusetshenziswa enemininingwane
2. Xhumana nophathe we-IT womqhudelwano
3. Sebenzisa umsebenzi wosizo ohlanganisiwe
4. Esimeni esiphuthumayo phakathi nomqhudelwano, ukusekela okubalulekile kuyatholakala
