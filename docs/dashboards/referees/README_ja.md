# 審判・判定員ダッシュボード

## はじめに

審判・判定員ダッシュボードは、武道・格闘技の大会において審査・審判を行う役員のために設計された専門インターフェースです。このプラットフォームは、技術審査員や試合審判の具体的なニーズに適したツールを提供します。

## ダッシュボードへのアクセス

審判・判定員ダッシュボードにアクセスするには：
1. MartialCompアカウントにログインしてください
2. プロフィールに「judge（判定員）」または「referee（審判）」の役割が設定されている場合、自動的にこのダッシュボードにリダイレクトされます
3. それ以外の場合は、URL `/dashboard/referee/` から直接アクセスできます

## 主な機能

### 概要

審判・判定員ダッシュボードのメインページには以下が表示されます：
- 配置が決まっている今後の大会
- 過去の大会の履歴
- 研修・更新講習のスケジュール
- 重要な通知（招集、スケジュール変更など）
- 規則および採点基準へのクイックアクセス

### 配置された大会

「大会」セクションでは以下のことが可能です：
- 配置が決まっている大会の詳細を確認する
- 自分の役割および担当する試合エリアを確認する
- 詳細なスケジュールと日程にアクセスする
- カテゴリ別の参加者リストを確認する
- 採点用紙および競技固有の規則をダウンロードする

### 技術採点

「採点」セクションでは以下のツールが利用できます：
- 電子採点システムへのアクセス
- リアルタイムでのスコア入力
- 競技種目別の評価基準の確認
- 過去の演技・試技の振り返り
- 自身の採点の一貫性を分析する

### 試合審判

試合審判向けの専用機能：
- ポイント計数システム
- ペナルティおよび警告の管理
- 統合タイマー
- 負傷および中断の追跡
- 各種規則に対応したインターフェース（テコンドー、空手など）

### 継続研修

「研修」セクションでは以下のことが可能です：
- 新規則および規則改定の確認
- 教育リソース（動画、資料）へのアクセス
- 更新講習への申し込み
- 研修履歴の確認
- 審判資格昇級試験の準備

## 追加機能

### 審判・判定員プロフィール

役員プロフィールの管理：
- 個人情報および連絡先
- 資格および審判レベル
- 担当競技種目と専門分野
- 空き状況と希望条件
- 審判を務めた大会の履歴

### コミュニケーション

主催者や他の役員とのコミュニケーションツール：
- 内部メッセージ機能
- スケジュール変更の通知
- 出欠の確認
- 大会後レポート
- 規則に関する質問

### 分析と統計

審判業務を分析したい判定員向け：
- カテゴリ別の採点統計
- 他の判定員との比較
- 一貫性の分析
- 推移グラフ
- カスタムレポート

### オフラインモード

インターネット接続なしで利用できる機能：
- 大会データの事前ダウンロード
- オフラインモードでのスコア入力
- 再接続時の自動同期
- 長時間の大会に対応するバッテリー節約モード

## 大会中の利用方法

### 事前準備

大会前の準備：
1. 配置とスケジュールを確認する
2. 該当する規則をダウンロードする
3. 採点基準を確認する
4. 必要に応じてオフラインモード用のデータをダウンロードする

### 大会中

イベント進行中：
1. リアルタイム採点インターフェースを使用する
2. 判断に迷った場合は採点基準をすぐに参照する
3. システムを通じてエリア責任者と連絡を取る
4. 他の判定員のスコアを確認する（許可されている場合）
5. インシデントや特殊な状況を効率的に管理する

### 大会後

業務の完了に向けて：
1. すべての採点を確定する
2. 大会後レポートを提出する
3. インシデントや改善点があれば報告する
4. イベントの統計を確認する
5. 今後の空き状況を更新する

## テクニカルサポート

ダッシュボードに関してお困りの場合：
1. 詳細な利用ガイドを参照してください
2. 大会のIT担当者にご連絡ください
3. 内蔵のヘルプ機能をご利用ください
4. 大会中の緊急時には、優先サポートが利用可能です
