# የዳኛ/ገምጋሚ ዳሽቦርድ

## መግቢያ

የዳኛ/ገምጋሚ ዳሽቦርድ የውጊያ ስፖርት ውድድሮችን ለሚገመግሙ እና ለሚዳኙ ባለሥልጣናት የተዘጋጀ ልዩ መገበያያ ነው። ይህ መድረክ ለቴክኒክ ዳኞች እና ለውጊያ ዳኞች ልዩ ፍላጎቶች የተመቻቹ መሣሪያዎችን ያቀርባል።

## ዳሽቦርዱን ማግኘት

የዳኛ/ገምጋሚ ዳሽቦርዱን ለማግኘት፡
1. ወደ MartialComp መለያዎ ይግቡ
2. የእርስዎ መገለጫ በ"judge" ወይም "referee" ሚና ከተዋቀረ፣ ወደዚህ ዳሽቦርድ በራስ-ሰር ይዘዋወራሉ
3. ካልሆነ ግን፣ በ `/dashboard/referee/` URL በኩል ያግኙት

## ዋና ዋና ባህሪያት

### አጠቃላይ እይታ

የዳኛ/ገምጋሚ ዳሽቦርዱ ዋና ገጽ የሚከተሉትን ያሳያል፡
- ለእርስዎ የተመደቡ መጪ ውድድሮች
- ያለፉ ውድድሮች ታሪክ
- የሥልጠና እና የማደስ የቀን መቁጠሪያ
- አስፈላጊ ማሳወቂያዎች (ጥሪዎች፣ የሰዓት ለውጦች)
- ደንቦችን እና የግምገማ መስፈርቶችን በፍጥነት ማግኘት

### የተመደቡ ውድድሮች

"ውድድሮች" ክፍሉ የሚከተሉትን ያስችላል፡
- ለእርስዎ የተመደቡ ውድድሮች ዝርዝሮችን ማየት
- ሚናዎን እና ተዛማጅ የውድድር ቦታዎችን ማየት
- ዝርዝር የሰዓት ሠሌዳዎችን እና ፕሮግራሞችን ማግኘት
- በምድብ የተዘረዘሩ ተሳታፊዎችን ዝርዝር ማየት
- የግምገማ ቅጾችን እና ልዩ ደንቦችን ማውረድ

### ቴክኒካል ግምገማ

"ግምገማ" ክፍሉ ለሚከተሉት መሣሪያዎችን ያቀርባል፡
- ወደ ኤሌክትሮኒክ ግምገማ ሥርዓት መድረስ
- በቀጥታ ጊዜ ውጤቶችን ማስገባት
- በዲሲፕሊን የተደራጁ የግምገማ መስፈርቶችን ማየት
- ያለፉ አፈጻጸሞችን መመልከት
- የግምገማ ወጥነትን መተንተን

### የውጊያ ዳኝነት

ለውጊያ ዳኞች የተለዩ ባህሪያት፡
- የነጥብ ቆጠራ ሥርዓት
- የቅጣቶች እና ማስጠንቀቂያዎች አስተዳደር
- የተዋሃደ ሰዓት ቆጣሪ
- የጉዳቶች እና መቋረጦች ክትትል
- ለተለያዩ ደንቦች (ታኩዋንዶ፣ ካራቴ፣ ወዘተ.) የተመቻቸ መገበያያ

### ቀጣይ ትምህርት

"ሥልጠና" ክፍሉ የሚከተሉትን ያስችላል፡
- አዳዲስ ደንቦችን እና የደንብ ማሻሻያዎችን መከታተል
- ትምህርታዊ ግብዓቶችን (ቪዲዮዎች፣ ሰነዶች) ማግኘት
- ለማደስ ሥልጠናዎች መመዝገብ
- የሥልጠና ታሪክዎን ማየት
- የዳኝነት ደረጃ ዕድገት ፈተናዎችን ማዘጋጀት

## ተጨማሪ ባህሪያት

### የዳኛ/ገምጋሚ መገለጫ

የባለሥልጣን መገለጫዎን ማስተዳደር፡
- ግላዊ መረጃዎች እና የመገኛ ዝርዝሮች
- ብቃቶች እና የዳኝነት ደረጃዎች
- ዲሲፕሊኖች እና ልዩ ችሎታዎች
- ቀጠሮዎች እና ምርጫዎች
- የተዳኙ ውድድሮች ታሪክ

### ግንኙነት

ከአዘጋጆች እና ከሌሎች ባለሥልጣናት ጋር ለመገናኘት የሚያገለግሉ መሣሪያዎች፡
- ውስጣዊ የመልእክት ልውውጥ
- የፕሮግራም ለውጥ ማሳወቂያዎች
- የተገኝነት ማረጋገጫዎች
- ከውድድር በኋላ ሪፖርቶች
- ስለ ደንቦች ጥያቄዎች

### ትንተና እና ስታቲስቲክስ

ሥራቸውን ለመተንተን ለሚፈልጉ ዳኞች፡
- በምድብ የተደራጁ የግምገማ ስታቲስቲክስ
- ከሌሎች ዳኞች ጋር ንጽጽር
- የወጥነት ትንተና
- የዕድገት ግራፎች
- ብጁ ሪፖርቶች

### ከመስመር ውጭ ሁነታ

ያለ ኢንተርኔት ግንኙነት የሚገኙ ባህሪያት፡
- የውድድር ውሂብ ቅድመ-ማውረድ
- ከመስመር ውጭ ሁነታ ውጤቶችን ማስገባት
- ግንኙነት ሲመለስ ራስ-ሰር ማመሳሰል
- ረጅም ቀናት ለሚያስፈልጉ የባትሪ ቆጣቢ ሁነታ

## በውድድሮች ወቅት አጠቃቀም

### ዝግጅት

ከውድድር በፊት፡
1. የተመደቡለትን እና ፕሮግራሙን ያረጋግጡ
2. ልዩ ደንቦችን ያውርዱ
3. የግምገማ መስፈርቶችን ያረጋግጡ
4. አስፈላጊ ከሆነ ውሂቡን ከመስመር ውጭ ሁነታ ያውርዱ

### በውድድር ወቅት

በዝግጅቱ ጊዜ፡
1. የቀጥታ ጊዜ ግምገማ መገበያያውን ይጠቀሙ
2. ጥርጣሬ ሲኖር መስፈርቶችን በፍጥነት ያማክሩ
3. ከቦታ ኃላፊ ጋር በሥርዓቱ በኩል ይገናኙ
4. የሌሎች ዳኞች ውጤቶችን ያዩ (ፈቃድ ካለ)
5. ክስተቶችን እና ልዩ ጉዳዮችን በብቃት ያስተዳድሩ

### ከውድድር በኋላ

ሥራዎን ለማጠናቀቅ፡
1. ሁሉንም ግምገማዎች ያረጋግጡ
2. ከውድድር በኋላ ሪፖርትዎን ያስገቡ
3. ክስተቶችን ወይም ማሻሻያዎችን ካሉ ያሳውቁ
4. የዝግጅቱ ስታቲስቲክስ ያዩ
5. ለወደፊት ቀጠሮዎችዎን ያዘምኑ

## ቴክኒካል ድጋፍ

ከዳሽቦርድዎ ጋር ችግር ሲያጋጥምዎ፡
1. ዝርዝር የአጠቃቀም መመሪያውን ያማክሩ
2. ከውድድሩ የኮምፒውተር ኃላፊ ጋር ይገናኙ
3. የተዋሃደውን የእርዳታ ተግባር ይጠቀሙ
4. በውድድር ወቅት አስቸኳይ ሁኔታ ካለ፣ ቅድሚያ ድጋፍ ይገኛል
