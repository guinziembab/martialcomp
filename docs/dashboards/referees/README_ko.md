# 심판/심사위원 대시보드

## 소개

심판/심사위원 대시보드는 무술 대회에서 평가 및 심판 업무를 수행하는 임원을 위해 설계된 전문 인터페이스입니다. 이 플랫폼은 기술 심사위원과 대련 심판의 고유한 요구에 맞춘 도구를 제공합니다.

## 대시보드 접근

심판/심사위원 대시보드에 접근하려면:
1. MartialComp 계정에 로그인합니다
2. 프로필이 "judge" 또는 "referee" 역할로 설정되어 있으면 자동으로 이 대시보드로 이동합니다
3. 그렇지 않은 경우 URL `/dashboard/referee/`를 통해 접근합니다

## 주요 기능

### 개요

심판/심사위원 대시보드의 메인 페이지에는 다음이 표시됩니다:
- 배정된 예정 대회
- 과거 대회 이력
- 교육 및 자격 갱신 일정
- 중요 알림 (소집 통지, 일정 변경)
- 규정 및 채점 기준 바로가기

### 배정된 대회

"대회" 섹션에서는 다음이 가능합니다:
- 배정된 대회의 세부 정보 확인
- 본인의 역할 및 해당 경기장 확인
- 상세 일정 및 시간표 접근
- 종별 참가자 명단 조회
- 채점표 및 특정 규정 다운로드

### 기술 채점

"채점" 섹션에서는 다음 도구를 제공합니다:
- 전자 채점 시스템 접근
- 실시간 점수 입력
- 종목별 평가 기준 조회
- 이전 연기 검토
- 채점 일관성 분석

### 대련 심판

대련 심판을 위한 전용 기능:
- 점수 카운팅 시스템
- 벌점 및 경고 관리
- 내장 타이머
- 부상 및 중단 추적
- 다양한 규정에 맞춘 인터페이스 (태권도, 가라테 등)

### 지속 교육

"교육" 섹션에서는 다음이 가능합니다:
- 새로운 규칙 및 규정 업데이트 확인
- 교육 자료 접근 (영상, 문서)
- 자격 갱신 연수 등록
- 교육 이력 조회
- 심판 등급 승급 시험 준비

## 추가 기능

### 심판/심사위원 프로필

임원 프로필 관리:
- 개인 정보 및 연락처
- 자격 및 심판 등급
- 종목 및 전문 분야
- 가용 일정 및 선호 사항
- 심판 활동 이력

### 커뮤니케이션

주최자 및 다른 임원과의 소통 도구:
- 내부 메시지 시스템
- 일정 변경 알림
- 참석 가능 여부 확인
- 대회 후 보고서
- 규정 관련 문의

### 분석 및 통계

채점 업무를 분석하고자 하는 심사위원을 위한 기능:
- 종별 채점 통계
- 다른 심사위원과의 비교
- 일관성 분석
- 추이 그래프
- 맞춤형 보고서

### 오프라인 모드

인터넷 연결 없이 사용 가능한 기능:
- 대회 데이터 사전 다운로드
- 오프라인 모드에서 점수 입력
- 재연결 시 자동 동기화
- 장시간 운영을 위한 배터리 절약 모드

## 대회 중 사용 방법

### 사전 준비

대회 전:
1. 배정 내용 및 일정을 확인합니다
2. 해당 규정을 다운로드합니다
3. 채점 기준을 확인합니다
4. 필요시 오프라인 모드로 데이터를 다운로드합니다

### 대회 진행 중

행사 진행 중:
1. 실시간 채점 인터페이스를 사용합니다
2. 의문이 있을 경우 기준을 신속히 확인합니다
3. 시스템을 통해 경기장 책임자와 소통합니다
4. 다른 심사위원의 점수를 확인합니다 (허용된 경우)
5. 사고 및 특수 상황을 효율적으로 관리합니다

### 대회 종료 후

업무를 마무리하기 위해:
1. 모든 채점 내용을 최종 확인합니다
2. 대회 후 보고서를 제출합니다
3. 사고 또는 개선 사항이 있으면 보고합니다
4. 행사 통계를 확인합니다
5. 향후 가용 일정을 업데이트합니다

## 기술 지원

대시보드 사용에 어려움이 있는 경우:
1. 상세 사용 가이드를 참고합니다
2. 대회 IT 담당자에게 연락합니다
3. 내장된 도움말 기능을 이용합니다
4. 대회 중 긴급한 경우, 우선 지원 서비스를 이용할 수 있습니다
