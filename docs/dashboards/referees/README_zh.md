# 裁判/评委控制面板

## 简介

裁判/评委控制面板是一个专为武术比赛中负责评判和执裁的官员设计的专用界面。该平台提供了针对技术评委和格斗裁判特定需求的专业工具。

## 访问控制面板

访问裁判/评委控制面板的方法：
1. 登录您的 MartialComp 账户
2. 如果您的账户已配置为"judge"（评委）或"referee"（裁判）角色，系统将自动跳转至该控制面板
3. 您也可以通过 URL `/dashboard/referee/` 直接访问

## 主要功能

### 概览

裁判/评委控制面板主页显示以下内容：
- 您已被指派的即将举行的比赛
- 已完成比赛的历史记录
- 培训与进修课程日程
- 重要通知（召集通知、时间变更等）
- 快速访问比赛规则和评分标准

### 已指派的比赛

"比赛"板块可以：
- 查看您已被指派的比赛详情
- 了解您的角色以及分配的竞赛场地
- 查看详细的时间安排与赛程
- 按组别查看参赛选手名单
- 下载评分表和相关比赛规则

### 技术评分

"评分"板块提供以下工具：
- 访问电子评分系统
- 实时录入成绩
- 查看各项目的评判标准
- 回顾之前的表演/比赛
- 分析您评分的一致性

### 格斗裁判

针对格斗裁判的专用功能：
- 计分系统
- 犯规和警告管理
- 内置计时器
- 伤病和比赛中断跟踪
- 适配不同规则体系的界面（跆拳道、空手道等）

### 继续教育

"培训"板块可以：
- 跟进最新规则和规则更新
- 访问教学资源（视频、文档）
- 报名参加进修培训
- 查看您的培训历史记录
- 准备裁判晋级考试

## 附加功能

### 裁判/评委个人资料

管理您的官方资料：
- 个人信息和联系方式
- 资质认证与裁判等级
- 执裁项目与专业方向
- 可用时间与偏好设置
- 执裁比赛历史记录

### 通讯

与组织者和其他官员沟通的工具：
- 内部消息系统
- 赛程变更通知
- 出勤确认
- 赛后报告
- 规则咨询

### 分析与统计

供评委分析自身工作的功能：
- 按组别统计评分数据
- 与其他评委进行对比
- 一致性分析
- 趋势图表
- 自定义报告

### 离线模式

无网络连接时可用的功能：
- 预先下载比赛数据
- 离线模式下录入成绩
- 恢复连接后自动同步
- 省电模式，适用于长时间工作日

## 比赛期间使用指南

### 赛前准备

比赛前：
1. 查看您的任务分配和赛程安排
2. 下载相关比赛规则
3. 核实评分标准
4. 如有需要，下载离线数据

### 比赛进行中

比赛期间：
1. 使用实时评分界面
2. 遇到疑问时快速查阅评判标准
3. 通过系统与场地负责人沟通
4. 查看其他评委的评分（如有权限）
5. 高效处理突发事件和特殊情况

### 赛后

完成工作：
1. 确认并验证您的所有评分
2. 提交赛后报告
3. 报告可能存在的问题或改进建议
4. 查看赛事统计数据
5. 更新您未来的可用时间

## 技术支持

如果在使用控制面板时遇到问题：
1. 查阅详细使用指南
2. 联系比赛信息技术负责人
3. 使用内置帮助功能
4. 比赛期间如遇紧急情况，可获得优先技术支持
