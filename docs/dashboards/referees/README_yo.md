# Dasibodu Adajo/Onidajo

## Ifaara

Dasibodu Adajo/Onidajo jẹ atọka amọja ti a ṣe apẹrẹ fun awọn oṣiṣẹ osise ti wọn n ṣe igbelewọn ati idajọ awọn idije ere idaraya ologun. Iru ẹrọ yii n pese awọn irinṣẹ ti a ṣe deede si awọn aini kan pato ti awọn adajo imọ-ẹrọ ati awọn adajo ija.

## Iwọle si Dasibodu

Lati wọle si dasibodu adajo/onidajo:
1. Wọle si akọọlẹ MartialComp rẹ
2. Ti a ba ti ṣe profaili rẹ pẹlu ipa "judge" tabi "referee", a o darí ọ lọ si dasibodu yii laifọwọyi
3. Bibẹẹkọ, lo URL `/dashboard/referee/`

## Awọn Iṣẹ Akọkọ

### Akopọ

Oju-iwe akọkọ dasibodu adajo/onidajo fi wọnyi han:
- Awọn idije ti n bọ nibiti a ti yan ọ
- Itan awọn idije ti tẹlẹ
- Kalẹnda awọn ikẹkọ ati awọn atuntunse
- Awọn iwifunni pataki (awọn ipe, awọn iyipada akoko)
- Wiwọle iyara si awọn ofin ati awọn ilana isiro

### Awọn Idije Ti A Yan

Apakan "Awọn Idije" jẹ ki o:
- Wo awọn alaye awọn idije nibiti a ti yan ọ
- Ri ipa rẹ ati awọn aaye idije ti o kan
- Wọle si awọn akoko ati eto alaye
- Wo akojọ awọn olukopa nipa ẹka
- Gba awọn iwe isiro ati awọn ofin kan pato silẹ

### Isiro Imọ-ẹrọ

Apakan "Isiro" n pese awọn irinṣẹ fun:
- Wiwọle si eto isiro itanna
- Titẹ awọn aaye ni akoko gidi
- Wiwo awọn ilana igbelewọn nipa ẹkọ
- Ṣe atunwo awọn isise ti tẹlẹ
- Ṣe itupalẹ ibamu awọn isiro rẹ

### Idajọ Ija

Fun awọn adajo ija, awọn iṣẹ ti a yan si:
- Eto kika awọn aaye
- Isakoso awọn ijiya ati awọn ikilọ
- Aago akoko ti a ṣe isọpọ
- Itọpinpin awọn ipalara ati awọn idaduro
- Atọka ti a ṣe deede si awọn ofin oriṣiriṣi (Taekwondo, Karate, ati bẹbẹ lọ)

### Ikẹkọ Lemọlemọ

Apakan "Ikẹkọ" jẹ ki o:
- Tẹle awọn ofin tuntun ati awọn imudojuiwọn awọn ilana
- Wọle si awọn ohun elo ẹkọ (awọn fidio, awọn iwe aṣẹ)
- Forukọsilẹ fun awọn idanileko atuntunse
- Wo itan ikẹkọ rẹ
- Murasilẹ fun awọn idanwo igbesoke ipele idajọ

## Awọn Iṣẹ Afikun

### Profaili Adajo/Onidajo

Isakoso profaili oṣiṣẹ osise rẹ:
- Alaye ti ara ẹni ati awọn olubasọrọ
- Awọn iyẹn ati awọn ipele idajọ
- Awọn ẹkọ ati awọn amọja
- Wiwa ati awọn ayanfẹ
- Itan awọn idije ti o ti ṣe idajọ

### Ibasọrọ

Awọn irinṣẹ lati basọrọ pẹlu awọn oluṣeto ati awọn oṣiṣẹ osise miiran:
- Eto ifiranṣẹ inu
- Awọn iwifunni iyipada eto
- Awọn ifọwọsi wiwa
- Awọn ijabọ lẹyin idije
- Awọn ibeere nipa awọn ofin

### Itupalẹ ati Awọn Iṣiro

Fun awọn adajo ti wọn fẹ ṣe itupalẹ iṣẹ wọn:
- Awọn iṣiro isiro nipa ẹka
- Afiwe pẹlu awọn adajo miiran
- Itupalẹ ibamu
- Awọn aworan alaworan iyipada
- Awọn ijabọ ti ara ẹni

### Ipo Aisiasopọ

Awọn iṣẹ ti o wa laisi asopọ ayelujara:
- Gbigba data idije tẹlẹ silẹ
- Titẹ awọn aaye ni ipo aisiasopọ
- Iṣọkan laifọwọyi nigbati asopọ ba pada
- Ipo ifowopamọ batiri fun awọn ọjọ gigun

## Lilo Lakoko Awọn Idije

### Imurasilẹ

Ṣaaju idije:
1. Wo iyansipo rẹ ati eto naa
2. Gba awọn ofin kan pato silẹ
3. Ṣayẹwo awọn ilana isiro
4. Gba data silẹ ni ipo aisiasopọ ti o ba nilo

### Lakoko Idije

Ni akoko iṣẹlẹ naa:
1. Lo atọka isiro ni akoko gidi
2. Wo awọn ilana ni kia ti aiyedede ba wa
3. Basọrọ pẹlu olori aaye nipasẹ eto naa
4. Ri awọn aaye awọn adajo miiran (ti a ba gba laaye)
5. Ṣakoso awọn iṣẹlẹ ati awọn ipo kan pato daradara

### Lẹyin Idije

Lati pari iṣẹ rẹ:
1. Fọwọsi gbogbo awọn isiro rẹ
2. Fi ijabọ lẹyin idije silẹ
3. Ṣe akiyesi awọn iṣẹlẹ tabi awọn ilọsiwaju ti o ṣee ṣe
4. Wo awọn iṣiro iṣẹlẹ naa
5. Ṣe imudojuiwọn wiwa ọjọ iwaju rẹ

## Atilẹyin Imọ-ẹrọ

Ni ọran iṣoro pẹlu dasibodu rẹ:
1. Wo itọsọna lilo alaye
2. Kan si oluṣakoso imọ-ẹrọ idije naa
3. Lo iṣẹ iranlọwọ ti a ṣe isọpọ
4. Ni ọran pajawiri lakoko idije, atilẹyin pataki wa
