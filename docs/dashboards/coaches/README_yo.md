# Dasibodu Olukọni Ọpọ-ẹkọ

## Ifaara

Dasibodu Olukọni Ọpọ-ẹkọ jẹ atọka ti a ṣe apẹrẹ pataki fun awọn olukọni ti wọn n kọ ọpọlọpọ ẹkọ ere idaraya ologun. Iru ẹrọ yii jẹ ki o le ṣakoso awọn akẹkọ, awọn ikẹkọ ati awọn idije daradara nipasẹ awọn ẹkọ oriṣiriṣi, lakoko ti o n ko alaye jọ ni aaye kan.

## Iwọle si Dasibodu

Lati wọle si dasibodu olukọni ọpọ-ẹkọ:
1. Wọle si akọọlẹ MartialComp rẹ
2. Ti a ba ti ṣe profaili rẹ pẹlu ipa "coach" ati pe o ni awọn iyẹn ninu ọpọlọpọ ẹkọ, a o darí ọ lọ si dasibodu yii laifọwọyi
3. Bibẹẹkọ, lo URL `/dashboard/coach-multidiscipline/`

## Awọn Iṣẹ Akọkọ

### Akopọ

Oju-iwe akọkọ dasibodu olukọni ọpọ-ẹkọ fi wọnyi han:
- Akopọ awọn akẹkọ rẹ nipa ẹkọ
- Awọn ikẹkọ ati awọn iṣẹlẹ ti n bọ
- Awọn isise aipẹ awọn akẹkọ rẹ ni idije
- Awọn iwifunni pataki (awọn igbesoke ipele, awọn idije ti n bọ)
- Awọn iṣiro ati awọn itọka ilọsiwaju

### Isakoso Awọn Akẹkọ

Apakan "Awọn Akẹkọ" jẹ ki o:
- Wo akojọ pipe awọn akẹkọ rẹ ni gbogbo ẹkọ
- Ṣe àlẹmọ awọn akẹkọ nipa ẹkọ, ipele tabi ẹka ọjọ ori
- Wo awọn profaili alaye pẹlu itan awọn ipele ati awọn abajade
- Tẹle ilọsiwaju imọ-ẹrọ akẹkọ kọọkan
- Ṣakoso awọn iforukọsilẹ si awọn idije
- Ṣeto awọn ẹgbẹ ikẹkọ ọpọ-ẹkọ

### Igbero Awọn Ikẹkọ

Apakan "Awọn Ikẹkọ" jẹ ki o:
- Ṣẹda ati ṣakoso awọn akoko ikẹkọ fun ẹkọ kọọkan
- Gbero awọn ikẹkọ agbelebu ti o ṣopọ ọpọlọpọ ere idaraya ologun
- Tẹle wiwa awọn akẹkọ
- Mura awọn eto kan pato ti a ṣe deede si ipele kọọkan
- Ṣe alaye awọn ibi-afẹde imọ-ẹrọ fun ẹgbẹ tabi enikeji
- Ṣe itupalẹ ipa awọn ọna ikẹkọ

### Itọpinpin Awọn Idije

Apakan "Awọn Idije" jẹ ki o:
- Wo kalẹnda awọn idije ti n bọ nipa ẹkọ
- Ṣakoso awọn iforukọsilẹ awọn akẹkọ rẹ
- Mura awọn ilana idije ti ara ẹni
- Ṣe itupalẹ awọn abajade ati awọn isise
- Ṣe idanimọ awọn aaye ti o lagbara ati awọn aaye lati ni ilọsiwaju
- Ṣe afiwe awọn isise laarin awọn ẹkọ

### Idagbasoke Imọ-ẹrọ

Apakan "Imọ-ẹrọ" jẹ ki o:
- Wọle si awọn ohun elo ẹkọ fun ẹkọ kọọkan
- Ṣẹda awọn eto imọ-ẹrọ ti a ṣe deede si ipele kọọkan
- Mura awọn akẹkọ fun awọn igbesoke ipele
- Tẹle ilọsiwaju imọ-ẹrọ nipa ẹkọ
- Fi idi awọn ero ikẹkọ agbelebu mulẹ
- Ṣe akọsilẹ awọn ọna ikọni

## Awọn Iṣẹ Kan Pato Ọpọ-ẹkọ

### Iṣọkan Laarin Awọn Ẹkọ

Awọn irinṣẹ ti a ṣe apẹrẹ pataki fun:
- Ṣe idanimọ awọn ibamu laarin awọn ẹkọ
- Ṣẹda awọn eto ikẹkọ ti o ṣopọ ọpọlọpọ ere idaraya ologun
- Ṣe itupalẹ gbigbe awọn ọgbọn laarin awọn ẹkọ
- Ṣe alekun idagbasoke gbogbogbo awọn elere-ije

### Isakoso Awọn Iwe-ẹri

Itọpinpin aarin ti awọn iyẹn rẹ:
- Awọn iwe-ẹri ikọni nipa ẹkọ
- Awọn iwe-ẹri kan pato
- Awọn idanileko ikẹkọ lemọlemọ
- Awọn atuntunse ti a gbọdọ ṣe
- Igbero awọn atuntunse

### Itupalẹ Afiwera

Awọn irinṣẹ itupalẹ fun:
- Ṣe afiwe awọn isise awọn akẹkọ rẹ laarin awọn ẹkọ oriṣiriṣi
- Ṣe idanimọ awọn agbegbe nibiti awọn ọna ikẹkọ kan munadoko ju
- Ṣe ayẹwo ipa ìṣe ọpọ-ẹkọ lori ilọsiwaju
- Ṣẹda awọn ijabọ ti ara ẹni fun akẹkọ tabi ẹgbẹ kọọkan

### Igbero Ilọsiwaju

Awọn iṣẹ lati ṣe alekun eto:
- Isakoso awọn akoko giga fun awọn idije oriṣiriṣi
- Iṣọkan awọn kalẹnda laarin awọn ẹkọ
- Igbero akoko ti a ṣe deede si awọn ibeere ọpọ-ẹkọ
- Isakoso ẹru ikẹkọ gbogbogbo

## Aṣayan Dasibodu

Dasibodu naa n pese ọpọlọpọ awọn aṣayan aṣayan:
- Ṣeto awọn widjeti nipa pataki
- Awọn àlẹmọ aiyipada gẹgẹ bi awọn ẹkọ akọkọ rẹ
- Ṣe alaye awọn iwọn ati awọn itọka pataki lati fi han
- Ṣẹda awọn dasibodu kan pato fun ẹkọ kọọkan
- Aṣayan awọn iwifunni ati awọn itaniji

## Isọpọ Pẹlu Awọn Eto Miran

Dasibodu naa sopọ pẹlu:
- Awọn eto isakoso awọn ẹgbẹ nibiti o ti n kọni
- Awọn ajọ agbaye ere idaraya ti awọn ẹkọ oriṣiriṣi rẹ
- Awọn irinṣẹ itupalẹ fidio
- Awọn ohun elo itọpinpin ipo ara
- Awọn iru ẹrọ ibasọrọ pẹlu awọn akẹkọ

## Atilẹyin Imọ-ẹrọ

Ni ọran iṣoro pẹlu dasibodu rẹ:
1. Wo itọsọna lilo alaye
2. Lo iṣẹ iranlọwọ ti o wa (aami "?" ninu apakan kọọkan)
3. Kan si atilẹyin imọ-ẹrọ nipasẹ fọọmu ti a yan si
4. Kopa ninu awọn webinaire ikẹkọ ti a n pese nigbagbogbo
