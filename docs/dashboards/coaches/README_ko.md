# 다종목 지도자 대시보드

## 소개

다종목 지도자 대시보드는 여러 무술 종목을 지도하는 코치를 위해 특별히 설계된 인터페이스입니다. 이 플랫폼을 통해 다양한 종목에 걸쳐 수련생, 훈련 및 대회를 효율적으로 관리하면서 정보를 중앙 집중화할 수 있습니다.

## 대시보드 접속

다종목 지도자 대시보드에 접속하려면:
1. MartialComp 계정에 로그인합니다
2. 프로필이 "코치" 역할로 설정되어 있고 여러 종목에 대한 자격을 보유하고 있으면, 자동으로 이 대시보드로 이동됩니다
3. 그렇지 않은 경우, `/dashboard/coach-multidiscipline/` URL을 통해 접속할 수 있습니다

## 주요 기능

### 전체 개요

다종목 지도자 대시보드의 메인 페이지에는 다음 정보가 표시됩니다:
- 종목별 수련생 현황 요약
- 예정된 훈련 및 일정
- 수련생들의 최근 대회 성적
- 주요 알림 (승급 심사, 다가오는 대회)
- 통계 및 진도 지표

### 수련생 관리

"수련생" 섹션에서는 다음 작업이 가능합니다:
- 전 종목에 걸친 수련생 전체 목록 조회
- 종목, 수준 또는 연령 카테고리별 수련생 필터링
- 급/단 이력 및 성적이 포함된 상세 프로필 조회
- 각 수련생의 기술적 진도 추적
- 대회 등록 관리
- 다종목 훈련 그룹 구성

### 훈련 계획

"훈련" 섹션에서는 다음 작업이 가능합니다:
- 각 종목별 훈련 세션 생성 및 관리
- 여러 무술을 결합한 교차 훈련 계획 수립
- 수련생 출석 추적
- 각 수준에 맞는 맞춤형 프로그램 준비
- 그룹 또는 개인별 기술 목표 설정
- 훈련 방법의 효과 분석

### 대회 추적

"대회" 섹션에서는 다음 작업이 가능합니다:
- 종목별 예정 대회 일정 조회
- 수련생 대회 등록 관리
- 맞춤형 대회 전략 수립
- 성적 및 퍼포먼스 분석
- 강점 및 개선 사항 파악
- 종목 간 성적 비교

### 기술 개발

"기술" 섹션에서는 다음 작업이 가능합니다:
- 각 종목별 교육 자료 접근
- 각 수준에 맞는 기술 프로그램 작성
- 수련생 승급 심사 준비
- 종목별 기술 진도 추적
- 교차 훈련 프로그램 수립
- 교수법 기록 관리

## 다종목 전용 기능

### 종목 간 협업

다음을 위해 특별히 설계된 도구:
- 종목 간 상호 보완성 파악
- 여러 무술을 결합한 훈련 프로그램 구성
- 종목 간 기술 전이 분석
- 선수의 종합적 발전 최적화

### 자격 관리

자격 사항 통합 관리:
- 종목별 지도자 자격증
- 전문 자격 인증
- 보수 교육 이수 현황
- 의무 갱신 교육
- 갱신 일정 계획

### 비교 분석

분석 도구:
- 다양한 종목에 걸친 수련생 성적 비교
- 특정 훈련 방법이 더 효과적인 분야 파악
- 다종목 수련이 진도에 미치는 영향 평가
- 수련생별 또는 그룹별 맞춤 보고서 작성

### 고급 계획

프로그래밍 최적화 기능:
- 다양한 대회에 대한 컨디션 관리
- 종목 간 일정 조율
- 다종목 요구사항에 맞춘 주기화 계획
- 전체 훈련 부하 관리

## 대시보드 맞춤 설정

대시보드는 다양한 맞춤 설정 옵션을 제공합니다:
- 우선순위별 위젯 배치
- 주요 종목 기준 기본 필터 설정
- 표시할 주요 지표 및 메트릭 정의
- 종목별 전용 대시보드 생성
- 알림 및 경고 맞춤 설정

## 다른 시스템과의 연동

대시보드는 다음 시스템과 연동됩니다:
- 지도 중인 클럽의 관리 시스템
- 각 종목의 체육 연맹
- 영상 분석 도구
- 체력 추적 애플리케이션
- 수련생과의 커뮤니케이션 플랫폼
