Date d'implémentation : 18 mai 2025

Vue d'ensemble

Tests de sécurité implémentés

1. Test d'isolation des schémas (cross_schema_access)

  • Vérifie que chaque tenant ne peut accéder qu'à son propre schéma PostgreSQL
  • Test l'isolation entre le schéma public et les schémas des tenants
  • Test l'isolation entre les schémas de différents tenants

2. Test d'isolation du middleware (middleware_isolation)

  • Vérifie que le middleware multi-tenant définit correctement le tenant
  • Teste que le contexte tenant est correctement isolé

3. Test d'isolation du cache (cache_isolation)

  • Vérifie que les clés de cache sont correctement préfixées par tenant
  • Teste que les tenants ne peuvent pas accéder aux données de cache des autres

4. Test d'accès aux fichiers (file_access)

  • Vérifie l'isolation des fichiers entre les tenants
  • Teste que les tenants ne peuvent pas accéder aux fichiers des autres

5. Test des en-têtes de sécurité (security_headers)

  • Vérifie la présence des en-têtes de sécurité HTTP requis
  • Teste la configuration de sécurité globale de Django

6. Test des permissions (tenant_permissions)

  • Vérifie que les permissions sont correctement appliquées aux tenants
  • Teste l'isolation des droits d'accès

Utilisation

Interface Web

Accédez au tableau de bord de sécurité via le menu admin :

/multitenant/admin/security/

Ligne de commande

# Audit complet python manage.py run_security_audit # Audit d'un tenant spécifique python manage.py run_security_audit --tenant=tenant_slug # Audit avec détails python manage.py run_security_audit --verbose

Fonctionnalités principales

  • Tableau de bord de sécurité avec score global et métriques
  • Audit automatisé avec génération de rapports détaillés
  • Historique des audits avec suivi des violations
  • Analyse des violations par type, sévérité et tenant
  • Rapports exportables au format JSON
  • API Python pour intégration dans le code

Classes et modules créés

Classes principales

  • SecurityAuditor : Classe principale pour exécuter les audits
  • TenantSecurityMonitor : Surveillance continue de la sécurité
  • TenantComplianceChecker : Vérification de conformité

Vues Django

  • SecurityDashboardView : Tableau de bord principal
  • SecurityReportListView : Liste des rapports d'audit
  • SecurityReportDetailView : Détail d'un rapport
  • RunSecurityAuditView : Lancer un audit
  • SecurityViolationsView : Analyser les violations

Structure des rapports

Les rapports sont enregistrés dans :

/mnt/c/martial_hub_django/martialcomp/logs/security_reports/

Format du rapport :

{
  "summary": {
    "status": "passed|failed",
    "tests_run": 6,
    "violations_found": 0,
    "report_id": "uuid",
    "timestamp": "2024-01-01T12:00:00",
    "tenant": "tenant_name|all"
  },
  "results": {
    "cross_schema_access": {
      "status": "passed|failed",
      "checks": [...],
      "violations": [...]
    },
    ...
  }
}
