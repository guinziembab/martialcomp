Documentation

Si vous rencontrez des problèmes avec les traductions, vérifiez:

  1. Que tous les fichiers de traduction .mo existent pour chaque langue
  2. Que les balises {% verbatim %}{% trans %}{% endverbatim %} sont correctement utilisées
  3. Que le middleware LocaleMiddleware est activé et dans le bon ordre
  4. Que le cookie de langue est correctement défini
  5. Que les URLs sont correctement préfixées si vous utilisez i18n_patterns
