## 🧪 **TESTS RECOMMANDÉS**

### **1. 🌍 Test du Changement de Langue**
**Objectif:** Vérifier que l'interface s'adapte correctement à chaque langue

**Étapes:**
1. Se connecter à https://martialcomp.com
2. Cliquer sur le sélecteur de langue (drapeau en haut à droite)
3. Tester plusieurs langues différentes
4. Vérifier que tous les textes sont traduits
5. Tester la navigation dans chaque langue

**Langues prioritaires à tester:**
- Votre langue maternelle
- Japonais, Chinois, Hindi, Vietnamien, Coréen, Amharique
- Au moins 3 langues européennes

### **2. 🏛️ Test du Dashboard Fédération**
**Objectif:** Vérifier l'accès au système de grades pour les fédérations

**Étapes:**
1. Se connecter avec un compte fédération
2. Accéder au dashboard fédération
3. Cliquer sur "Examens & Grades"
4. Vérifier que l'accès fonctionne
5. Tester la création d'examens

**Utilisateurs concernés:** Admins de fédération

### **3. 👥 Test de l'Ajout de Pratiquants**
**Objectif:** Vérifier que l'ajout de pratiquants fonctionne pour tous les types d'utilisateurs

**Étapes:**
1. Se connecter avec un compte club
2. Aller dans "Pratiquants" → "Ajouter un pratiquant"
3. Remplir le formulaire complet
4. Tester la génération du numéro de licence
5. Vérifier que le pratiquant est créé

**Utilisateurs concernés:** Propriétaires de club, coaches

### **4. 🏆 Test de la Création de Compétitions**
**Objectif:** Vérifier que la création de compétitions fonctionne correctement

**Étapes:**
1. Se connecter avec un compte fédération
2. Aller dans "Compétitions" → "Créer une compétition"
3. Remplir le formulaire de création
4. Vérifier que les types de compétition se chargent
5. Tester la sauvegarde

**Utilisateurs concernés:** Admins de fédération

### **5. 📱 Test de la Fonctionnalité QR**
**Objectif:** Vérifier que les QR codes des pratiquants fonctionnent

**Étapes:**
1. Accéder au profil d'un pratiquant
2. Cliquer sur "Voir QR Code"
3. Vérifier que le QR code s'affiche
4. Tester le scan du QR code
5. Vérifier l'accès public aux QR codes

**Utilisateurs concernés:** Tous les utilisateurs

## 🐛 **RAPPORT DE BUGS**

### **Comment Signaler un Problème**

#### **1. Informations Requises**
- **Description** : Expliquez clairement le problème
- **Étapes** : Décrivez exactement ce que vous avez fait
- **Résultat attendu** : Ce qui devrait se passer
- **Résultat obtenu** : Ce qui s'est réellement passé
- **Capture d'écran** : Si possible, joignez une image
- **Navigateur** : Chrome, Firefox, Safari, etc.
- **Appareil** : Desktop, mobile, tablette

#### **2. Exemple de Rapport**
```
🐛 BUG RAPPORTÉ

Description: Le bouton "Sauvegarder" ne fonctionne pas
Étapes: 
1. J'ai cliqué sur "Ajouter un pratiquant"
2. J'ai rempli le formulaire
3. J'ai cliqué sur "Sauvegarder"
Résultat attendu: Le pratiquant devrait être créé
Résultat obtenu: Rien ne se passe, le bouton ne répond pas
Navigateur: Chrome 118
Appareil: Desktop Windows
```

#### **3. Où Envoyer les Rapports**
- **Email** : support@martialcomp.com
- **Sujet** : [TEST PILOTE] Description du problème
- **Priorité** : Indiquez si c'est critique ou mineur
