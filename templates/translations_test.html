5. Instructions pour l'implémentation

Pour utiliser les traductions dans vos templates:

  1. Chargez le module i18n: {% verbatim %}{% load i18n %}{% endverbatim %}
  2. Pour les chaînes simples: {% verbatim %}{% trans "texte à traduire" %}{% endverbatim %}
  3. Pour les blocs: {% verbatim %}{% blocktrans %}texte à traduire{% endblocktrans %}{% endverbatim %}
  4. Pour utiliser le filtre: {% verbatim %}{{ "texte"|trans }}{% endverbatim %}

Pour la gestion des fichiers de traduction:

  1. Extraire les messages: python manage.py makemessages -l <langue>
  2. Éditer les fichiers .po dans le répertoire locale
  3. Compiler les messages: python manage.py compilemessages
